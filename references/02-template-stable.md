# 稳定多模态模板

## 何时读取

有单图、多图、图文混合输入，或任务强调参考还原、角色一致性、逐镜连续与质量复盘时读取。

## 差异化能力

1. **事实卡**：锁定事实、合理推断、导演新增分层记录。
2. **角色置信度**：明确名称和作品信息优先；仅凭普通外貌不能确认身份。
3. **首帧锚定**：说明主体、位置、姿态、视线、镜头和已发生状态。
4. **四阶段接力**：首次接触 → 结果利用 → 升级峰值 → 终结余波。
5. **返修路径**：输入忠实、动作因果、时空连续、镜头、物理、声音、格式逐项检查。

## 使用规则

- 图片负责已呈现事实，文字主要补运动、节奏、受力和声音。
- 多图先声明每份素材职责，禁止交换编号或让一个素材同时控制所有维度。
- 后一镜继承前一镜的位置、速度、受力、伤损和摄影机状态。
- 角色漂移、动作无对象、无故越轴或结尾静止均视为结构失败，回到上游重写。
