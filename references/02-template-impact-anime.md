# 动漫高冲击模板

## 何时读取

短时长、高密度、二次元/国漫/风格化动作、多资产参考，或用户要求强开场、节奏拐点、夸张特效与声音同步时读取。

## 差异化能力

1. **资产绑定**：定义素材职责，保持编号、角色、场景和武器归属一致。
2. **高冲击开场**：首帧即有效攻防或位移，不用站立、凝视或空泛蓄力消耗时长。
3. **节奏结构**：接触 → 近景对招 → 空间变化 → 情绪拐点 → 终结余波。
4. **效果附着**：气焰、速度线、粒子与冲击波跟随肢体、武器、轨迹或命中点。
5. **声音分层**：动作声、环境声和配乐分别设计，命中、停顿与终结同步。

## 使用规则

- 快不等于快切；先写具体动作，再用背景相对运动、短暂停顿和冲击反馈表现速度。
- 近景对招必须有明确招式序列和防守变化。
- 风格化夸张不能破坏角色结构、武器归属和空间方向。
- 字段、素材标签、时长和声音能力服从目标工具。
