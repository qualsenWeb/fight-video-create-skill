# Reference 检索索引

## 固定读取顺序

1. `00-reference-index.md`：路由。
2. `01-core-guidelines.md`：公共动作与镜头规则。
3. 按条件选择一个 `02-template-*`。
4. 按题材选择一个 `03-topic-*`；混合题材最多增加一个。

## 专用模板路由

- `02-template-stable.md`：单图、多图、图文混合；要求事实锚定、角色一致性、逐镜状态和严格质检。
- `02-template-impact-anime.md`：短时长、高密度、动漫/风格化动作、多资产绑定与声音节奏。
- `02-template-combat-library.md`：角色创建、选招、武学/兵器知识、完整镜头规格、视觉风格和场景选择。

## 题材路由

- `03-topic-modern.md`：现代近身格斗、枪战、特工、追逐、西部枪战。
- `03-topic-eastern-fantasy.md`：武侠、仙侠、忍者武士、中国神话、东方法术。
- `03-topic-western-history.md`：西方奇幻、古战场、角斗、海盗海战。
- `03-topic-scifi-supernatural.md`：机甲、机器人、赛博、异能、时间/空间和灵异。
- `03-topic-vehicles-war.md`：空战、编队、军阵、载具、海空协同和大规模战争。
- `03-topic-creatures-tokusatsu.md`：妖兽、巨龙、海怪、巨人、怪兽、巨型机甲对怪兽。

## 混合题材选择示例

- 仙侠修士对巨兽：主 `03-topic-eastern-fantasy.md`，辅 `03-topic-creatures-tokusatsu.md`。
- 机甲城市群战：主 `03-topic-scifi-supernatural.md`，规模复杂时辅 `03-topic-vehicles-war.md`。
- 海盗船遭海怪：主 `03-topic-western-history.md`，辅 `03-topic-creatures-tokusatsu.md`。
- 现代士兵对异能者：按剧情主视角选择 `03-topic-modern.md` 或 `03-topic-scifi-supernatural.md`，另一份作辅助。

## 非全量读取限制

- 普通任务：索引 + 公共规范 + 1 专用模板（可选）+ 1 主题材。
- 复杂混合任务：最多增加 1 个辅题材。
- 不因用户只说“高燃”就读取全部模板；高燃是节奏要求，不是题材。
- 原始 `资料/` 仅在 reference 无法覆盖具体招式或新增样本吸收时定向读取。
