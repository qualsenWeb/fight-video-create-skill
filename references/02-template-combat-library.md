# 通用高密度动作知识库入口

来源基线：`资料/武打skill.md`，已去除单一模型绑定。

## 何时读取

用户要求以下任一内容时读取本入口：

- 创建角色卡或战斗风格；
- 从拳法、踢技、剑法、刀法、兵器或轻功中选招；
- 需要完整镜头规格和可执行机位；
- 需要默认视觉风格或场景候选；
- 需要扩展成高密度近景对招。

## 定向读取原始知识库

不要全量读取 `资料/武打skill.md`。先搜索对应标题，再只读相关行段：

- 镜头规格：搜索“镜头规格强制系统”“镜头目的性四原则”。
- 近景对招：搜索“上半身近景对招体系”。
- 角色创建：搜索“角色创建引导流程”。
- 兵器与轻功：搜索“兵器技法调用规则”。
- 角色与拳法：搜索“角色拳法体系参考”。
- 招式：搜索具体拳法、兵器或动作名称。
- 视觉风格：搜索“视觉风格选择功能”。
- 场景：搜索“场景设计选择功能”。

## 使用边界

角色、颜色和既有招式是可选资产，不得自动套给用户原创角色。只提取能支撑当前动作因果和角色签名的少量招式。公共动作和连续性规则以 `01-core-guidelines.md` 为准。
