# 通用创作规范

## 提示词与分镜结构

```text
Shot = Subject + ActionChain + Space + Camera + Feedback + Style + Audio + StateHandoff
```

- `Subject`：角色/生物/载具、稳定外形、武器、阵营与相对位置。
- `ActionChain`：起始状态 → 攻击 → 防守/受击 → 位移 → 反击/终结。
- `Space`：地点、可辨认锚点、天气和可互动环境。
- `Camera`：景别、视角、机位、运动、跟随目标和结束位置。
- `Feedback`：受力、重心、材质、衣物/武器/地面/介质反馈。
- `Style`：媒介、色彩、光线、特效附着方式与情绪。
- `Audio`：动作同期声、环境声和配乐策略。
- `StateHandoff`：人物位置、朝向、武器、伤损、运动惯性和环境变化。

## 五项硬约束

1. 用户锁定事实 > 可见素材事实 > 连续性补全 > 导演新增。
2. 不用“快速连击”代替动作；写清肢体、目标、落点、应对和结果。
3. 固定交战轴和空间锚点；越轴时用全景、遮挡或中性机位重新建立方向。
4. 近景看手部/面部/接触点，中景看攻防，全景看走位与空间结果，特写只作命中或转折标点。
5. 物理闭环：蓄力/位移 → 接触 → 反作用 → 姿态变化 → 环境反馈。

## 剧本演化

```text
SimpleStory
  → DramaticGoal
  → InitialState
  → Escalation
  → TacticalOrEmotionalTurn
  → Resolution
  → ResidualMotion
```

每一步必须改变目标、优势、关系、位置或环境状态。无法改变状态的画面是装饰镜头，应删除或压缩。

## 镜头选择

- 小幅拳掌肘和武器接触：近景/中近景。
- 踢击、摔投、中距离兵器：中景。
- 腾空、追逐、大范围技能、军阵：全景。
- 关键落点、破绽、表情：0.2—0.5 秒特写。
- 每镜只设一个主运镜；运镜由主体动作触发并在可说明的位置停止。

## 分段原则

当故事超出单次生成容量：

- 按冲突阶段拆成多个视频片段；
- 每段只承担一个主要叙事任务；
- 每段记录首帧、尾帧与下一段交接状态；
- 不通过压缩文字强行把完整故事塞进一个短片。

## 质量检查

- 主体是否稳定可辨？
- 动作是否有因果和可见结果？
- 镜头能否看清动作而非抢动作？
- 受力、材质和特效是否一致？
- 镜间位置、朝向、伤损和武器是否连续？
- 输出是否服从目标工具真实协议？
