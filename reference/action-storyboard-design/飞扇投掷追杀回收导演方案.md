# 飞扇投掷追杀回收导演方案

## 适用边界

适用于可辨认扇面、扇骨和外轮廓的大型投掷法器，在开放空域对单一主要目标执行追杀、封线与回收。也可迁移至环刃、盘刃等有明确实体外形的投掷法器。

## 标准链路

`持有展示 → 蓄势与肩胯发力 → 松手离体 → 固定初始攻击轴线 → 弧线或追踪变轨 → 攻击介质释放 → 目标大位移躲避 → 原位置命中反馈 → 回收或消散`

- 起抛镜头必须先看到法器在手中，再看到手掌松开；禁止从画外直接飞入。
- 初始弹道以施术者和目标同框建立；后续变轨需保留法器实体与前一轨迹的惯性关系。
- 法器释放的线网、刃光或能量必须从扇缘、扇骨或明确结构发出，并切开云雪、地形或目标旧位置证明杀伤。
- 目标每次躲避都要显示旧位置、跨越路径、新位置与旧位置被击中的反馈，避免用镜头切换冒充闪避。
- 回收时以手势、能量牵引或既定回旋弧线解释，并给出接住或消散结果。

## 镜头纪律

用侧面双人广角锁定起抛轴线；俯拍或广角跟拍展示法器与目标的空间关系；接住时可短切中近景。镜头不得越轴导致投掷方向与目标关系翻转。

## 门禁

法器不可在追杀中变成不可辨认光团；攻击不应遮蔽法器本体；三次以上躲避时高度、横向与纵深至少改变两个维度；回收前不让法器无因消失。
