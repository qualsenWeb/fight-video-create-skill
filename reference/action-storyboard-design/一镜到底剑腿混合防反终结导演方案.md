# 一镜到底剑腿混合防反终结导演方案

来源：《裂空·诛魔 V3.4》与《霜月剑姬·冰封沧溟》。提炼一镜到底、剑腿混合、防反和移动聚能机制。

## 七拍结构

空间进入 → 兵器三击建立压力 → 剑腿混合绕背 → 敌方远程反扑与防反 → 移动中聚能并牵引接近 → 单一终结 → 过曝缓恢复和动态收尾。

## 核心规则

- 一镜到底仍按2至4秒动作段落设计，用人物擦身、碎片、烟雾和短时过曝完成视点接力。
- 剑与腿承担不同距离：剑封中距、腿在贴身时打腕、膝、胸甲或借敌方武器换位。
- 防反必须沿敌方来向发生：硬接或偏转后，让敌方能量、惯性或武器线反噬其自身防御。
- 聚能必须发生在飞升、旋身、追近、牵引或换位中，禁止站桩发光。
- 终结前只保留一个最高强度高潮；黑白冲击、过曝、空间撕裂等不能在每次普通接触重复。

## 连续性门禁

遮挡前记录双方位置、朝向、速度、武器状态和伤痕；遮挡后至少继承四项。最终过曝必须先恢复人物剪影，再恢复颜色和细节；最后一帧保留衣摆、余电、碎片或镜头缓移。
