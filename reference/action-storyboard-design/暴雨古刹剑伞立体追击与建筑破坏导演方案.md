# 暴雨古刹剑伞立体追击与建筑破坏导演方案

## 适用边界

适用于双人近身兵器战，场景具有庭院、回廊、屋顶、大殿与悬崖等连续高低层，双方能够通过飞檐、木柱、铁链或巨物完成有支点的追击与反制。伞类兵器可以展开防守、收拢点刺、以伞钩挂檐或挂链，但不要求必须使用原案例角色和配色。

不适用于平坦无建筑场景、纯远程站桩对轰、低机动写实格斗或无法承载建筑破坏的短时单镜头。原稿中的0.01秒冲刺、违反重力跑柱和整座大殿切断属于夸张3D CG能力档，写实任务必须降级。

## 叙事脊柱

`庭院抢先手 → 回廊纵轴压迫 → 飞檐向上追击 → 屋顶贴身破防 → 重击塌顶共同坠落 → 殿内巨物改线 → 贴地反制 → 错身终结 → 临崖急停 → 延迟结构结果`

原案例共十二镜，镜头1未标时长，其余镜头合计17.5秒。入库时不推断镜头1时长；改编需按目标平台重新分配时间，不能声称原稿具有精确总时长。

## 多层路线纪律

- 每一层只承担一个主要职责：庭院建立方向，回廊压缩闪避，飞檐与屋脊改变高度，大殿让坠落和巨物改线，悬崖提供终结尺度；
- 跨层必须有可见触发：后翻退出、护栏破裂、伞钩挂檐、踏柱连跑、主梁断裂、铁链摆荡或冲刺穿门；
- 上一层的破坏成为下一层的入口，屋顶坠落时双方姿态、兵器接触和碎片速度连续；
- 铜钟等巨物只改变一次主要攻击线，使用后保留摆动、落点或断裂状态，不跨镜重置；
- 每次进入新区域先用最短全景交代支点与落点，再收紧到兵器接触。

## 剑伞攻防关系

- 长剑以斜撩、刺、撩、抹、截、重劈和平削形成直线与弧线压迫；每条短链最多三至四招；
- 展开的伞面负责竖架、偏转和吸收正面冲击，收拢骨伞转为短棍或点刺武器；伞钩负责挂檐、挂链和改变身体轨迹；
- 伞面格挡后必须出现伞骨受力、持伞手腕偏转、身体滑步或伞面角度变化；长剑被卡后必须沿伞骨滑移、压剑、抽离或换线；
- 手部打击只在贴身且对方手腕已被兵器关系固定时使用，目的为改变持械线，不写成无依据的点穴瘫痪；
- 最终平斩必须由前段手腕受击、中门暴露、落地路线或追击惯性形成，不因“眼神爆燃”突然获得必胜速度。

## 三级碰撞表现

原稿的“每击固定冲击帧”改为可选强度梯度：

1. **轻接触**：刃伞摩擦、拉丝火星、局部水膜或骨焰剥离、一次短促轴向微震；仅在需要强调首次接触时选用局部冲击帧；
2. **重接触**：武器明显下沉或回弹、角色重心变化、脚步滑移、局部负片或放射冲击、对应材质破坏；
3. **终结爆发**：短冲击帧、局部鱼眼或闪白、环形冲击波和延迟结构结果；必须保留主体轮廓、攻击方向和结果链。

同一短链不为每次轻碰撞重复插帧。全屏负片、强Bloom和鱼眼只能服务唯一终结接触，不能同时覆盖动作过程。

## 运镜适配

- 原稿的复合运镜视为镜头段落内的接力候选，不是必须同时执行的命令；每个动作阶段保留一种主运镜，其他只做短促构图修正；
- 庭院贴地前推在剑刃接触前停止，大幅180度甩摇放在两人完成交错之后；
- 回廊四连快攻使用侧面平移跟拍，不叠加持续焦点摇甩；最后重击成立后才短倾斜显示护栏破坏；
- 飞檐追击使用低位上摇或全景垂直跟随，屋顶近身用中景稳定接触；
- 屋顶塌陷到大殿使用同轴下坠跟拍，铜钟横扫使用全景显示钟、目标和闪避路径；
- 临崖终结的径向震荡在斩击出手后触发，入鞘阶段改用低速跟随并让暴雨、衣料和建筑裂纹继续运动。

## 结尾闭环

`前段破绽成立 → 剑客沿已建立路线错身平斩 → 双方分离并保留攻击轴 → 剑客临崖滑停 → 入鞘声成为既有剑痕的延迟释放节点 → 对手倒下或失衡 → 建筑沿同一斩线出现结构结果 → 暴雨与坍塌余波继续`

延迟爆发不能新增与平斩不一致的方向。若平台难以稳定生成“入鞘触发延迟破坏”，改为斩击接触当场出现结构裂纹，入鞘只完成声音与余波收束。

## 生成门禁

- 伞在展开、收拢、挂檐和挂链之间必须通过可见手部动作转换；
- 剑和伞的持握、长度、受力与损伤连续，不无因换手、变形或穿体；
- 全程强动态模糊降级为边缘与轨迹模糊，接触点和脚步保持清楚；
- Time Ramp最多用于一次极限闪避或终结读点，不在每镜反复快慢切换；
- “零站桩”解释为没有无功能停顿；临崖入鞘允许主体短暂稳定，但雨、衣袍、电弧、裂纹和坍塌持续运动；
- 场景破坏强度逐级增长，不能在回廊轻击阶段提前达到终结级建筑崩塌。
