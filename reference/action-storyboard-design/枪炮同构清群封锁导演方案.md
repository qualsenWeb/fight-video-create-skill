# 枪炮同构清群封锁导演方案

来源：《长枪清群怪·枪炮同构流连招提示》。适用于长枪与电磁炮、无人机、装甲火力一体化的科幻清群及BOSS封锁。

## 两阶段结构

### 群怪清剿
长枪三段刺扫破开前排 → 枪头切换近距炮膛零距离穿甲 → 枪身展开磁轨远射贯穿纵深 → 肩炮与枪花协同锁敌 → 挑空后胸炮轰落 → 多炮门近距饱和齐射 → 无人机从封线升级为区域覆盖。

### BOSS封锁
兵器格挡和突刺拉开距离 → 电磁桩钉地建立边界 → 烟幕剥夺视野 → 浮游单元持续削盾 → 粘性电磁雷迟滞 → 全域脉冲锁定 → 狙击形态贯穿核心 → 单元与桩体同步收束。

## 武器状态连续性

每次变形写清当前形态、机械展开方向、发射节点、射后状态和恢复方式。已经离舱的无人机、桩体与弹药不得跨镜无因恢复。近战枪术和炮击不能同时占用同一枪头结构，除非资料明确为独立炮门。

## 群战调度

敌群按前排近战、中排补位、远端掩体分层；主角路线先破口、再穿纵深、最后回到中央释放区域火力。无人机承担封线和补射，不替代主角独立完成全部战斗。

## 门禁

仅用于明确科技武器、机甲或机械变形能力。传统长枪武者、低科技古战场和纯写实枪术不使用。
