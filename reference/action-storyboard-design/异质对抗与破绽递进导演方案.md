# 异质对抗与破绽递进导演方案

## 适用边界

适用于双方在体型、武器长度、火力、防护、机动、数量或环境适应性上存在明显差异的战斗。核心不是让弱势方突然提高力量，而是让其改变接触条件，逐步把对手优势拆成可利用的负担。

不适用于完全同构的演武、只展示单方能力、没有反制窗口的处决，或胜负不需要前置条件的短动作。

## 对抗建模

先分别确定双方五项战斗事实：

- **优势距离**：贴身、近距、中距、远距或跨尺度。
- **主要威胁**：速度、覆盖、质量、装甲、控制、数量或环境适应。
- **动作代价**：回收慢、转向大、弹药有限、关节暴露、需要支点、怕被贴身或无法持续输出。
- **可积累状态**：疲劳、伤损、过热、失衡、弹药、武器完整度、视野或行动空间。
- **失败条件**：被逼入边缘、失去武器、核心暴露、无法换气、出口封死或被群体合围。

## 导演脊柱

`优势方先建立不可硬接的威胁 → 弱势方用一次防守确认代价 → 改变距离或进入结构盲区 → 对同一局部连续施压 → 优势方有效反制并造成真实伤损 → 伤损迫使弱势方换策略 → 已累积的局部破坏形成唯一窗口 → 终结动作兑现窗口 → 结果保留双方状态代价`

## 六类异质关系

### 1. 短兵或徒手对长兵重击

- 先让长兵通过枪尖、斧弧、阔刀或巨剑控制外圈，不允许短兵无代价贴近。
- 贴近路径来自偏转兵器头部、抢入回收阶段、贴杆滑入或借障碍缩短有效长度。
- 进入内圈后攻击持握、腕肘、肩线或下盘；长兵方用杆尾、护手、盾撞或身体冲撞重建距离。

### 2. 机动射手对重型追击者

- 射手通过移动射击、地形换位和局部命中维持距离，不在原地持续输出。
- 重型目标用掩体、投掷物、范围横扫或破坏落脚点压缩路线。
- 终结窗口来自同一关节、感知点、持械手或装甲缝的累积损伤，不来自临时出现的弱点。

### 3. 剑盾对双持或大范围兵器

- 盾只承担一次主方向防护，另一方向通过侧步、转盾或贴近斧柄解决；不能同时无代价封住多条攻击线。
- 短剑从盾沿下、持械手外侧或大幅挥击后的空门进入。
- 盾面破裂后必须改变打法，可将残盾用于最后一次偏转、投掷遮挡或弃盾换双手持剑。

### 4. 单人对持续群体

- 目标不是清空无限敌人，而是打开出口、守住节点、取得物品或击倒关键个体。
- 借窄口、障碍和倒地者限制同时接敌数量；当前接触者与下一威胁形成重叠交接。
- 武器卡住、体力下降、伤口扩大和退路缩短共同推动策略变化。

### 5. 普通体型对巨型目标

- 小型角色避开完整质量对撞，沿攻击回收期接近关节、甲缝、感知器官或动力核心。
- 巨型目标每次攻击都重塑环境，同时暴露新的攀附、滑行或遮蔽路径。
- 终结前至少完成“限制一个运动部位—迫使姿态改变—暴露核心或致命结构”两级拆解。

### 6. 近战对柔性束缚

- 柔性攻击必须显示固定端、自由端、缠绕圈和张力方向。
- 防守者优先顺拉力移动减小勒紧，再通过切断、卡柱、反缠、踩压固定端或借回收力接近操控者反制。
- 多条柔性肢体合围时保留可识别间隙；脱困窗口来自不同触手到达时间和路径差，而非无因挣断。

## 节奏与分镜职责

1. **能力差建立**：用完整双人或尺度构图证明为什么不能硬拼。
2. **第一次试错**：让弱势方尝试常规方案并付出代价。
3. **规则识别**：通过动作结果发现回收期、盲区、关节或环境规律。
4. **局部拆解**：连续两到三次行动服务同一破坏目标。
5. **反制回落**：优势方打断节奏，伤损改变弱势方下一步。
6. **窗口兑现**：终结只利用已经建立的缺口。

关键局部接触可用中近景，距离变化、群体路线、巨型覆盖和危险边缘必须回到能读清全身与空间的景别。切换视点时继承人物位置、武器状态、伤损和运动方向。

## 胜负门禁

- 不以“更快、更强”代替策略改变。
- 同一弱点至少被观察或触发一次，再被终结动作利用。
- 受创方不得无因恢复；武器、盾牌、装甲或支点损坏必须持续生效。
- 优势方必须至少完成一次有效反制，证明其威胁真实存在。
- 非致命目标以缴械、制伏、迫退、打开出口或守住节点收束，不强制击杀。
