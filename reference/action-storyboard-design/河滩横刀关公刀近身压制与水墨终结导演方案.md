# 河滩横刀关公刀近身压制与水墨终结导演方案

## 适用边界

适用于开放河滩、浅滩、湿地或泥水荒草地中的一打一古风兵器战，尤其适合轻快单手刀/横刀对重型关公刀、偃月刀或长柄大刀。战斗以贴身攻防和横向追击为主体，一方通过错步与短刀线夺取侧面，另一方用长柄重刃、腿法和击退维持压迫；终局可选择写实破防或超常水墨刀气。

不适用于纯室内、多层建筑追击、无兵器徒手战、双方全程远程对轰或短到只能承载单次动作的镜头。目标不足十秒时，不保留十五镜结构，只取“入场突进—一轮压制反转—破防结果”。

## 冲突裁决

原资料同时写有“零站桩无蓄力、全程近身无隔空对波”和后段“悬空聚气、巨型剑气远程命中”。入库后分成两个阶段：

1. **近身主战阶段**：不站桩、不远程对波；动作由攻防、击退和追击持续连接；
2. **超常终结阶段**：只有角色明确具备刀气能力且用户接受短促聚势时才启用。聚势不是全局规则，需由前一记破防与拉开的空间窗口成立。

写实任务删除悬空、劈云和数米沟壑，把终结改成破防鞭腿、交错斩或逼退收刀。

## 导演脊柱

`斗笠遮面入场 → 甩笠与拔刀共用一次动作触发突进 → 荒草遮挡后第一次重接触 → 重刀击退与贴身追击 → 倒飞卸力后贴地反攻 → 泥水区高低位与圆弧走位换权 → 破绽逼退与四刀破防 → 鞭腿击飞建立终结窗口 → 条件化水墨刀气终结 → 收刀、接笠、戴笠完成首尾闭环`

斗笠不是装饰：甩出时负责遮挡转场和启动突进，结尾回收时负责验证空间连续性与人物控制力。若模型难以维持飞行道具跨多镜连续，可改为斗笠落在固定锚点，结尾由角色步行拾回，不强行回旋飞返。

## 双兵器关系

- **横刀手**：主战近距，以低重心突进、错步绕侧、贴地反撩、短链压线和快速回收制造节奏；
- **关公刀手**：主战中距，以横扫、下劈、刀杆/刀背截线和腿法连接制造重量与击退；
- 横刀手不能在重刃完整发力区持续硬架，应通过偏转、卸力、滑步或切入柄侧减小力矩；
- 关公刀手被贴近后，用转髋、缩柄、刀杆横截、膝撞或侧踹重新夺回中距，不无因原地挥满圆；
- 腿法只在兵器已经牵制对方上肢或线路时进入，避免兵器与踢击同时各演各的。

## 泥水压力链

### 1. 首次破局

从荒草前景后冲出，横刀沿低位圆弧斜取肩线；重刀横架后顺旋身反扫。镜头用低位中全景侧跟，草叶在接触前退出核心构图。第一次重接触建立两种武器的重量差，不需要连续插入多次冲击帧。

### 2. 击退与追击

关公刀横扫牵制横刀后接侧踹，逼对手沿湿泥滑退；横刀手竖刀和前臂共同管理武器线，躯干承受踢击后后撤卸力。关公刀手追进下劈，形成“击退不是休息，而是下一轮追击的空间来源”。

### 3. 贴地反攻

横刀手由倒飞或后滑末态翻身落地，借湿地继续卸力，再从低位反撩下盘；关公刀手抬步避刃并用重刃砸地封路线。滑铲、贴地斩和砸地只选择一项作为主动作，镜头贴地但必须保留两人脚步与武器落点。

### 4. 换权升级

以膝撞、斜劈、竖架、错步绕侧形成一次攻防权交换；随后用圆弧走位和三次轻接触调节距离。这里承担呼吸功能，碰撞表现应轻于前后重击，避免全段同强度。

### 5. 破绽与破防

重刀旋转过度或回收过慢暴露腰侧/中门，横刀手以不超过三动作的短链逼退，再用四刀节奏中的最后一刀压开兵器。所谓“双臂震麻”仅写成短时握持不稳、肩线下沉或武器线偏移，不使用伪医学描述。

### 6. 踢击与终结窗口

横刀手在对方兵器被压开的完成态沉腰旋身，以鞭腿或蹬踢击中躯干防护区。慢动作只覆盖接触与初始形变，随即回到正常速度显示被击飞轨迹和地面反馈。该击飞为后续收刀、追斩或超常刀气提供距离，不自动决定死亡结局。

## 镜头策略

- 入场可用贴地旋升表现服装、刀鞘和眼神，但只在角色尚未交战时使用复合运动；
- 甩笠时先短跟飞行物，再回拉揭示拔刀突进，两个动作按触发先后接力，不能同时无因推拉；
- 复杂连招用双人中景或中全景平行跟拍，碰撞瞬间稳定，反馈之后才短甩或后撤；
- 贴地鱼眼只服务一次重击或压迫构图，不作为全段固定畸变；
- 螺旋环绕只用于动作密度较低的圆弧周旋，四刀破防期间改用稳定侧跟；
- 慢动作只服务鞭腿接触或唯一终结接触，不能与抽帧、全屏负片和剧烈震镜同时堆叠；
- 宏观刀气若启用，切至高空全景前先建立刀气起源、目标位置和攻击轴，后撤以容纳结果为目的。

## 碰撞与水墨表现

- 轻接触：金属擦响、刃口偏转、小量墨点或火星、脚下涟漪；
- 重接触：先显示手腕、肩线、兵器和脚步受力，再选择一次局部冲击帧、镜头回弹或泥水爆开；
- 终结爆发：全屏闪白、鱼眼或大范围冲击波最多选择少数组合，只服务唯一终结；
- 黑色与赤红水墨分别绑定角色和武器，离开接触界面后恢复清楚归属；
- 全程强动态模糊、每次碰撞固定抽帧和负片属于原案例参数，不作为本方案硬规则。

## 生成门禁

- 唐横刀始终从明确刀鞘位置拔出并回到同一鞘位；关公刀的柄长、握点和刀头朝向跨镜连续；
- 斗笠甩出方向、离画位置和回收路径一致，头戴状态不能中途恢复；
- 每次倒飞、滑退、蹬地和击飞都在泥水表面留下连续痕迹；
- 角色不可悬空等待；若启用超常悬停，必须有明确能力表现并限于终结短段；
- 破防来自前文对兵器线和重心的压制，终结不得无因跳过对手防守；
- 最后一帧保留雨丝、草絮、泥沙、积水回流、衣摆或斗笠余动中的至少一层运动。
