# 控制僵直型擒杀连段导演方案

来源：《30秒擒杀连段》。用于处决型、控制型或实力悬殊战斗，不作为势均力敌对决默认协议。

## 因果骨架

突进近身 → 控肩颈建立僵直 → 膝撞确认控制 → 借控制点腾空连击 → 重踹砸地 → 俯冲追打 → 二次提起 → 控制式终结。

## 控制连续性

- 控制点必须可见：肩颈、手臂、腰胯或腿部，不能只写“锁住”。
- 每次腾空和换向都说明抓控点是否保留、转移或短时释放。
- 被控者的躯干回弹、脚部离地、旋转方向和落点服从施力方向。
- 砸地后追击者必须继承下坠动量，不能切镜后重新站立起招。

## 分段职责

1. 建立：近身扣锁和第一次短击证明优势。
2. 空中：后旋重踢、横踹、交替侧踢或双腿锁夹改变高度。
3. 地面：砸落后以扫踢、侧踹或膝击阻止恢复。
4. 再控制：抓起或借反弹重返空域，但只保留一次二次抛空。
5. 终结：利用已建立的朝向和控制线完成单腿重蹬、摔落或投掷。

## 门禁

只有用户明确要求处决、僵直、木桩压制或实力悬殊时，才允许被控者长期无法反击。势均力敌时必须给被控者一次挣脱、护架、转髋卸力或落地反制窗口。禁止颈部危险动作被描写成教学建议。
