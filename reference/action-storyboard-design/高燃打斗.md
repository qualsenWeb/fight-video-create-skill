# 通用高燃打斗提示词模板

把创意转换为可供不同视频生成模型理解的高密度打斗契约。目标不是堆叠“电影级、顶级、震撼”等形容词，而是让镜头有明确观察位置和运动目的，让角色在清楚的空间内持续交战，每次攻击都有防守、受力、环境反馈和可见终点。最终提示词应根据目标模型支持的时长、输入素材、提示词长度和控制能力进行适配，不绑定特定平台或模型语法。

## 核心承诺

生成结果必须同时满足：

1. **持续交战**：开场已经在打，结尾仍有惯性余波；不热身、不对视、不摆胜利姿势。
2. **快而可读**：速度来自短动作链、运动轨迹、背景相对运动和冲击帧，不靠全屏模糊或复制残影。
3. **空间清楚**：全程围绕三个空间锚点换位，人物始终在画面内，不跑散。
4. **攻防成对**：每个攻击都对应闪避、格挡、卸力或反击，并显示身体受力。
5. **物理闭环**：蓄力/接触 → 反作用力 → 脚步或身体位移 → 地面、衣料、兵器或环境反馈。
6. **终结不静止**：最后一击以滑停、震颤、碎屑、扩散冲击波或衣袍回落结束，不以 pose 结束。
7. **镜头有因果**：每个镜头先确定景别、机位和观察轴，再定义由人物动作触发的单一主运镜与明确终点；运镜不得抢动作或丢失接触点。

## 适用边界

使用本模板：

- 适合目标模型单次生成时长的近身兵器战、拳脚战或能力型终结战。
- 单条高密度打斗，或长序列中可独立生成并连续衔接的一个片段。
- 支持纯文本、图生视频、参考视频、首尾帧或视频延续等输入方式；仅使用目标模型实际具备的能力。
- 二维水墨动画、赛璐璐动画、写实电影、3D 动画等媒介。

不要直接使用本模板：

- 大规模战争全景、多人军团调度。
- 以对白、情绪表演或产品展示为主的镜头。
- 需要一条提示词承载超出目标模型稳定生成能力的完整故事。此类需求应拆为多个具有明确交接状态的连续片段。

## 工作流程

### 1. 建立最小制作简报

从用户输入提取下列变量。已有信息不得重复询问；缺失项可采用默认值：

| 变量 | 含义 | 默认值 |
|---|---|---|
| `duration` | 生成时长 | 10 秒 |
| `aspect_ratio` | 画面比例 | 16:9 |
| `medium` | 二维动画/写实/3D | 根据参考图判断 |
| `style_lock` | 美术技法、色盘、环境质感 | 沿用用户参考 |
| `fighter_a` / `fighter_b` | 外形、武器、屏幕方向 | A 左→右，B 右→左 |
| `anchor_left` | 左侧空间锚点 | 环境中的大型固定物 |
| `anchor_center` | 中央交战锚点 | 开阔交锋区域 |
| `anchor_right` | 右侧空间锚点 | 高差、出口或障碍 |
| `shot_structure` | 单镜头/分阶段长镜头/多镜头 | 分阶段连续镜头 |
| `camera_axis` | A/B交战轴与越轴规则 | A左B右，不越轴 |
| `shot_scale_arc` | 景别变化 | 全景→双人中景→全景结果 |
| `camera_motion_arc` | 主运镜的起点、触发与终点 | 跟随→侧移→后撤 |
| `outcome` | 最终结果 | 胜负强烈暗示，不血腥 |
| `audio_policy` | 声音策略 | 同期音效，无配乐 |

若三个锚点未给出，从场景中选择彼此可区分、不会移动的三个位置。锚点必须能用“左侧/中央/右侧”或“前景/中景/后景”清楚描述。

用户未指定镜头时，不可直接套用“推拉摇移环绕”。先根据动作任务选择景别和机位，再选择最少且最有效的运动。默认保持A在画面左侧、B在画面右侧；只有通过正俯拍、中性正面或明确遮挡转场重新建立方向，才允许越轴。

### 2. 选择输入与生成方式

先确认目标模型实际支持的输入类型，再采用对应写法：

- **纯文本生成I2V**：提示词需完整说明角色、场景、美术、动作、镜头与声音。
- **参考图生成R2V**：参考图负责已呈现的角色、构图或美术；提示词重点补充运动、节奏、受力、声音和保持项，避免重复描绘导致漂移。
- **参考视频生成**：逐项声明每份素材的职责，例如“`[动作参考视频]`只参考攻防节奏，不继承人物、服装、场景和美术”；若另有运镜参考，则由`[运镜参考视频]`单独负责景别、机位、运动节奏和镜头终点。
- **首尾帧生成**：`[首帧图]`定义起点，`[尾帧图]`定义终点；提示词只描述两者之间可连续完成的动作、位移与镜头变化。
- **视频延续**：以已验收视频的真实尾帧、人物位置、镜头状态和运动方向为起点，不以计划中的尾帧为起点。

素材引用标记必须替换为目标平台的实际语法；若平台不支持某种输入方式，则降级为其可执行的纯文本描述，不虚构控制能力。

一份参考素材只承担一个主要职责。动作参考与运镜参考优先拆分，不得让同一素材同时控制人物身份、动作、镜头、场景、美术和声音。

### 3. 锁定媒介语法

#### 手绘二维、水墨或赛璐璐

第一句明确媒介，例如：

> 原创手绘二维国风水墨动作动画，宣纸底、焦墨干笔、飞白线条、有限色。

使用动画制作语言：

- 二拍一用于蓄势、步法和回收。
- 一拍一仅用于突进、连击和终结。
- 涂抹帧表现挥击弧线。
- 单张高反差冲击帧表现关键命中。
- 背景横向卷动、多层视差和速度线表现超高速。
- 身体停止后，头发、衣摆、尘沙和兵器继续回落或震颤。
- 用画稿横移、纵向摇移、布局推近、背景急拉和多层视差表达二维“运镜”；每个动作阶段只使用一种主要画面运动。

二维提示词可以使用全景、双人中景、近景、低位、侧面、俯视等构图词，但不得使用焦距、镜头型号、景深、光圈、传感器、真实快门等摄影参数，以免漂移成真人或伪 3D。

#### 写实或三维

可以使用低机位追拍、侧向跟拍、快速后撤、短促甩镜等摄影语言。先选能读清攻防的景别和机位，再选运动方式；每个时间段只保留一个主要运镜。运动模糊只用于边缘和轨迹，人物轮廓与兵器接触点必须可读。复杂连击期间优先稳定侧向跟拍，不使用360度环绕；环绕只用于动作密度较低、地理关系已经建立的短阶段。

### 4. 编排十秒动作脊柱

默认使用六段式脊柱。它是因果结构，不要求机械地逐秒写满：

1. **0–1 秒｜直接入战**
   两人已在中央锚点交战；用一次明确碰撞建立速度、方向和重量。

2. **1–3 秒｜压迫链**
   进攻方完成三招以内的短链；防守方贴身闪避/格挡并借环境反弹回中央。

3. **3–5 秒｜换位链**
   围绕中央与一个侧锚点高速换位。每次移动都由攻击导致，不做无目的跑位。

4. **5–7 秒｜环境反作用**
   一方被压至侧锚点，利用墙面、坡面、残骸或地形反蹬；回到中央完成升级碰撞。

5. **7–9 秒｜终结与反转**
   一方发动不超过四动作的终结链，另一方连续化解并抓住唯一空隙反击。

6. **9–10 秒｜交错结果**
   双方完成一次交错终击；用滑停、震颤、破损、碎屑和扩散冲击波暗示胜负，不停下摆 pose。

若时长不是 10 秒，按比例压缩或扩展阶段，但不要通过增加招式填满时长。4–6 秒只保留“直接入战 → 压迫/反转 → 交错结果”三段。

### 5. 编写动作链

每个时间段遵循：

`攻击目的 → 身体与武器动作 → 对手响应 → 接触反馈 → 位移结果 → 环境余波`

示例：

> A 贴地横切逼 B 离开右侧斜坡；B 竖刃格挡，前臂被震开后立即回收；两人脚下沙地向外爆裂，B 向后滑移半步但仍留在近身距离。

规则：

- 一条短链最多 3–4 个动作。
- 招式必须能由前一个动作的重心和惯性自然进入。
- 武器不得无原因脱手、变形或穿透。
- 角色受到冲击后必须出现手腕偏转、肩线下沉、脚步滑移、躯干回弹等至少一种反馈。
- 环境特效必须由动作触发，不可独立抢戏。
- 能量效果不得遮蔽人物超过关键接触瞬间。

### 6. 先建立镜头契约

镜头不是动作之后附加的装饰。每个阶段在写招式前先填写：

`叙事目的 → 景别 → 机位/观察角度 → A/B画面位置 → 主运镜 → 动作触发点 → 镜头终点 → 下一阶段交接状态`

示例：

> 显示B把A逼离右侧锚点 → 双人中景 → 交战轴侧面低位 → A左B右 → 向左平行跟随 → B第一记横切时启动 → 在中央锚点停住并保留两人全身 → 下一阶段从A踩住残骸开始。

镜头契约必须包含：

- **观察轴**：明确A/B左右关系。默认不越过交战轴。
- **安全构图**：复杂动作保持双人中景或全景，并在运动方向前方保留空间。
- **启动原因**：人物冲刺、被击退、跃起或冲击波扩张触发镜头运动。
- **运动终点**：落在下一个锚点、关键接触构图或结果构图，不写无终点的“持续环绕”。
- **交接状态**：记录人物位置、运动方向、镜头高度和运动是否仍在继续。

### 7. 选择景别、机位和运动

| 动作任务 | 推荐景别 | 推荐机位 | 首选运动 | 目的 |
|---|---|---|---|---|
| 建立三锚点与屏幕方向 | 双人全景/大全景 | 侧面或低位三分之四 | 短跟随或二维背景平移 | 让观众先看懂空间 |
| 高速压迫链 | 双人中景 | 交战轴侧面 | 平行跟随 | 同时看清攻防与脚步 |
| 单次关键命中 | 双人中近景 | 接触点一侧 | 短促推近或保持构图 | 强调接触和受力 |
| 高低差、跃起或坠落 | 全景 | 低位仰视/高位俯视 | 垂直跟随或画稿纵移 | 交代高度和落点 |
| 环境反蹬与回中心 | 双人全景 | 侧后方三分之四 | 背后短追后转侧跟 | 显示借力路径 |
| 能量对撞与冲击扩张 | 全景 | 正面或斜侧 | 快速后撤/背景急拉 | 容纳冲击范围 |
| 终结交错与惯性结果 | 双人中景转全景 | 保持原轴 | 跟过交错点后减速 | 不以pose结束 |

执行规则：

1. **一阶段一主运镜**：一个阶段只允许一种主要运动；短促构图修正不算第二运镜。
2. **动作越复杂，镜头越简单**：三至四动作连击使用平行跟随或稳定双人构图，不叠加环绕、推拉和甩镜。
3. **先看见再加速**：开场先用0.3–0.8秒建立A/B方向和锚点，再进入高速；若首帧已经建立空间，可直接加速。
4. **接触时稳定**：关键命中前完成大幅运镜，碰撞瞬间保持接触点可读；冲击后再后撤或甩向结果。
5. **近景有时限**：近景只用于一个明确接触或表情反应，通常不超过0.5秒；复杂连招不得长期使用近景。
6. **剪切落在完成态**：多镜头结构在格挡完成、落地、撞击或遮挡后切，不在武器尚未接触时切断动作。
7. **越轴必须重建**
