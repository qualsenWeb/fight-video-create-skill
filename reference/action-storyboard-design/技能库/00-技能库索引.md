# 技能库索引

技能库收录无法满足招式库入库条件、但具备独立“前置条件 → 发动 → 作用 → 终止”机制的能力。检索入口为 `00-路由元.json`。

## 使用顺序

1. 先检索招式库；能转换为具体武学、兵器技法、身体路径或连续招式的内容，必须进入招式库。
2. 招式库没有可用候选时，才以“单体”或“群体”检索技能库。
3. 特殊法器、身体部位、介质、状态和控制接口属于二级前置条件，不参与自动匹配。
4. 选中技能后必须展示二级前置条件；条件不满足时，只能创造合理条件、采用文件给出的替代条件，或放弃该技能。
5. 技能库只提供能力机制，不替代招式、动作路径、接触反馈和分镜因果。

## 与招式库的边界

- 飞剑、剑阵、水刃剑气、法相、投掷法器、巨兵器、骨伞、双链及具体拳腿兵器链，均优先使用招式库。
- 技能中出现武器、法器或身体部位，只表示发动条件或能力载体；一旦内容重点变为具体持握、挥击、接触、位移或连招，就应转入招式库。
- 同一来源可以分别提炼招式和技能，但不得在两个库重复保存同一机制。技能条目必须写明其招式库排除项。
