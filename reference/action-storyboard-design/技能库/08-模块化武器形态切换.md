# 模块化武器形态切换

## 来源与入库判定

- 来源：`reference/action-storyboard-design/枪炮同构清群封锁导演方案.md`，并由 `reference/example-scripts/多兵器腿法与玄幻战斗十四文档结构案例集.md` 的案例 L 交叉验证。
- 证据：同一长枪在近战、近炮、磁轨远射和狙击形态间切换，每次都需交代展开方向、发射节点、射后状态和恢复方式。
- 入库理由：核心是复合装备的互斥形态管理与状态连续性，不是一套固定枪法或射击连招。

## 检索与条件

- 一级检索词：**单体、群体**。
- 二级前置条件（不参与匹配）：持有具备机械、法术或模块化变形结构的复合武器；形态清单、转换耗时、占用部件、弹药或能量来源明确。
- 选中提醒：必须先确认武器确实可变形，并列出当前形态、目标形态、展开方向、可用功能和恢复方式；普通兵器不能直接套用。
- 条件不足时：可创造模块化枪体、机械臂、可插拔炮门或多形态法器；若设定只允许单一固定武器，则放弃采用。

## 能力机制

1. 武器从当前形态解除占用并开始可见转换。
2. 部件沿明确方向展开、折叠、滑移或重组，形成新发射/作用节点。
3. 新形态只执行其被定义的职责；互斥形态不能同时占用同一结构。
4. 射后、受损、过热或能量耗尽会改变可用形态；复位必须显示恢复过程。

## 适用边界与用途

- 适合科技、机甲、机关术或模块法器世界观，可服务单体决斗和群体清场。
- 镜头以结构特写说明转换，再用景别变化展示功能距离改变；状态切换可作为战斗阶段转折。
- 不得跨镜无因恢复弹药、无人机或已损坏部件。

## 招式库互斥

- 长枪刺、扫、挑、枪托击等身体路径使用招式库 `21-破穹长枪连击专项.md` 或相应兵器资料。
- 投掷变轨法器使用招式库 `10-投掷法器追杀回收专项.md`；本条只保存同一装备的功能形态切换。
