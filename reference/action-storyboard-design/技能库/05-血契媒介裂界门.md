# 血契媒介裂界门

## 来源与入库判定

- 来源：`reference/example-scripts/赤紫天地开界神剑降临二十五秒即梦案例.md` 的第三段。
- 证据：角色咬破手指、以血划扇激活血纹，裂界从媒介后方逐步形成，先有少量妖兽探出，再扩展为大规模破界。
- 入库理由：核心是血契激活空间通道并承载群体通过；法器只作固定仪式媒介，不承担投掷追杀招式。

## 检索与条件

- 一级检索词：**群体**。
- 二级前置条件（不参与匹配）：施术者可提供血液或等价生命印记；持有能承载契约的法器、符印、祭坛或身体纹章；具备开界权限和安全落点。
- 选中提醒：必须确认献血代价、媒介状态、裂界位置、通向何处以及可通过的对象范围。
- 条件不足时：可创造预先签订的血契、祭坛印记、权杖、面具或身体纹章；不能合理建立契约媒介与空间权限时放弃采用。

## 能力机制

1. 以可见生命印记激活固定媒介，媒介出现持续契约状态。
2. 裂点从媒介附近产生并逐步扩张为稳定通道。
3. 先由少量目标试探通过，再按通道尺度增加通过数量和体量。
4. 契约耗尽、媒介损坏、施术者失去意识或通道主动闭合时终止；已通过目标不会随门关闭而无因消失。

## 适用边界与用途

- 适合异界入侵、召入援军、妖潮来源揭示和群体威胁升级。
- 镜头以取血和媒介近景建立代价，再后拉读取裂点扩张、试探目标和群体涌出。
- 不作为任意瞬移捷径；必须维护入口、出口、容量和闭合状态。

## 招式库互斥

- 法器脱手、变轨追杀和回收使用招式库 `10-投掷法器追杀回收专项.md`。
- 裂谷承接巨兵器、插地二沉、大地开界和群体吸落使用招式库 `11-天地开界巨兵器专项.md`；本条只保留血契开门与群体通过。
