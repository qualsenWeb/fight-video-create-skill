# 柔性附属肢体惯性配重

## 来源与入库判定

- 来源：`reference/example-scripts/青灵御水者与赤狐妖灵暴雨悬空古刹对决案例.md`。
- 证据：案例明确要求狐尾承担配重、扫击或改线，并以狐尾惯性解释湿滑屋顶和回廊间的高速折返。
- 入库理由：能力依赖特殊身体结构产生惯性和姿态控制，不是一套可供普通人体直接学习的招式。

## 检索与条件

- 一级检索词：**单体**。
- 二级前置条件（不参与匹配）：角色具有真实连接躯干、有明确长度、质量和活动范围的尾部或等效柔性附属肢体；腰胯能够控制其摆向。
- 选中提醒：必须先确认附属肢体存在、没有被束缚或受伤，并为其预留摆动空间。
- 条件不足时：可合理创造尾状机械组件、具备承力结构的长披帛或其他有质量的柔性附属物；普通衣摆、无质量光带不满足条件，无法建立时放弃采用。

## 能力机制

1. 躯干转向或落脚前，附属肢体因惯性产生滞后摆动。
2. 腰胯主动改变摆向，使附属肢体承担反向配重、侧向牵引或落地稳定。
3. 配重结果改变角色的转弯半径、身体朝向、落点或失衡恢复。
4. 附属肢体受控、缠住、超出关节活动范围或没有摆动空间时，能力失效。

## 适用边界与用途

- 适合湿滑地面、窄梁、屋脊、回廊、高低差和高速变向。
- 镜头应同时保留腰胯、支撑脚、附属肢体弧线和落点；用尾端擦地、水花或尘迹说明惯性方向。
- 不得把附属肢体无限伸长、无质量漂浮，或用它替代普通角色的完整身法训练。

## 招式库互斥

- 尾击、缠绕、抽打等具体攻击路径若可形成独立动作链，应优先整理为招式库资料。
- 本条只保存附属肢体作为身体结构参与配重、改线和恢复的能力机制。
