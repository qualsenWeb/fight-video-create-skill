# 动势蓄能

## 来源与入库判定

- 来源：`reference/action-storyboard-design/一镜到底剑腿混合防反终结导演方案.md`。
- 证据：方案要求聚能只能发生在飞升、旋身、追近、牵引或换位中，禁止站桩发光。
- 入库理由：核心是将连续有效位移转化为可储存、可中断、可消耗的强化状态，不依赖某种具体招式。

## 检索与条件

- 一级检索词：**单体**。
- 二级前置条件（不参与匹配）：角色具备储能身体、能量回路或装备；存在可持续的有效位移；明确蓄能上限、中断条件和释放节点。
- 选中提醒：必须先定义什么动作能充能、如何显示充能增长、何时中断、最终消耗到什么能力。
- 条件不足时：可创造充能纹路、惯性发电模块、呼吸循环或“完成规定距离/有效换位次数后充满”的规则；若只是普通跑动、没有状态增长与消耗，则放弃采用。

## 能力机制

1. 角色以追近、升降、旋身、牵引或空间换位开始积累动势。
2. 每次有效位移增加可见储能状态；原地摆动和无结果动作不计入。
3. 停滞、失衡、受控或回路受损会降低或清空储能。
4. 达到阈值后只强化一次明确能力，释放后回落，不无限叠加。

## 适用边界与用途

- 适合追逐、长镜头、立体换层和需要把大招前摇并入动作过程的单体战斗。
- 镜头用轨迹亮度、气流、装甲纹路或环境扰动递增表现储能，不用静态发光代替位移。
- 不把身法本身、普通奔跑或镜头运动算作技能效果。

## 招式库互斥

- 具体轻功、步法、腿法或兵器旋动如何执行，优先使用招式库相应资料。
- 本条只规定“有效动势转化为强化状态”的能力规则，不保存任何固定连招。
