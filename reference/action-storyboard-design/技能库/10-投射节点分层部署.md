# 投射节点分层部署

## 来源与入库判定

- 来源：`reference/example-scripts/黑紫骷髅鱼群天幕水墨清群案例.md`。
- 证据：黑紫铭文天幕被定义为第二阶段发射与分层节点，向空中、中层和地面投下既有骷髅群，但不替代群体自身路径。
- 入库理由：核心是预先建立节点，再把既有单位分配到多个空间层；它不是具体召唤物的攻击招式。

## 检索与条件

- 一级检索词：**群体**。
- 二级前置条件（不参与匹配）：场中已有可持续追踪的天幕、门阵、穹顶或节点网络；存在可部署的单位存量；节点与目标高度层之间有明确投射路径。
- 选中提醒：必须先建立节点位置、单位来源、投射容量和各层职责；节点不能凭空生成无限单位。
- 条件不足时：可创造预置符阵、浮空投放平台、传送门网络或载具投放点；没有单位库存或稳定节点时放弃采用。

## 能力机制

1. 先展开并稳定一个或多个投射节点。
2. 将既有单位按目标、方位和高度层分配到不同节点。
3. 节点依次或并行完成投射，形成高空、中层、地面等多层部署。
4. 节点损坏、容量耗尽、控制中断或单位库存清空时终止；已部署单位继续遵循自身运动规则。

## 适用边界与用途

- 适合大规模围剿、守城增援、地空分层和宏观战场升级。
- 镜头先拍节点亮起，再沿投射路径向目标层运动，最后用俯拍同时读取不同层的数量与方向。
- 不适合单体决斗、狭窄空间或只需一次单点攻击的镜头。

## 招式库互斥

- 若节点部署的是飞剑、剑雨或万剑剑潮，优先使用招式库 `07-万剑诀雷域箭雨专项.md`。
- 实体群在部署后的偏航、疏密与重组可使用技能库 `03-实体群指令编队.md`；节点只负责投射与分层，不重复保存编队机制。
