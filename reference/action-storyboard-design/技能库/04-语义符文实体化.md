# 语义符文实体化

## 来源与入库判定

- 来源：`reference/example-scripts/浩然正气经文光墙镇魔三十秒案例.md`。
- 证据：案例由诵读展开经文光墙，再将“鼎”“锁”等文字逐笔拆解、重组并增长为承担不同职责的实体。
- 入库理由：发动接口和能力变化来自语义文字的结构转换，不是具体武器招式或普通能量弹。

## 检索与条件

- 一级检索词：**群体**。
- 二级前置条件（不参与匹配）：角色具备诵读、发声、结印或书写接口；场中存在可见且有语义的文字、符文、图腾或几何符号载体；每种符号的功能可解释。
- 选中提醒：必须展示“载体出现 → 笔画/结构拆解 → 重组 → 实体增长 → 功能生效”，不能直接跳出完成体。
- 条件不足时：可创造经卷、碑文、符纸、法典、投影界面或预置符号阵列；若世界观不允许语义符号生效，则放弃采用。

## 能力机制

1. 通过声音、书写、手势或注视激活语义载体。
2. 指定符号从载体剥离，并保留可读的结构变化。
3. 符号重组为与语义职责一致的实体，如屏障、镇压体、束缚结构或净化区。
4. 实体完成一次职责后回归符号、碎解或耗散；施术中断、语义载体损坏或权限失效即终止。

## 适用边界与用途

- 适合守城、仪式战、分区控场、净化和需要文化符号辨识度的群战。
- 镜头先拍口型、手势或书写触发，再从平面符号跟到立体增长；多种符号必须分区、分时承担不同职责。
- 不得让文字只作为装饰字幕，也不得将普通无来源光束称为文字化形。

## 招式库互斥

- “锁”字形成的链条若重点变为双链锚定、张力借力和交绞动作，改用招式库 `26-双链锚定与双属性协同专项.md`。
- 由兵器挥动产生的符术攻击路径属于对应兵器招式资料；本条只保存语义载体的结构转化能力。
