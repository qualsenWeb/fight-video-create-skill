# 实体群指令编队

## 来源与入库判定

- 来源：`reference/example-scripts/黑紫骷髅鱼群天幕水墨清群案例.md`。
- 证据：案例由手势、视线和下压动作统一改变骷髅群的 S 形偏航、疏密和高度层，并要求群体不能跨段无因重生。
- 入库理由：核心是对既有可控实体群发布编队指令，不是单个实体的具体攻击招式。

## 检索与条件

- 一级检索词：**群体**。
- 二级前置条件（不参与匹配）：场内已存在一批同类可控实体；施术者与实体群之间有视线、手势、精神、信号或等效指令接口；可持续追踪单位数量和损耗。
- 选中提醒：必须明确实体群来源、指令接口、当前存量以及指令变化如何传到群体。
- 条件不足时：可预先布置傀儡、骨片、纸偶、机械单元或召入一批已受控实体；若只有临时光效、无法证明单位受控，则放弃采用。

## 能力机制

1. 已存在的实体群接收统一方向和基础队形。
2. 控制者通过一次可见指令改变疏密、偏航、前中尾厚度或高度层。
3. 群体以补位、分流、回收或重组维持队形，损毁单位不无因恢复。
4. 控制者失去指令接口、实体离开作用范围或群体存量耗尽时终止。

## 适用边界与用途

- 适合开阔空域、大规模清群、包抄、合围和阵形压迫。
- 镜头用控制者指令特写建立因，再切超广角读取群体方向与厚度，最后跟入一条前锋线确认结果。
- 不适合单体决斗，也不能把普通敌群调度误写成超自然控制能力。

## 招式库互斥

- 若受控实体为飞剑、剑阵或万剑剑潮，优先使用招式库 `07-万剑诀雷域箭雨专项.md`。
- 单个投掷法器的变轨追杀与回收使用招式库 `10-投掷法器追杀回收专项.md`。
