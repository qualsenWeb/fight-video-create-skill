# 核心化封闭能量壳

## 来源与入库判定

- 来源：`reference/example-scripts/仙侠快速拼招加大招.txt` 第三、第四段。
- 证据：案例要求能量从全身回流，角色始终位于完整闭合雷暴球几何中心，并由外壳先承担接触、受压和崩解。
- 入库理由：核心是角色与闭合能量壳的空间、受力和存亡关系，不是护盾格挡招式或兵器技法。

## 检索与条件

- 一级检索词：**单体**。
- 二级前置条件（不参与匹配）：角色可将大范围能量向全身回流并压缩；具备稳定核心状态和足够开放空间；能够承担壳体破裂后的反噬或代价。
- 选中提醒：必须明确角色位于壳体内部核心，外壳先接触目标；同时说明成壳时间、维持消耗和破壳后果。
- 条件不足时：可创造储能核心、全身导流纹路或外部供能源；若角色只能形成贴身护盾、无法维持闭合结构或空间不足，则放弃采用。

## 能力机制

1. 外放能量向角色身体或核心节点回流、压缩。
2. 形成具有完整边界的闭合壳体，角色固定在内部核心而非表面。
3. 壳体作为整体移动、承受碰撞或压迫，接触顺序始终为外壳先、核心后。
4. 壳体受损必须连续表现凹陷、裂解、泄能或坍缩；主动解除、能量耗尽或核心失稳时终止。

## 适用边界与用途

- 适合单体宏观对撞、不可逆终局、牺牲或以防御体承担冲击的战斗。
- 镜头先近景读取回流，再高速后拉揭示闭合边界与核心位置；碰撞时保留壳体形变和内部后果。
- 不适合狭窄近身格斗，也不等同于普通贴身护盾、雷网或人物带头冲撞。

## 招式库互斥

- 兵器挥击、格挡和反击动作仍使用招式库。
- 巨型法相或独立能量实体的抓控摔投使用招式库 `09-巨型法相擒摔专项.md`；本条的壳体没有独立肢体和自主动作。
