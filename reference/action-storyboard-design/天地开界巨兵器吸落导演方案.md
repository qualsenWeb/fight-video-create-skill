# 天地开界巨兵器吸落导演方案

## 适用边界

适用于天象级巨兵器由既有裂谷或能量通道降临，命中关键目标后继续改变地层，并以开界、吸落或封闭作为宏观终结。适合开放雪原、荒原、山海等有足够尺度锚点的环境。

## 分段因果

`前段天穹开裂并稳定敞开 → 后段巨兵器从裂谷内沿同一轴线降临 → 锁定关键目标并命中 → 插地/二次沉降 → 地层裂纹扩展 → 两侧地层真实分离 → 异界内部显露 → 吸流拉动残余目标 → 地层闭合与余波收束`

巨兵器、裂谷和界门不是三个无关大招。每一步的末态必须提供下一步的空间条件与能量来源。

## 宏观尺度与镜头

- 建立镜头至少包含普通目标、山岳级目标、巨兵器/裂谷三类尺度锚点。
- 巨兵器在远景保持与山岳级目标显著不对等的体量；不得缩成普通巨剑、细光柱或抽象光效。
- 关键命中使用极短冲击帧，不替代前后的完整接近、接触和后果。
- 地层开界以远距广角完整呈现“裂纹贯穿—断层抬升—两侧分离—开口扩大”，禁止瞬切小洞或圆形传送门。
- 吸落时先让小型目标滑动、腾空，再给重型目标犁地、抓附、后仰和最终失稳，体现重量差。

## 角色安全与收束

在巨兵器、地层或吸流主导的阶段，非必要角色退出危险区或明确保持安全高度；被关键命中的角色不得无因重返。终结后必须交代巨兵器、界门、吸流和环境的收束状态，避免角色在已闭合地层中穿模出现。

## 门禁

检查裂谷与巨兵器是否跨段承接、尺度是否可见、环境是否连续受损、目标是否有重量反馈、镜头是否保持同一宏观观察关系，以及终结是否只保留一个主要结果。
