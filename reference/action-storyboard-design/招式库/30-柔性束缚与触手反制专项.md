# 柔性束缚与触手反制专项

## 来源与使用边界

- 来源：用户提供的忍者、古墓与深海题材战斗资料之动作设计层。
- 用途：处理钢丝、绳索、绷带、锁链或触手的缠绕、绊锁、拖拽与脱困。
- 本条描述实体柔性结构的动作链；无质量、无固定端或不受张力约束的效果不适用。

## 四项状态

每条柔性结构必须保持：

1. 固定端或操控端位置；
2. 自由端运动方向；
3. 与目标的缠绕圈数和接触部位；
4. 当前张力、松弛段与断裂状态。

## 主动控制链

### 1. 支点挂接—摆荡换位

`抛出自由端绕过檐角/栏杆/桅杆 → 收紧确认承力 → 角色蹬离原位 → 沿绳弧越过对手攻击线 → 接近弧线最低点时释放或缩短 → 落向对手侧后`

支点必须能承受角色质量；绳索被切断后按断点分成两段继续运动。

### 2. 脚踝绊锁—短时夺权

`自由端贴地绕过目标脚踝 → 控制者落地或站稳 → 收腕拉紧 → 目标支撑脚被带偏 → 控制者趁单膝跪落完成一次攻击或换位 → 对手切断、跨出或反拉脱困`

绊锁是短时窗口，不是永久定身。

## 被束缚反制链

### 3. 顺拉力减压—切断脱离

`手腕/脚踝/尾部被缠 → 先沿拖拽方向移动减少瞬时勒紧 → 转动被缠部位找到松弛侧 → 用刃口切割外层或让绳索摩擦固定物 → 脱离后沿垂直方向离开旧拉力轴`

直接反向挣扎会加大张力，只在角色力量足以破坏固定端时使用。

### 4. 借拖力接近操控者

`对手收紧并拖拽 → 被控者放平身体降低阻力 → 顺拖力加速靠近 → 在操控者回收手臂或触手根部进入攻击范围 → 固定缠绕段并切割根部/持握端 → 借断裂反冲脱离`

### 5. 反缠与卡柱

`柔性结构横扫或回收 → 防守者让自由端越过身体 → 抓住松弛段绕柱/兵器护手一周 → 蹬地改变张力方向 → 操控者被迫前倾或失去一条攻击路径 → 防守者从未封侧撤离`

## 多触手合围

- 不同触手按距离与路径先后到达，不机械同步闭合。
- 先识别覆盖最快的一条，用偏转或切割制造缺口；第二条只能封堵撤离线，第三条才承担抓取。
- 被抓后保留其他触手位置，脱困路线不能穿过尚未处理的实体。
- 切断的肢体、喷出的介质和回缩残端继续影响视野与水流或地面路线。

## 门禁

- 缠绕只发生在可接触部位，不能隔着实体障碍无因闭合。
- 颈部、胸腹和关节束缚必须控制持续时间与伤害后果。
- 柔性结构不能同时处于完全绷直和绕多圈松弛状态。
- 控制者失去意识、固定端断裂或结构被切断后，张力立即变化并进入回落或漂移。
