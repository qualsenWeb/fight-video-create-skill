# 15-骨伞近身拆招与巨掌镇压专项

## 来源与使用边界

- 来源：用户资料《7.30.txt》，吸收日期2026-08-22；
- 用途：为骨伞或承力伞类兵器提供俯冲对点、旋伞卸力、收伞点刺、挂腕踢击，以及具备法相能力时的裂隙巨掌镇压；
- 近身动作可独立使用，巨掌部分仅适用于明确拥有召唤、法相或空间能力的角色。

## 结构化绑定

- `weapon_binding`：可承力伞骨、伞柄和伞尖，能够展开、收拢及短时离手的骨伞/法器伞；
- `primary_range`：近身拆招转中远程终结；
- `required_capability`：巨掌镇压需要法器释雾、空间裂隙与同源法相控制；
- `avoid_when`：普通雨伞、低强度写实格斗、空间没有巨掌落点，或时长不足以交代法器与法相来源。

## 执行级动作与连招

### 1. 垂直伞尖—上迎剑尖对点（风格化能力档）

`伞手从高柱蹬离 → 收拢伞骨让伞尖沿垂线下压 → 剑手沉髋并从下向上送出剑尖 → 两条兵器轴在双方之间短暂对准 → 接触后伞尖和剑尖同时偏离中心 → 双方分别落向预定落点`

- 只用于高精度风格化动作，不冒充常规实战最优解；
- 接触前用侧面或斜侧广角确认共同轴线，接触后必须有偏转和落地结果；
- 不用全屏特效代替两个尖端的可见接触。

### 2. 横斩逼线—旋伞倾角卸力—收伞回刺

`剑手横斩封住前方 → 伞手后滑并把展开伞面倾向斩击来向 → 手腕带伞面旋转让剑刃沿外侧伞骨滑走 → 伞手借后滑回弹合拢伞面 → 伞柄/伞尖沿剑手中线短刺 → 剑手侧滑并竖剑格挡`

- 旋伞卸力依靠倾角、滑刃和脚步，不让伞面静止硬吃全部冲击；
- 展开到收拢必须通过可见手部动作；
- 回刺用于逼退和夺回攻击权，不自动命中心口。

### 3. 下劈压迫—伞柄挂腕—转身侧踹

`剑手跃起或高举剑完成向下劈砍 → 伞手侧滑半步避开刃线 → 收拢伞柄从外侧上挑挂住持剑腕/护手附近 → 顺下劈动量把腕线引向侧下方 → 伞手前脚踩实并转髋 → 后腿侧踹躯干防护区 → 剑手沿既有方向后飞或滑退`

- 挂腕只控制短时持械线，不声称关节永久失能；
- 侧踹在剑线已被引偏后进入，避免身体撞进未受控刀刃；
- 被踢者的兵器、躯干与脚步同时响应，击退距离服从能力档。

### 4. 骨伞离手盘旋—释雾开裂

`近身重击已拉开距离 → 伞手向上抛出展开骨伞 → 伞体保持可辨轮廓盘旋 → 青色/同源雾从伞骨和旋转轨迹扩散 → 雾中先出现细小裂点 → 两只同源巨手抓住裂缝边缘 → 沿相反方向逐步撕开空间`

- 法器的持有、离手、上升和盘旋连续；
- 雾只承担转场和能力介质，不永久遮蔽施术者与目标；
- 裂隙扩大需要过程，不能从黑屏直接切到完整法相。

### 5. 法相显形—单掌下压镇落

`裂隙达到稳定宽度 → 法相头部/肩线与一只主巨掌依次显现 → 施术者维持控制手势或同源能量连接 → 巨掌对准已建立地面落点 → 掌面下压引发目标衣发、气场和积水先行受压 → 掌面与地面/目标发生一次主接触 → 石板下沉、碎石和水雾沿外侧扩散 → 法相与烟尘收束`

- 巨掌不是独立召唤兽，施术关系必须保持；
- 至少一个广角同框施术者、巨掌、目标与落点；
- 只执行一次镇压，不在命中后追加第二个同职责巨拳或爆炸。

## 组合建议

- **近身写实降级链**：2 → 3，以击退或夺械线结束；
- **风格化完整链**：1 → 2 → 3 → 4 → 5；
- 短时生成可将1删除，从已建立的地面近战进入2—3，或单独生成4—5并用明确首帧状态承接。
