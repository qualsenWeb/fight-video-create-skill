# 万剑诀、雷域与箭雨式群体飞剑专项

> 来源：用户资料《万剑诀+雷域+箭雨》，即梦2.0-720三段10秒生成案例；吸收日期：2026-08-21。
>
> 定位：补齐现有资料中“修仙高级剑招专项”实际缺失的群体御剑、剑阵与雷剑终结执行细节。本文件只覆盖群体飞剑技法，不冒充完整的修仙剑法体系。

## 一、使用门槛

选用前必须同时确认：

- 角色掌握御剑、剑阵、召剑或大规模远程控剑能力；
- 场景能容纳高空汇聚、宽弧转向或大范围下射；
- 对手数量或目标尺度值得使用群体飞剑，而非单剑精确打击；
- 目标时长能容纳至少“起势—群体运动—接触/临界结果”三段；
- 用户允许超常仙侠尺度，或已明确锁定万剑归宗、剑雨、雷域等能力。

普通持剑角色、狭窄室内、低法术武侠或无法解释飞剑来源时不得使用。

## 二、共通执行结构

每个群体飞剑招式至少写清：

`人物触发动作 → 飞剑来源 → 群体组织 → 剑尖与运动方向 → 宏观路径 → 目标响应 → 接触或临界状态 → 群体余势 → 下一招条件`

所有飞剑保持正常尺寸，剑尖朝运动方向、剑柄在后。附着雷电、火焰、雾或光带时仍需看清剑体，不以特效替代飞剑。

群体不是招式背景。每个主群都具有前部、中段、尾部、横向宽度、上下厚度和前后纵深；转向按“前端先变线—中段扭转—尾部延迟追随—外层回补”传播。

## 三、核心招式

### 3.1 远天赴命

- **功能**：召集与蓄势。
- **起势**：角色在高空单掌控场或缓慢抬手，人物周围的能量向掌心、剑印或控制中枢压缩。
- **来源**：飞剑从远天、宗门剑塔、山脊、云层深处和画外不同高度持续出现；禁止在人物身边突然生成。
- **轨迹**：高层由远云压近，中层从左右天际汇入，低层贴山脊或建筑掠过后抬升。
- **反馈**：风压牵引衣袍与发丝，空气出现向内塌陷，远层银点逐渐形成宽厚剑流。
- **结果**：飞剑进入人物头顶或身后控制空域，为星河编队、漩涡剑潮或多路剑流提供数量基础。

### 3.2 万剑星河随身

- **功能**：以人物换位牵动整片剑群，建立绝对控制感。
- **起势**：角色从当前高空位置沿清楚轨迹进行一次或多次大范围换位，不用推镜或硬切冒充瞬移。
- **轨迹**：人物原位留下短暂残影、音爆或能量拖尾；外层剑群拉出大弧，中层斜向补位，内层追随新方向偏航。
- **群体响应**：群体改向沿前中尾传播，不允许所有剑机械同步转头。
- **结果**：人物在新位置刹停，剑群仍保持惯性和分层回补，为分路编队或发令攻击创造起势。

### 3.3 五路立体千剑流

- **功能**：远距离迁徙、包围和分路攻击。
- **起势**：万剑星河中的多个区域自然分轨；“五路”是来源案例参数，可按目标规模改为三路、五路或更多主群。
- **群体结构**：每路前部为宽阔错层锋线，中段上下换层与前后穿插，尾部持续追入；边缘分流后回补。
- **宏观路径**：高位前压后下弯、侧路大弧上升切中层、中央S形偏航、低位掠地抬升、后上路外绕补位。
- **对手响应**：目标群体被不同方向的阴影、剑鸣和风压包围，防御区域被逐步压缩。
- **结果**：各路在目标上空保持前后错层，为同步俯冲、垂天剑瀑或交叉封锁提供入口。

### 3.4 垂天剑瀑

- **功能**：把横向迁徙转为纵向覆盖。
- **起势**：主剑群抵达目标上空，人物以一次挥手、指向或剑印变化发令。
- **转向**：前部先俯冲，中段沿宽阔垂直弧面跟随，尾部因惯性拉出长弧后追入；群体底部、边缘和中段可裂出次级支流。
- **接触**：大量彼此分离的剑体按不同倾角和纵深持续下压，先贯穿前层目标，再由中段和尾部连续补入。
- **反馈**：目标被贯穿、压碎、掀飞或迫使分散，地面产生剑痕、裂缝、碎石和与目标材质匹配的破坏。
- **结果**：可停在全面命中前形成悬念，也可进入低空回潮或雷域清场。

### 3.5 铭文天幕·分区箭雨

- **功能**：建立覆盖全战场的分区下射场域。
- **起势**：人物释放半透明能量天幕，天幕扩张并在不同区域点亮控制节点或铭文纹理。
- **释放**：各节点分层、分批裂放由数百把飞剑组成的三维下射支脉；上层较密，中层斜射，下层逼近地面。
- **边界**：“箭雨”只表示密集下射节奏。角色没有弓箭时，攻击主体始终是飞剑，不生成实体箭矢。
- **接触**：不同区域先后命中，保留支脉宽度、厚度和前中尾，不能散成普通单剑雨。
- **结果**：形成高空天幕—中层剑群支脉—地面命中区的三层空间，可连接雷柱或地表雷海，但只选一种雷域机制。

### 3.6 低空剑鱼回潮

- **功能**：让第一轮落剑后的存量飞剑继续猎杀，避免攻击后全体插地消失。
- **起势**：命中后的部分飞剑借反弹、控剑力或未耗尽动量重新抬升，在地面上方重组。
- **路径**：一群贴地大弧回旋横扫，一群在中低空斜切压入，一群从侧面分流包抄后再汇聚。
- **接触**：群体前缘切开目标阵线，中段持续穿插扩大缺口，尾部补入完成绞杀。
- **反馈**：低空剑鸣、尘浪、碎甲或目标残留物沿群体反方向喷散。
- **结果**：剑群留下连续命中点和地面沟壑，为地表雷海或最后一次收束提供导电/能量路径。

### 3.7 不规则漩涡剑潮

- **功能**：将远天来剑汇聚为天穹级终招前摇。
- **起势**：不同方向和高度的剑流向人物头顶大范围汇入。
- **结构**：外层大范围环绕，中层斜插补位，内层高速拧转；局部支流分离、升沉和改向后重新并轨。
- **限制**：保持不规则三维鱼群风暴，禁止同心圆、规则圆盘、空心剑管、中央黑洞或机械旋转。
- **触发**：人物睁眼、挥手或剑指等唯一动作让“拧转汇聚”切换为“整体推进”。
- **结果**：剑潮横贯天穹，并在目标上空折成多处前后错层的剑瀑。

## 四、雷域终结变体

### 4.1 落剑雷柱阵

- 群体剑幕命中后，雷痕沿地面裂缝向相邻覆盖区传递；
- 多个命中区依次爆起成片雷柱，上方剑幕仍在补入；
- 雷柱只强化已经成立的落剑结果，不能先于飞剑接触出现；
- 适合纵向压迫和双层清场，但应控制亮度与数量，避免遮住剑体和目标反馈。

### 4.2 地表雷剑浪潮

- 赤雷只沿落剑点、目标裂口和地面沟壑连通，不从天空劈落，不形成雷柱；
- 低空飞剑重新组成厚重剑潮，贴地能量流与赤雷共同形成横向推进的雷剑浪潮；
- 前缘为贴地雷裂，中层为密集低空剑群，后层为能量流、尘浪和目标崩解余波；
- 浪潮贯穿后，地面雷痕可在核心区域失稳，形成环形冲击与全域清场。

两种变体默认互斥。需要雷柱时不得同时声明“禁止任何雷柱”；选择地表雷海时不得又从天空降雷。

## 五、三段连招骨架

### 5.1 召剑压境

`远天赴命 → 万剑星河随身 → 多路立体剑流 → 垂天剑瀑临界`

适合第一段建立规模，结尾停在即将命中，给下一段保留接力状态。

### 5.2 落剑回潮

`剑瀑命中 → 存量飞剑抬升 → 低空剑鱼回潮 → 铭文天幕展开 → 分区箭雨 → 落剑雷柱阵或大范围清场`

适合中段展示飞剑复用和天地三层攻击。若10秒容量不足，删去天幕或雷域之一。

### 5.3 天穹终灭

`远天再召 → 不规则漩涡剑潮 → 唯一人物触发 → 剑潮整体推进 → 多处剑瀑 → 全域密集下压 → 地表雷剑浪潮 → 环形终结`

适合终局全灭。人物触发前可有极短静压，触发后天地、剑潮和附着能量在同一拍爆发。

## 六、合理性与时长门禁

- 10秒通常只容纳一次召集/重组、一次宏观迁徙和一次攻击结果；同时塞入两次完整召剑、多个特写、两种雷域和核爆终结会过载。
- 剑数是规模建议，不是固定事实。模型无法稳定维持数万把时，优先保证多个厚体群体和持续补入，不用少量近景飞剑冒充。
- 大师级控剑者可以用极简手势；能力较弱者必须增加法器、阵眼、剑匣或同伴协同等合理来源。
- 开放高空适合大弧转向；低空和建筑密集场景应减少主群数量、缩小转弯半径并明确避障。
- 雷域必须由落剑点、能量连接或人物施法触发，不能无因出现。
- 命中后要说明飞剑是耗尽、插地、折断、回收还是重组，不得跨段无因恢复满量。

## 七、摄影门禁

- 摄影机从群体外部拍摄，超广角读取宏观路线，长焦读取群体厚度；
- 不跟随单剑进入剑群内部，不用巨剑冲镜制造虚假规模；
- 人物、剑群和目标至少有一次同框；
- 群体转向使用宽景别，人物发令使用中近景，命中反馈使用贴地或目标主观镜头；
- 新镜头继承人物高度、群体方向、剑体状态、目标分布和特效余波中的至少四项。

## 八、禁止事项

- 扁平剑板、剑墙、细线剑束、规则放射剑扇；
- 单剑领飞、巨剑替代万剑、少量飞剑贴镜冒充规模；
- 同心圆、机械漩涡、统一旋转中心、中央黑洞、空心剑管；
- 用真实水流、水幕、水花或瀑布表现“剑潮、剑河、剑瀑”；
- 雷电完全覆盖剑身，导致剑体不可辨；
- 人物无能力依据却凭空统御万剑；
- 镜头进入剑群内部后只剩光线和穿模；
- 群体命中后全体无因消失，下一镜又满量复位。
