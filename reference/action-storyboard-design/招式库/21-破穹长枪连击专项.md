# 破穹长枪连击专项

来源：《破穹七连枪＋墨龙贯空奥义》。

## 中距破防链

贴地侧闪重刀 → 枪杆旋扫下盘 → 收腕拧腰上刺胸甲 → 横扫腰侧扩大失衡 → 沉腕挑枪使目标离地 → 双手过顶以枪杆下劈 → 落地反刺肩甲 → 旋身平扫重建距离。

## 追击链

腾空斜劈破来袭刃气 → 枪托短击面门或护架 → 落地滑步缠压敌兵器 → 枪尖横抹护架外侧 → 膝撞破坏重心 → 连续短突刺覆盖胸、肩、腰三个高度。

## 挑空接口

枪杆下压锁住敌兵器，转髋让枪尖走大弧上挑躯干。目标被挑飞后，持枪者收枪站稳并沿枪身聚能；终极枪气、龙形能量或直线贯穿必须由枪尖直刺触发并沿此前抛飞轴追击。

## 巨型目标拆解接口

`沿雪坡或斜面滑入攻击覆盖边缘 → 枪尖刺膝窝迫使单膝落地 → 借锤柄、前臂或环境高差升到肩侧 → 连点肩颈与肘弯限制持械臂 → 沿巨型目标回收动作滑向背侧 → 枪尖攻击已暴露的核心或结构缝隙 → 投枪后立即离开巨物倒落范围`

面对巨型目标时，长枪用于维持安全半径和攻击局部，不与完整质量正面对撞。每次关节损伤必须改变跪姿、持械高度、转身速度或攻击覆盖；核心终结只能在前段姿态改变后成立。

## 门禁

枪杆下劈和枪托击打需确认武器结构可承力。短时长选取一条主链，不硬凑“七”这个数量。面对巨型目标时先建立尺度和倒落方向；没有可见关节、甲缝或核心时，不得临时制造弱点。
