# 破穹长枪连击专项

来源：《破穹七连枪＋墨龙贯空奥义》。

## 中距破防链

贴地侧闪重刀 → 枪杆旋扫下盘 → 收腕拧腰上刺胸甲 → 横扫腰侧扩大失衡 → 沉腕挑枪使目标离地 → 双手过顶以枪杆下劈 → 落地反刺肩甲 → 旋身平扫重建距离。

## 追击链

腾空斜劈破来袭刃气 → 枪托短击面门或护架 → 落地滑步缠压敌兵器 → 枪尖横抹护架外侧 → 膝撞破坏重心 → 连续短突刺覆盖胸、肩、腰三个高度。

## 挑空接口

枪杆下压锁住敌兵器，转髋让枪尖走大弧上挑躯干。目标被挑飞后，持枪者收枪站稳并沿枪身聚能；终极枪气、龙形能量或直线贯穿必须由枪尖直刺触发并沿此前抛飞轴追击。

## 门禁

枪杆下劈和枪托击打需确认武器结构可承力。枪尖横抹颈侧在非致命或平台限制场景改为抹开护架。短时长选取一条主链，不硬凑“七”这个数量。
