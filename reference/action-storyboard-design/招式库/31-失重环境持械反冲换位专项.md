# 失重环境持械反冲换位专项

## 来源与使用边界

- 来源：用户提供的太空题材战斗资料之动作设计层。
- 用途：在失重或近失重环境中组织持械突进、格挡反冲、舱壁蹬射、抓取与武器回收。
- 适用于有明确舱壁、护栏、绳索、喷口或可抓取结构的空间；不适用于无边界且角色没有推进方式的空域。

## 动量规则

- 每次线性加速必须来自蹬壁、抓拉、喷口、抛物或对手碰撞。
- 挥击会让角色身体产生反向转动趋势；双手持重兵器需要通过收腿、触壁或抓杆抑制自旋。
- 格挡后的双方沿接触法线分离，除非一方抓住对手、武器或固定结构。
- 离开支点后只能沿既有动量漂移，直到下一次外力介入。

## 执行动作链

### 1. 蹬壁斜射—三击改向

`背部或双脚接触舱壁 → 屈膝储存弹力 → 朝对手侧前方蹬出 → 第一击迫使护架偏左 → 反震使身体向右漂 → 收膝转髋修正自旋 → 第二击沿新角度切入 → 第三击只在脚或肩再次接触边界后发动`

连续攻击次数由可用支点决定，不能悬空无限变向。

### 2. 重击格挡—反冲分离—二次接近

`双方兵器重接触 → 接触点火花或结构震颤 → 双方沿相反方向漂开 → 一方先触壁并蹬回 → 另一方抓杆或以喷口改线 → 第二次接触发生在新的高度或横向位置`

### 3. 被掼壁—屈膝借身脱离

`持械腕被抓 → 对手将身体推向舱壁 → 背肩先接触并分散冲击 → 双膝收向胸前 → 双脚蹬在对手胸腹或肩部 → 反作用力拉开抓握 → 漂移中重新建立持械方向`

受击造成的疼痛、装甲损伤或呼吸紊乱进入下一轮动作。

### 4. 武器脱手回收

`兵器因撞击脱手并保持旋转 → 角色与兵器沿不同速度漂移 → 通过蹬壁或抓栏改变自身路线 → 从柄部运动前方截取而非原地等待 → 握住后先收臂消减相对速度 → 再转入攻击姿态`

### 5. 漂浮物遮蔽反制

`对手利用漂浮物遮住视线 → 防守者不追逐全部目标 → 推开最近碎屑建立观察缝 → 根据碎屑受力方向判断来袭轴 → 侧蹬离线 → 用攻击余势把碎屑推向对手下一路径`

## 门禁

- 地板、墙面和天花板在失重中都是等价支点，左右与上下关系由既有观察轴保持。
- 漂浮碎片、断裂护栏和脱手兵器跨阶段保留速度与方向。
- 能改变形态的武器仍须遵守结构占用和转换过程；形态变化不提供无来源推力。
- 终结后双方不会自然落地，应通过抓取、磁吸、绳索、喷口或气流变化收束位置。
