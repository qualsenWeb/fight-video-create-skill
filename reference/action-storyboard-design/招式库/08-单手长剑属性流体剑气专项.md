# 单手长剑属性流体剑气专项

> 来源：用户资料《剑仙魔仙》即梦-720 三段一次生成案例，以及《7.23日视频，剑仙水刃.docx》三套水刃清场提示词；吸收日期：2026-08-21。
>
> 定位：补充“单手长剑挥斩—属性流体剑气脱刃—远程飞行—对冲/命中—地形反馈”，以及连续饱和清场、轨迹变体和短时水系剑气塑形的执行级招式。命名武器、角色身份和固定阵营只属于具体案例，不进入本通用专项。

## 一、结构化绑定

- `weapon_binding`：单手持握的正常尺寸长剑、直剑或外形与挥斩轨迹兼容的剑类武器；
- `required_capability`：角色具备稳定剑气外放及至少一种属性附着能力；
- `primary_range`：中远程；
- `combat_role`：远程压制、封线、反击、对冲、地形破坏和终结；
- `forbidden_binding`：弓箭、枪械、法杖、长枪、棍、群体飞剑、无剑角色；
- `avoid_when`：普通持剑者无超常能力、需要近身实体拼剑、狭窄空间无法容纳宽幅剑气、时长只够一次普通挥砍。

武器名称不改变绑定。只有用户明确指定具体命名剑时，才在项目角色卡或案例中保留名称。

## 二、共通动作链

每道剑气必须遵循：

`重心与握剑姿态 → 肩肘腕带动剑刃 → 属性沿手臂和剑身汇入 → 剑气沿刃面脱离 → 剑尖/刃面方向决定弹道 → 对手或地形响应 → 流体接触结果 → 残留痕迹 → 下一次挥剑条件`

硬性规则：

- 人物保持单手握剑，另一手可用于平衡、护身或短促术式，但不能无因换成双手重武器动作；
- 每次挥剑只生成与该轨迹匹配的一道主剑气；多发必须由连续可见挥斩产生；
- 属性特效沿服装结构、手臂发力链、剑身表面和剑气根部传递；
- 剑体始终清晰，不能被电弧、烈焰、雾或水光完全覆盖；
- 剑气脱刃后保持刃状主结构，不退化成无方向光球。

## 三、基础剑气

### 3.1 宽幅贯空流刃

- **功能**：连续直线压制与封锁横向路线；
- **起势**：单手横斩、斜斩或反手挥扫，转髋与肩线共同提供速度；
- **形态**：凝实宽幅的流体刃，宽度可为常规剑气的3—4倍，核心刃面稳定，边缘保留属性介质翻涌；
- **弹道**：沿剑刃切线高速直进，可轻微弧行但不能无因追踪目标；
- **命中**：定点流体炸裂，属性沿碎块、裂纹或地面痕迹继续扩散；
- **结果**：用于密集连射时，每道剑气保留间距、来源和独立落点。

### 3.2 弧形封线刃

- **功能**：迫使目标改变高度或横向切线；
- **起势**：转身大弧横扫、回身反切或由低到高的挑斩；
- **形态**：弧形流体刃随剑尖路径展开，弧面前缘锋利、后缘逐渐消散；
- **弹道**：横跨目标预计路径，而非直接追尾；
- **响应**：目标必须下沉、越过、借地形遮断或以另一道剑气对冲；
- **结果**：为下一道直线追击或垂直重斩创造封位条件。

### 3.3 扇形连射

- **功能**：中距离区域压制；
- **起势**：角色连续完成2—4次不同角度短促挥斩，脚步或空中姿态持续换位；
- **形态**：多道彼此分离的宽幅流刃形成扇形或高低错层弹道；
- **限制**：不得一次挥剑凭空复制成整片弹幕；
- **结果**：前层封路，中层逼迫变向，后层对准新落点补入。

## 四、连续清场与轨迹变体

### 4.1 连续饱和水刃清场

- **功能**：单名持剑者对多方向、多高度敌群持续压制，火力从点、线扩展为面和分层覆盖；
- **前置**：角色具备高频连续挥斩、稳定剑气外放和足够的空域/地面路线；
- **升级链**：`单道精确水刃 → 横向连续落点 → 扇形/交叉覆盖 → 多高度弹道 → 饱和清场`；
- **执行**：每轮保留可见挥剑、脱刃方向和独立落点；主角在突进、折返、升空或俯冲中持续改变发射位置；
- **敌方响应**：敌群需要补位、闪避、对冲、改变高度或绕过残骸，不能静止等待清除；
- **限制**：饱和来自挥剑频率、分刃能力、覆盖范围和目标层级递进，不等于一次挥剑无因复制满屏剑气；达到峰值后不追加同职责的第二套终极爆炸。

### 4.2 Z字水浪切线

- **功能**：连续改变两至三个方向，切断敌群横向避让路线；
- **起势**：两至三次方向明确且首尾接续的斜斩、反切或旋身连斩；
- **形态**：每次剑刃轨迹生成一段水浪刃，相邻段在空中短时衔接为Z字折线；
- **结果**：先逼迫目标向第一处缺口移动，再由后续折线封住新路线；
- **限制**：Z字来自连续挥斩组合，不是一道剑气在无追踪能力时任意折角。

### 4.3 环形水浪横斩

- **功能**：震开近地包围、建立换层空间或把既有水刃存量向四周释放；
- **起势**：完整旋身横斩，落足、转髋、肩线和剑尖共同形成稳定圆周轴；
- **形态**：水浪沿剑刃圆周轨迹向外扩散，前缘保持环形刃向，后缘散成水雾、冰晶或属性附着；
- **结果**：近地目标按受力方向向外失衡，主角可借反力升空、折返或转入下一轮远射；
- **限制**：不能只让人物原地旋转而无脚步与发力轴，也不能把环形扩散写成无来源的全场同时爆炸。

### 4.4 细刃水剑气群

- **功能**：在已建立的水刃存量上分化为高密度穿透弹幕；
- **前置**：角色明确具备分刃、剑阵式分化或水刃汇流能力，且前镜已显示介质与数量来源；
- **成形**：连续短斩先生成多道主刃，或一次触发让既有主刃裂成有限、方向可读的细刃；
- **弹道**：细刃按扇形、交叉、网状或分层方向推进，保留局部间隙和独立落点；
- **限制**：“数百道”只作为大规模视觉目标，不能覆盖人物、剑身和全部战场关系；普通剑气外放角色不得直接套用。

## 五、水系剑气塑形

冰鹰、游龙或其他动物轮廓只属于剑气的短时攻击形态，不属于通用召唤术。必须同时满足：

`既有水刃/水浪介质 → 剑刃动作或剑尖落点触发 → 材质沿连续路径汇流 → 形成可读攻击部位 → 沿既定弹道完成一次攻击职责 → 散回水雾、冰晶、电弧或水痕`

### 5.1 冰鹰俯冲形态

- **前置**：宽幅水浪或多道水刃已在主角周围/前方汇流；
- **触发**：旋身收剑、反手挥斩或剑尖导向给出俯冲路线；
- **攻击部位**：翼刃负责横向切线，利爪负责局部抓击，鹰首只承担方向读取；
- **消散**：完成低空掠阵或单次俯冲后立即破成水雾、冰晶与既有附着效果；
- **禁止**：无前置水体凭空出现、长期自主盘旋、脱离持剑者指令追踪或表现为有独立生命的召唤兽。

### 5.2 游龙穿阵形态

- **前置**：通过剑尖落点、水浪盘刃或连续水刃建立足够介质，并让敌方与环境先对能量变化产生响应；
- **触发**：一次明确挥剑、拔剑或剑尖导流完成从“汇聚”到“脱刃成形”的切换；
- **攻击部位**：龙首负责冲击，躯干盘旋改写阵线，局部刃面/龙爪切入侧翼，龙尾利用剩余动量完成横扫；
- **连续性**：水纹、冰晶与附着效果从龙首沿躯干连续传播，持剑者沿既定剑气路径移动时需有御空能力或形态动量依据；
- **消散**：摆尾或贯穿结束后散回水浪、水雾、冰晶、电弧和地表痕迹；
- **禁止**：破土而出的独立实体龙、无剑刃触发的召唤、龙体与持剑者穿模、攻击后环境无痕复原。

### 5.3 化形选择门禁

- 一段短视频通常只保留一种主化形，冰鹰与游龙不在同一高潮连续叠加；
- 化形应替换同职责的属性潮或饱和弹幕高潮，不能在完整终结后再追加；
- 形态复杂度必须服从时长和可读性，无法同时读清起源、成形、攻击和消散时退回基础水刃；
- 更换为其他形态时仍须重新定义介质来源、剑刃触发、攻击部位、弹道职责和消散结果。

## 六、重型剑气

### 6.1 崩岳流体柱斩

- **功能**：垂直压制、地形开沟和大范围阶段破坏；
- **起势**：角色在上方完成明确下劈，或从低位上挑后让剑气沿既定弧线砸落；
- **形态**：超粗柱状或厚壁状流体剑气，内部保持浓淡层次和推进方向；
- **命中**：先压缩落点介质，再径向炸开冲击、碎块和属性余波；
- **地形结果**：产生纵深沟壑、环形裂纹或局部结构崩解；
- **限制**：柱体仍是剑气，不变成无刃向的自然瀑布、烟柱或独立雷柱。

### 6.2 贴地断层斩

- **功能**：沿地面追击远端目标并改变地形路线；
- **起势**：单手挥剑斩地，剑身属性在接触前达到峰值；
- **路径**：复合流体刃沿地面高速推进，依次掀起表层、裂开深层并留下连续属性痕迹；
- **响应**：目标需侧切、升空、越过沟壑或以对冲攻击削弱；
- **结果**：沟壑成为后续追逐的真实障碍，不在下一镜复原。

### 6.3 属性潮终结

- **功能**：把连续剑气或先前落点汇成唯一终结威胁；
- **前置**：至少已建立多次挥斩、地面痕迹或空域弹道；
- **成形**：密集剑气在同一宏观方向上汇入厚重属性潮，仍能看出多层刃面和前后推进；
- **触发**：由一次清楚挥剑完成从“汇聚”到“推进”的切换；
- **限制**：不能跳过前置直接生成百米级天灾，也不能与另一套核爆大招同时竞争结尾。

## 七、属性材质模板

### 7.1 水体、冰晶与电弧

- 核心为半透明液态水刃，表面有真实流动、折射和高光；
- 边缘可附着少量冰晶碎块，保持锋利刃向；
- 电弧沿剑身纹理和剑气根部附着，命中后沿水渍、裂纹或碎块表面短距扩散；
- 禁止电弧脱离载体在空中无因乱飘。

### 7.2 黑雾与烈焰

- 核心为具有体积和浓淡层次的凝实黑雾刃，不是松散烟团；
- 烈焰沿服饰纹理、剑身和黑雾刃边缘窜动；
- 命中后黑雾炸开、火星喷溅并留下焦黑、余烬或短暂余烟；
- 禁止烈焰替代刃体结构或持续遮住人物轮廓。

以上是可替换模板，不固定角色阵营。其他属性也应保持“主体介质 + 锚定附着效果 + 对应落点残留”的三层关系。

## 八、对冲与格挡

剑气格挡不是兵刃接触。两道剑气相遇时：

1. 先建立相反或交叉弹道；
2. 接触核心短暂压缩、偏转或互相切入；
3. 主体介质按属性发生一种主要反应；
4. 环形冲击、蒸汽、碎屑或火星沿受力方向释放；
5. 双方根据对冲结果继续换位、补射或失去原路线。

水与烈焰可生成汽化白雾，电弧与黑雾可产生短促爆闪；反应只用于证明碰撞，不能形成长期全屏遮挡。

## 九、持剑与动作门禁

- 剑尖、刃面和挥斩轨迹决定剑气方向；
- 高频连射仍需肩、肘、腕和重心变化，禁止只抖手腕生成弹幕；
- 单手剑适合横扫、斜劈、回身反切、上挑和俯冲下劈，不擅自改成双手长柄横抡；
- 位移中挥剑时，落足、反蹬或空中转体需为剑刃提供稳定发力轴；
- 人物主体保持清晰，动态模糊优先作用于剑刃、剑气边缘和背景相对运动；
- 命中后必须留下与属性、力度和材质相符的痕迹；
- 特效不穿模，不在剑气飞行中闪烁、断帧或无因消失。

## 十、不适用与冲突

- 群体飞剑、万剑归宗、剑阵、剑雨或低空剑群使用 `07-万剑诀雷域箭雨专项.md`；
- 近身实体拼剑、格挡、缴械和逐招拆解使用其他兵器或武学资料；
- 无剑角色不能仅因需要漂亮特效而套用本专项；
- “箭雨”若只描述密集下射剑气，也不能生成实体箭矢；
- “雷域”“烈焰”“黑雾”“水浪”属于属性与结果，不是武器类型；
- 来源案例中的命名武器只保留在案例，不视为通用招式前提。
