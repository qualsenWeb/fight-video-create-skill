# 13-横刀对关公刀河滩连招专项

## 来源与使用边界

- 来源：用户资料《河滩战斗.txt》，吸收日期2026-08-22；
- 用途：唐横刀或同类单手刀对关公刀、偃月刀等重型长柄刀的执行级攻防，以及湿软泥水地面的滑退、追击和贴地反制；
- 原资料含大量极限时间、720度旋转和超常刀气。下文补足重心、接触、反馈与适用条件，不把整理内容伪称传统刀法定式。

## 兵器与距离门禁

- 横刀手依靠切线、错步和短路径夺取近距，不在长柄刀完整横扫半径内连续硬抗；
- 关公刀手依靠柄长维持中距，近身后缩短握距、用刀杆/刀背截线或以腿法重新拉开；
- 湿地转向必须降低重心，急停会产生滑移；旋身次数由角色能力、摩擦和时长决定；
- 下述动作名称用于资料检索和编排，不代表历史武术定名。

## 执行级动作与连招

### 1. 甩笠拔刀—贴水突进

`非持刀手沿斜上方向甩出斗笠 → 斗笠短暂遮挡对手视线或镜头 → 持刀手拇指顶开刀镡并抽刀 → 前脚蹬开浅水 → 身体沿低直线进入交锋距离 → 刀尖保持在身体前侧而非拖在身后`

- **目的**：把入场道具、拔刀和突进合并为一条因果链；
- **反馈**：蹬地点水膜后喷，刀鞘固定在腰后，衣摆和雨丝沿反方向拖动；
- **下一条件**：进入重刀前侧，不直接冲入满幅横扫线。

### 2. 低位回旋斩—横架反扫

`横刀手降髋向外侧切步 → 腰胯带刀沿斜上或水平圆弧攻击肩线 → 关公刀手双手分握横架 → 接触后顺刀势转髋卸力 → 以刀背或刀杆反向扫出 → 横刀手错步绕向柄侧`

- 接触点为横刀中前段对关公刀刀身/刀杆强区；
- 横架者肩线下沉、后脚滑半步，进攻者刀腕外偏；
- 反扫不是原地满圆，需由第一次接触提供旋转动量。

### 3. 横扫牵制—侧踹击退—追身下劈

`关公刀横扫迫使横刀竖刃或退线 → 武器线被牵制时前腿收膝 → 髋部送出侧踹命中躯干防护区 → 横刀手后撤滑步卸力 → 关公刀手落脚后转髋追进 → 双手举刀下劈封住退路`

- 腿与刀不是同时命中两个独立目标；横扫先占用对手防线，侧踹随后进入；
- 被踢者表现躯干回弹、脚下犁痕和呼吸受阻，不默认骨折；
- 追击必须从踢腿回收和落脚继续，不瞬移贴脸。

### 4. 后滑翻身—旋身反撩下盘

`横刀手沿湿泥后滑 → 一手或肩背短暂触地管理翻转 → 双脚重新落地并继续沿原方向卸力 → 前脚外摆建立旋转轴 → 腰胯带刀完成一周以内旋身 → 刀刃贴近地表反撩对手下盘/落脚区`

- 原资料的720度只用于明确超常机动；常规执行优先180—360度完成同一职责；
- 反撩以逼跳、逼退或破坏落脚点为目的，不自动砍中脚踝；
- 未命中时刀风切开浅水，留下清楚攻击线。

### 5. 反撩逼跳—力劈封落点

`横刀贴地反撩 → 关公刀手提膝跃开刀线 → 空中收刀至头侧 → 依靠下落重力和肩髋共同发力向落点劈砸 → 横刀手侧滚/滑铲离开垂直线 → 重刃砸入泥水形成局部凹坑`

- 下劈目标是封住横刀手起身路线，不要求直接命中肩背；
- 重刃落地后有短暂回收负担，为贴地反制创造窗口；
- 泥水只沿落点外喷，不产生无因全屏爆炸。

### 6. 贴地滑铲—低扫斩—刀头点地变向

`横刀手借上一段滑行动量降至低姿 → 支撑腿向前、后腿控制方向 → 刀刃沿地面横扫落脚区 → 关公刀手单脚转移重心 → 刀头短点地面形成支点 → 转髋带动身体和刀杆改向 → 以扫腿或刀杆低扫逼横刀手退出低姿`

- 滑铲必须继承速度和湿滑表面；
- 关公刀刀头点地只承担一次变向支撑，不能像撑杆一样无损弹飞；
- 结束态为双方重新站立或半蹲、相距半臂至一臂，可直接进入近身短链。

### 7. 膝撞斜劈—竖架错步绕侧

`关公刀手缩短握距贴近 → 前膝顶向躯干迫使对手收肘 → 双手随落脚把刀从高位斜劈 → 横刀手沉腰塌步竖架并向外侧引偏 → 接触后后脚绕过前脚完成错步 → 沿关公刀柄侧切到对手侧后`

- 竖架是引偏而非静止承受全部重力；
- 错步启动于兵器接触后的偏转，不在重刀尚未落下时穿过攻击线；
- 侧后位置只保留一个短动作窗口，对手可以转身或缩柄应对。

### 8. 虚探—削腕线—挑刃三连

`横刀手沿圆弧走位 → 刀尖短探面门逼对手抬刀 → 立即收半程并侧身削向持械腕线 → 对手缩腕、转柄格挡 → 横刀由下向上垫步挑刃 → 关公刀头被抬离中线 → 双方保持移动不复位`

- “削腕线”可落空或打在护腕/刀柄附近，目的为改变握持线，不默认断腕；
- 三招点到即收，适合作为轻接触呼吸段；
- 镜头使用稳定双人中景，避免三次接触各自插入全屏冲击帧。

### 9. 腰侧破绽—贴腹横斩—砸刀—沉肩顶

`关公刀回收过大暴露腰侧 → 横刀手横向切入近距 → 刀刃以可控制深度横切躯干防线/衣甲 → 反臂用刀背或刀脊砸向对方刀杆 → 对方兵器线被压低 → 横刀手收刀贴身沉肩顶撞 → 关公刀手沿湿泥连续后退`

- 影视安全或非致命任务把第一击处理为擦甲、切衣或迫使护刀，不写实砍入腹部；
- 三击共享前进动量，总数不再叠加第四、第五个无反馈动作；
- 每次后退保留脚步、泥痕和兵器回收状态。

### 10. 四刀压防—沉腰重劈破线

`斜劈迫使外架 → 竖斩压低重心 → 撩削抬高刀杆一端 → 横抹封住侧退 → 横刀手借前四击累积的角度优势沉腰重劈 → 关公刀横架但握持线下沉偏离中门`

- 前四刀按清楚节奏执行，不强制在0.2秒内完成；
- 每刀必须改变对方刀杆角度或脚步，不能原位连续闪烁；
- 最终破线表现为武器被压开、手腕回弹和胸前防区暴露，不声称双臂永久失能。

### 11. 破线旋身鞭腿—双向腾空分离

`对方兵器刚被压开 → 横刀手回收刀臂避免自伤 → 前脚踩实、沉腰转髋 → 后腿沿水平弧线甩出鞭腿/蹬踢 → 足背或靴底命中胸腹防护区 → 对手沿原攻击轴后飞或滑退 → 进攻者受反作用力后仰并准备落地`

- 慢动作只覆盖接触、衣料形变和初始冲击波；
- 被击飞距离服从角色能力与地面摩擦，写实档改为退步或跌倒；
- 下一条件可为收刀定胜负，也可为超常终结建立远距窗口。

### 12. 千云墨斩（超常能力档）

`破线击飞已建立安全距离 → 横刀手在落地或短时能力悬停中稳定刀线 → 手腕翻刀并让墨色能量沿刀身汇聚 → 目光确认目标与攻击轴 → 单次向下挥斩 → 竖向墨色刀气沿既有轴线推进 → 目标防守/命中结果与地面沟痕同步出现 → 余波结束后收刀`

- 只在角色明确拥有外放刀气、短时滞空或同等能力时使用；
- 与“全程近身无隔空攻击”互斥；一旦选择本招，应把它标为独立终结阶段；
- 写实档删除本招，以第11条或交错斩作为终结；
- 劈云、深沟和全屏负片属于尺度选项，不是招式成立条件。

## 组合建议

- **短时写实链**：2 → 3 → 7 → 10 → 11；
- **泥水反转链**：3 → 4 → 5 → 6 → 8；
- **风格化终结链**：9 → 10 → 11 → 12；
- 单次生成只选一条主链，并按时长删减动作；不要把十二条全部连续塞入一个短镜头。
