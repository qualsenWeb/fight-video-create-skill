# 街舞式连续突进腿法专项

来源：《10秒街舞格斗腿法·连续突进突袭战》与《霜月剑姬·冰封沧溟》。

## 技法链

- 滑铲侧踢：从前冲降重心，支撑腿折叠滑行，攻击腿横扫踝、胫或膝侧；命中使对手抬脚或侧移，为撑地踢建立近距。
- 撑地二段横踢：单掌落在身体侧前方，肩髋形成支撑轴；第一腿扫下盘，髋部继续旋转带第二腿扫腕或肩线，落腿即回收进入垫步。
- 双飞踢：由垫步和摆臂起跳，两腿分先后或同时蹬向胸腹护架；命中后不能悬停，借反作用力收膝落地或后翻卸力。
- 换位后旋踢：前脚点地变向，视线先回看，转髋带脚跟横击肋部或护架外侧；对手格挡后形成侧向滑退。
- 俯身扫堂腿：从后旋踢落脚直接降重心，手掌可短暂支地，腿沿贴地弧线扫支撑脚；落空时必须收腿起身，避免静止趴地。
- 倒立侧踢：仅在对手直线拳压或高位攻击时使用，双手支撑让身体侧移，腿从攻击线外侧踢腕或头侧；结束后滚髋落地。
- 俯冲三段踢：高点收髋后连续完成左右分踹、交叉横踢、定点重踢；每段改变目标或角度，最后一击才承担终结。

## 门禁

需要可滑地面、可承力支点和足够全身空间。复杂腿链优先全身景别。角色受伤、穿长重甲或鞋底不适合滑行时降级为垫步低扫和短后旋踢。
