# 巨型法相擒摔专项

> 来源：用户资料《0819紫红》第一段；吸收日期：2026-08-21。
>
> 定位：为具备法相、能量投影或巨型实体延伸能力的角色，提供拦截、擒控、抡摔与压落的执行级动作链。法相不是独立召唤兽。

## 一、结构化绑定

- `required_capability`：角色能稳定生成并控制与自身同源的巨型能量实体；
- `primary_range`：中远程起势，巨型实体近中距离接触；
- `combat_role`：拦截高速巨物、改变目标运动方向、制造重型落点；
- `required_space`：开放空域或可容纳完整抡摔弧线的大型地面；
- `avoid_when`：角色只具备单体远程法术、目标没有可抓取的实体受力点、空间过窄或时长不足以建立生成与接触。

## 二、共通动作链

`施术媒介蓄力 → 能量流入媒介/角色 → 法相由近及远显现 → 巨掌沿攻击轴线前探 → 接触目标控制点 → 五指、掌根与腕部锁定 → 提臂带起整体 → 腰肩转动抡出弧线 → 过肩/压落 → 环境冲击与法相收束`

施术者、法相和目标在侧面宏观镜头中至少同框一次。法相的手掌不能从目标背后无因出现；起手方向、接触方向和摔投落点应共享同一攻击轴线。

## 三、基础招式

### 3.1 正面巨掌拦截

- **功能**：截停迎面高速目标；
- **起势**：施术者保持稳定姿态，以媒介或手势完成单一发令；
- **路径**：法相从角色后方或已锁定方位向前探掌，掌面正对目标来向；
- **反馈**：目标外层、头部或躯干受压偏移，周围介质沿反方向翻卷；
- **限制**：不能用全屏冲击波替代掌面接触。

### 3.2 控首提身

- **功能**：从拦截转为改变巨型目标重心；
- **接触点**：抓住头部、颈部、肩背、甲壳边缘或其他明确承力结构；
- **发力**：五指收拢、虎口压紧、掌根上托，目标躯干按控制点被连续带起；
- **限制**：先显示控制点和局部受力，再展示整体升空，禁止直接把整只目标瞬移抛起。

### 3.3 法相过肩摔

- **功能**：把拦截动量转为垂直或斜向重落；
- **动作**：`控首 → 提臂 → 目标全身离开原路线 → 法相腰肩转动 → 目标越过肩背 → 向预定落点翻转压下`；
- **镜头**：侧面超广角完整读取弧线，必要时用近景补抓握细节；
- **结果**：目标、风雪、碎石和附着能量沿同一弧线拖拽，落点留下塌陷或冲击环。

## 四、法相收束门禁

- 法相必须在攻击前有生成来源，攻击后有淡化、回流、转入下一动作或余波残留；
- 施术者不因法相出手而无因换位；
- 巨型目标若在压落后消散，先给出命中、受力和粒子化/残留过程；
- 不把同一段再叠加第二个同职责的巨手、巨拳或落地爆炸。
