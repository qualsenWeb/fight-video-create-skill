# 折扇开合切线与近身反制专项

> 来源：用户案例《青蓝女剑客与赤狐折扇女侠雨后江南古宅对决案例.md》；吸收日期：2026-03-14。
> 
> 定位：补充普通折扇作为近身兵器时的开合、接触、卸力、切线和短距反制执行细节。不包含角色专属狐尾、颜色、人物身份或脱手法器追杀。

## 一、结构化绑定

- `weapon_binding`：可承受近身接触的折扇，扇骨、扇缘和扇面均保持可辨；
- `required_capability`：角色具备稳定的折扇开合、格挡、切线和短距反制能力；
- `primary_range`：近距离至中近距离；
- `combat_role`：改线、格挡、卸力、扰乱节奏和反入；
- `environment_support`：地面、墙面、廊柱、门框或其他可提供重心回收和短距换位的支点；
- `forbidden_binding`：默认无脱手追杀、无独立飞行、无扇面替代盾牌的全身防护、无凭空远程光束。

## 二、共通动作链

每次折扇攻击或防守至少写清：

`持扇状态 → 开合/转腕动作 → 扇骨或扇缘接触线 → 对手响应 → 卸力或改线方向 → 重心回收 → 下一次攻击窗口`

折扇不是装饰性道具。开扇、收扇、旋扇和扇面接触必须改变攻击线、距离、视线或重心中的至少一项。

## 三、基础技法

### 3.1 开扇封线

- **功能**：展开扇面，覆盖对手预计进入的横向路线；
- **起势**：前臂向外旋转，拇指推动扇骨打开，身体前脚同时斜切出中线；
- **接触**：扇骨或扇缘接触对手前臂、武器侧面或手腕外侧，不用扇面硬吃重击；
- **结果**：对手攻击线被推向外侧，扇手获得半步切入或撤离窗口；
- **限制**：必须有明确开扇动作，不能在闭扇状态直接生成完整扇面效果。

### 3.2 扇缘切线

- **功能**：以扇骨尖端或扇缘切入手腕、前臂、肋侧或武器空档；
- **起势**：闭扇贴身，肘部收近躯干，前手从对手兵器外侧沿短弧线送入；
- **轨迹**：短促直入或斜向擦线，不画大圈；
- **结果**：对手收腕、转肩或后退，扇手沿接触方向继续短距追入；
- **限制**：不把折扇写成长剑或长棍，攻击半径受扇长和前臂距离限制。

### 3.3 旋扇卸力

- **功能**：把来袭的直线力量引向侧后方；
- **起势**：扇面或扇骨以斜角接触来器，肩线不正面顶住，前臂随来力旋转；
- **轨迹**：接触点沿小弧线滑向外侧，身体同步侧移半步；
- **反馈**：扇骨震颤、对手武器偏转、脚底滑过湿地或衣摆被带动；
- **结果**：扇手不复位，直接以收扇点刺、扇缘切线或短肘进入反击。

### 3.4 收扇反入

- **功能**：利用收扇动作缩短外形和距离，进入对手兵器内圈；
- **起势**：扇面完成一次格挡或扰乱后，手腕内收合扇，前脚沿对手外侧踏入；
- **轨迹**：闭扇沿前臂、肋侧或肩线短促直送；
- **结果**：对手若抬臂防守，上盘被吸引，扇手可用低位步法或另一侧切线继续进攻；
- **限制**：收扇不是瞬移，必须展示脚步、肩线和接触距离变化。

### 3.5 扇面扰乱

- **功能**：改变视线与攻击判断，不直接承担终结；
- **起势**：开扇掠过面前或武器外侧，利用扇面遮挡一瞬；
- **衔接**：遮挡结束前必须完成侧移、换手、收扇或扇缘切入之一；
- **结果**：对手攻击落空或转向错误，扇手从侧面获得短窗口；
- **限制**：扇面遮挡不得超过一次关键接触所需时间，不能靠黑屏代替位置变化。

## 四、可执行连段

### 4.1 开扇改线反入

`开扇封住外侧 → 扇缘推偏来器 → 侧步脱开中线 → 收扇贴入 → 闭扇短刺 → 旋身回收`

适合雨后庭院、回廊和门框等空间。扇手的侧步落点应避开积水深坑或掉落瓦片。

### 4.2 旋扇卸力切肋

`斜角接触 → 旋扇引开重击 → 对手肩线前探 → 扇缘沿肋侧短切 → 后撤半步保持扇距`

适合对抗直剑、短刀或其他线性兵器。若对手是重型长柄兵器，不得用扇面正面硬架，应先离开尖端和杆身的主力线。

### 4.3 扇面扰乱换位

`开扇掠面造成短遮挡 → 踏墙/绕柱换线 → 收扇从侧后反入 → 对手转身格挡 → 扇缘接触后顺势退入下一空间`

环境支点只承担换位，不凭空增加扇子的攻击距离。

## 五、兵器接触与连续性门禁

1. 折扇的接触点优先是前臂、腕部、武器侧面和肋侧空档，不把扇面当作无损盾牌。
2. 开扇负责扩大遮挡和改线，收扇负责缩短距离和反入，旋扇负责引偏受力；三者职责不可无因互换。
3. 每次接触后必须保留扇骨震颤、对手武器偏转、脚步滑移或肩线改变等反馈。
4. 湿滑地面只改变摩擦和落脚稳定性，不自动让角色高速漂移；每次滑步都要有控制和回收。
5. 折扇不能因为开合而变成长兵器，也不能在无离手动作时变成远程投射物。
6. 扇面遮挡镜头后必须恢复双方位置、观察轴和下一动作方向。
7. 一段短视频通常选择两至三种主技法，再以一次明确力量对撞或脱离收束。

## 六、与相近专项的区分

- 普通折扇近身拆招使用本专项；
- 骨伞的伞钩、挂腕、旋伞和法相裂隙使用 `15-骨伞近身拆招与巨掌镇压专项.md`；
- 法器脱手变轨追杀与回收使用 `10-投掷法器追杀回收专项.md`；
- 无固定兵器的御水控场不使用本专项；
- 远程水墨剑气属于剑类属性流体剑气专项，不由折扇自动产生。

## 七、交付检查

- 是否明确当前为开扇还是收扇；
- 是否写出扇骨/扇缘的接触对象和方向；
- 是否写出对手的受力反馈和下一动作条件；
- 是否通过脚步、支点和重心完成换位；
- 是否避免扇面全能格挡、无因远程投射和遮挡后位置丢失。
