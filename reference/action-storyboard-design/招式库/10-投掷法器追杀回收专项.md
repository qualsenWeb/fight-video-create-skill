# 投掷法器追杀回收专项

> 来源：用户资料《0819紫红》第二段；吸收日期：2026-08-21。
>
> 定位：为扇、环刃、盘刃等可辨认实体法器提供脱手投掷、变轨追杀、攻击附着和回收的执行级结构。

## 一、结构化绑定

- `weapon_binding`：扇、环刃、盘刃或具有清楚轮廓、可脱手飞行的实体法器；
- `required_capability`：角色具备远程御器、回收或能量牵引能力；
- `primary_range`：中远程；
- `combat_role`：追杀、封线、逼位、远程压制和回收续战；
- `avoid_when`：法器不允许脱手、主体是不可辨认光球、空间不足以表现弹道，或目标只需一次静态防御。

## 二、标准链路

`持器可见 → 肩背腰胯蓄势 → 手掌松开 → 法器离手 → 初始弹道锁定 → 实体飞行与变轨 → 结构附着攻击 → 目标换位 → 旧位置命中 → 回收/消散`

法器在离手前后都必须保持可辨认外形。能量只附着于边缘、骨架、轨迹或命中点，不能吞没实体结构。

## 三、基础招式

### 3.1 脱手重投

- **功能**：建立单次高威胁攻击轴线；
- **起势**：持器手臂侧后拉开，转髋、拧腰、沉肩后大幅甩臂；
- **释放**：手掌明确松开，法器沿手臂延长线飞出；
- **镜头**：先给持器状态，再在施术者与目标同框的广角中读清弹道；
- **限制**：不得让法器从画外凭空高速出现。

### 3.2 弧线追杀

- **功能**：迫使目标横向、纵向或纵深换位；
- **路径**：初始直线后按惯性进入大弧或折返，变轨前保留前一方向的延续；
- **反馈**：每次目标离开旧位置后，法器或其攻击附着击中旧位置并留下云雪、地形或能量爆裂；
- **限制**：追踪不等于瞬移，法器不能无过程跨越整个画面。

### 3.3 边缘线网封锁

- **功能**：扩大法器的路径威胁并封住目标可逃方向；
- **生成**：线网从扇缘、刃缘或明确结构连续拖出；
- **分层**：前线逼迫，侧线切断，后线命中旧位置；
- **限制**：线网须保留间隙和来源，不能用无方向紫光覆盖全屏。

### 3.4 牵引回收

- **功能**：收回法器并把远程追杀转入下一回合；
- **触发**：手势、牵引能量或回旋弧线在前镜建立；
- **结果**：法器沿可读路径回到手中，或在完成职责后沿轨迹消散；
- **限制**：不让法器在目标失去画面后无因消失。

## 四、生成门禁

检查持有、离手、初始轴线、变轨、攻击来源、目标路径、旧位置反馈和回收结果是否完整。多次躲避至少改变高度、横向、纵深中的两个维度。
