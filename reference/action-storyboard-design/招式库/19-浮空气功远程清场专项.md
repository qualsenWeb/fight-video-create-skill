# 浮空气功远程清场专项

来源：《10秒气功天空远程攻击》。

## 动作链

结印或收掌聚能与起跳同步 → 折线升空建立射界 → 掌击气波破前排 → 连发灵弹压缩侧向路线 → 横向气斩截断补位 → 震荡气劲推开近身目标 → 空中旋身反手连轰 → 屏障短接触卸力 → 翻转聚能俯冲推出覆盖气功波。

## 空域规则

每次悬停都必须由上升动量、能力托举或短时换向解释。发射动作对应弹道：掌推对应直线气波，横挥对应横向气斩，双掌收拢对应集中弹，双掌外推对应覆盖波。镜头保留人物、弹道和至少一层目标落点。

## 火力升级

单道结果 → 连续弹点 → 横向封线 → 多方向反手射击 → 单次覆盖终结。不得在覆盖高潮后再追加同职责大招。

## 门禁

仅供具备气功、灵能或飞行能力的角色。纯写实武者、无远程能力或狭窄室内不使用。
