# 剑腿双修冰系连招专项

来源：《霜月剑姬·冰封沧溟》。腿法基础与16有重叠，本文件只保留剑腿距离切换和冰系结果。

## 距离切换

长剑四击压防：横斩腕线 → 上撩面甲 → 下挑肘弯 → 平截膝侧。敌方重击压顶时以横剑上架和冰盾承压，炸盾反作用力作为滑铲进入腿法内圈的接口。

腿法短链：滑铲绕侧 → 掌撑低扫膝弯 → 高扫持械腕 → 垫步双飞踢胸甲 → 落地折线后旋踢 → 扫堂破重心。被擒腿时以另一腿蹬膝甲借力旋身，空中回收长剑后落地完成宽幅回旋斩。

## 冰系反馈

剑击留平行霜蚀痕，腿击在接触点炸局部冰晶并蔓延霜裂。只有终结阶段才生成法相、百丈冰刃或全场冰封。冰层、焦痕和碎甲跨镜保留。

## 门禁

剑已反扣背后或明确腾出双手后才使用掌撑腿法；持剑手不能同时无因支地。冰盾爆散后应交代碎片、护腕状态和角色受力。
