## 八¾、兵器技法调用规则（兵器 / 高级轻功专项资料库入口）

> **定位**：SKILL.md 是打戏导演和决策中枢，兵器 / 高级轻功专项资料库是武术顾问和细节仓库。主文件不塞满所有执行级动作，但必须知道：有哪些兵器技法、高级轻功体系、修仙高级剑招体系，每套体系什么性格、什么时候调用、调用后如何转成镜头语言。

### 触发条件：什么时候必须调用兵器 / 高级轻功专项资料库

当用户出现以下任一需求时，必须优先读取对应兵器专项资料库，禁止只凭招式名生成：

1. 创建持剑角色 / 剑客 / 用剑人物，或用户明确绑定9套剑法之一 → 读取 `兵器技法资料库_剑法专项.md`。
2. 创建持镰角色 / 死神 / 守墓人 / 亡灵战士 / 重甲收割者，或用户明确绑定“正统死神长柄镰刀” → 读取 `兵器技法资料库_长柄镰刀专项.md`。
3. 创建雷电将军 / 雷神 / 稻妻神明 / 一心净土 / 梦想一心 / 无想一刀 / 居合太刀角色，或用户明确绑定“梦想一心太刀术” → 读取 `兵器技法资料库_梦想一心太刀专项.md`；必须剔除常态长枪动作，只保留梦想一心太刀专属剑术。
4. 创建鸣潮绯雪 / 绯雪 / 樱灼流 / 常世身 / 预求身 / 灼霜 / 霜樱单太刀角色，或用户明确绑定“绯雪樱灼流单太刀术” → 读取 `兵器技法资料库_绯雪樱灼流单太刀专项.md`；必须保留唯一迅刀太刀「灼霜」、常世/预求双形态、临时能量冰弓、居合时停与武道收刀礼，禁止实体双刀/双剑虚影/分身/锁链。
5. 生成剑法对战 / 长柄镰刀对战 / 梦想一心太刀对战 / 绯雪单太刀对战 / 兵器打戏 / 持械VS徒手 / 持械VS持械。
6. 用户要求“兵器镜头”“剑招细一点”“镰刀招式细一点”“太刀居合细一点”“绯雪单刀细一点”“兵器大招”“兵器终结技”。
7. 创建轻功型角色 / 身法型角色 / 飞檐走壁角色 / 仙侠腾挪角色 / 高机动追逐型角色，或用户明确要求“高级轻功”“轻功细一点”“轻功动作细一点”“飞檐走壁细一点”“腾挪换位细一点” → 读取 `兵器技法资料库_高级轻功专项.md`。
8. 生成大量空中换位 / 连续借力 / 贴水轻功 / 竹梢腾挪 / 飞檐追逐 / 断崖折返 / 绳索滑行 / 高空回落类打戏时，优先读取 `兵器技法资料库_高级轻功专项.md`，禁止只写成“角色轻功很好”“飞来飞去”这类空泛描述。
9. 创建修仙剑修 / 御剑角色 / 剑仙 / 剑尊 / 剑阵宗师 / 天外飞仙型角色，或用户明确要求“修仙高级剑招”“仙侠剑招细一点”“御剑招式细一点”“剑阵细一点”“万剑归宗细一点”“破空裂虚细一点” → 读取 `兵器技法资料库_修仙高级剑招专项.md`。

### 兵器技法总原则

| 原则 | 要求 | 错误写法 | 正确写法 |
|------|------|---------|---------|
| **兵器不是徒手换皮** | 必须写清兵器关键部位参与动作；剑法写剑尖/剑刃/剑脊/剑格/剑身/握柄，长柄镰刀写镰尖/镰刃/镰柄/镰钩/刃背 | “角色用兵器攻击” | “镰尖直线平刺咽喉，镰钩外侧勾住对方枪杆向外拉扯卸械” |
| **必须写攻击轨迹** | 每个兵器招式必须明确直刺/斜劈/横斩/圆弧/贴地扫/反手回斩/勾拉/短距飞斩 | “兵器光闪过” | “镰刀贴地水平横扫脚踝，浅灰扁平镰风沿地面划出完整弧线” |
| **必须写接触反馈** | 兵器碰撞要有火花、震颤、金属摩擦、刃身弹开、镰钩拉扯受力 | “挡住攻击” | “镰钩勾住刀背向外猛拉，金属摩擦迸出冷白火星，敌方持械手腕被带偏” |
| **必须写兵器与身体协同** | 剑法不是手腕乱挥，镰刀也不是魔法挥光；要写腰胯/步法/重心/双手握柄/身体下沉或腾空 | “挥镰攻击” | “双手分握镰柄首尾，腰胯横向转动带动镰刃划出中位弯月横斩” |
| **必须绑定镜头目的** | 近景看手腕剑尖，全景看大圆弧和腾空，特写看命中点 | “镜头跟拍剑招” | “特写·正面微侧平视·急速推镜·推进至剑尖刺入冰壁裂纹处” |

### 兵器镜头禁忌

1. **中景/全景兵器攻防禁止90°侧面正拍**：会像横版格斗游戏，兵器厚度和空间纵深消失；必须改30-60°斜角。
2. **高速兵器招式不能全程特写**：特写只用于破绽/命中/格挡/勾卸瞬间，持续0.2-0.5秒后必须切走。
3. **大圆弧剑花/满月镰斩不能用近景**：近景只会看到一团光，必须中景/全景展示完整轨迹。
4. **太极剑禁用剧烈抖动**：杨式太极剑要稳定、柔和、低对比度，不能写成独孤九剑式高速乱刺。
5. **独孤九剑禁用厚重拖尾**：它是“细、准、快、破绽单点”，不是大刀式宽光带。
6. **长柄镰刀禁用锁链、分身、结界、大范围黑雾**：写实死神镰只允许单柄长金属镰刀、冷银浅灰金属刃光、短距飞镰和镰钩卸械。
7. **梦想一心太刀禁用常态长枪动作**：雷电将军梦想一心体系只允许太刀、居合、胸口拔刀、无想一刀、雷光斩线；禁止写枪尖、枪杆、枪花、长枪突刺、薙刀式扫杆。
8. **绯雪樱灼流禁用双刀和分身**：绯雪体系全程只允许唯一迅刀太刀「灼霜」；寒簇樱矢可临时幻化能量冰弓，但射完必须回归单太刀；禁止实体双刀、双剑虚影、分身、锁链、多重实体刀具。
9. **兵器碰撞不能只写爆炸**：必须写剑身/剑格/剑脊、镰刃/镰钩/镰柄或太刀刀尖/刀刃/刀格/刀背的物理接触，爆炸只是反馈不是动作本体。

### 兵器招式转提示词公式

```text
[角色] + [步法/重心] + [身体发力] + [兵器部位] + [攻击轨迹] + [命中/格挡/勾卸目标] + [兵器反馈] + [镜头目的]
```

```text
青岚碎步贴近，腰胯小幅拧转，剑尖走极小侧弧绕开对手剑锋中线，直线点刺持械手腕，剑尖命中瞬间爆出冷白星芒；特写·45°斜侧平视·急速推镜·推进至剑尖刺入手腕破绽处定格0.2秒。
```

### 调用优先级

1. **用户指定某套剑法** → 先读剑法专项资料库中该套剑法，再生成。
2. **用户指定正统死神长柄镰刀/持镰角色** → 先读长柄镰刀专项资料库，再生成；必须保留无锁链、无幻术分身、无领域结界、无大范围黑雾的写实限定。
3. **用户指定梦想一心太刀术/雷电将军/雷神/一心净土/无想一刀/居合太刀角色** → 先读梦想一心太刀专项资料库，再生成；必须保留胸口拔刀、居合快斩、诸愿百眼愿力、雷光湮灭刃光，并剔除常态长枪动作。
4. **用户指定绯雪樱灼流单太刀术/鸣潮绯雪/绯雪/樱灼流/常世身/预求身/灼霜/霜樱单太刀角色** → 先读绯雪樱灼流单太刀专项资料库，再生成；必须保留唯一迅刀太刀「灼霜」、常世身轻盈粉樱快斩、预求身冰蓝居合弹反、临时能量冰弓与归刃漫天雪，禁止实体双刀/双剑虚影/分身/锁链。
5. **用户指定高级轻功 / 飞檐走壁 / 贴水轻功 / 竹梢腾挪 / 高空回落 / 绳索滑行 / 空中连续换位** → 先读高级轻功专项资料库，再生成；必须保留借力点、落脚点、折身换向、环境反馈与非魔法化轻功逻辑。
6. **用户指定修仙高级剑招 / 御剑 / 剑阵 / 万剑归宗 / 天外飞仙 / 破空裂虚 / 大道无形** → 先读修仙高级剑招专项资料库，再生成；必须保留剑招结构、人物动作、剑气层级与仙侠空间尺度，不能只写抽象神通名词。
7. **用户只说“持剑角色”** → 先用9套剑法定位速查推荐2-3套，让用户选；如果用户明确偏仙侠、御剑、剑阵、云海剑修，则优先推荐修仙高级剑招体系。
8. **用户只说“持镰/死神/守墓人/收割者角色”** → 默认推荐正统死神长柄镰刀，并询问是否搭配八极/形意/泰拳/柔道/武侠身法等徒手或身法技法。
9. **用户只说“雷系太刀/神性居合角色”** → 默认推荐梦想一心太刀术，并询问是否搭配截拳道、咏春、武侠身法或空手道强化零前摇与居合节奏。
10. **用户只说“冰樱太刀/霜樱巫女/双形态单刀角色”** → 默认推荐绯雪樱灼流单太刀术，并询问是否搭配武侠身法、空手道、截拳道或柔道强化滑步、居合定格、截击与反制。
11. **用户只说“轻功型角色 / 身法宗师 / 飞檐走壁角色 / 仙侠腾挪角色”** → 默认推荐高级轻功体系，并询问是否搭配武侠身法、剑法、截拳道、咏春或空手道强化轻功后的落点攻击。
12. **用户只说“修仙剑尊 / 剑仙 / 御剑角色 / 仙门首席 / 剑阵宗师”** → 默认推荐修仙高级剑招体系，并询问是否搭配高级轻功体系、武侠身法或某套传统剑法补近身对招。
13. **用户说“直接帮我创建”** → 按角色气质自动选1套主战兵器技法 / 高级轻功体系 / 修仙高级剑招体系 + 1-2套徒手/身法/摔投技法，并说明理由。
14. **普通徒手对战** → 不主动调用兵器库，避免兵器信息干扰徒手体系；但当用户明确强调高频空中换位、飞檐追逐、贴水腾挪时，可以单独调用高级轻功专项；当用户明确强调御剑、剑阵、云海剑修、仙侠终极剑招时，可以单独调用修仙高级剑招专项。
