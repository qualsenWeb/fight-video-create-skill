# 双链锚定与双属性协同专项

> 来源：用户案例《渊鳞双色双链墨海清场与巨魔终结案例.md》；吸收日期：2026-03-14。
> 
> 定位：补充双链武器在清群、锁控、借力、交绞和单体终结中的执行关系。水火、冷暖和颜色仅作为可替换属性示例，不是本专项的固定设定。

## 一、结构化绑定

- `weapon_binding`：两条可见链体，分别由左右手、臂甲、法器或明确的身体锚点控制；
- `required_capability`：角色能够维持链条张力、方向切换和至少一个目标/地形锚定；
- `primary_range`：中近距离至中距离；
- `combat_role`：封线、缠绕、锁控、拉拽、借力、双侧夹击和单体终结；
- `environment_support`：柱体、断桥、地面裂口、目标关节或其他可承受拉力的锚点；
- `forbidden_binding`：无接触漂浮光带、同时无锚点的全场束缚、链条替代瞬移、双链无分工的长期混色。

## 二、核心链条

每次双链动作至少写清：

`出链姿态 → 链体路径 → 第一锚点 → 张力方向 → 目标响应 → 第二锚点/交汇 → 拉拽或锁控结果 → 释放、回收或下一次挂接`

链条的戏剧功能来自张力变化。只写“链条飞出缠住目标”不足以形成可执行动作，必须说明链从哪里来、绕过什么、钩住哪里以及拉力把谁带向何处。

## 三、基础技法

### 3.1 双侧封线

- **功能**：限制目标横向逃离路线；
- **起势**：双臂分别向左右或上下错开，链体沿不同角度铺开；
- **路径**：一条切目标前进线，另一条绕向侧后方或地面支点；
- **结果**：目标被迫减速、抬升、下沉或改变方向；
- **门禁**：两条链不能在同一平面平行摆动，必须形成不同的张力方向。

### 3.2 交叉锁腕

- **功能**：控制单体目标的一侧或双侧上肢；
- **起势**：一链先绕过目标前臂或腕部，另一链从相反方向切入；
- **接触**：第一链固定腕部后，第二链压住肘外侧或另一腕部；
- **结果**：目标肩线被拉开，重心偏向一侧，角色获得近身打击或换位窗口；
- **限制**：不能在目标未受力、未失衡时直接写成完全僵直。

### 3.3 链条借力弹射

- **功能**：让角色或目标沿张力方向改变位置；
- **起势**：链先挂住柱体、断梁、目标关节或其他承力点；
- **动作**：角色屈膝降重，随后以蹬地和转髋把自身拉向锚点，或反向拉动目标；
- **反馈**：链节拉直、锚点震动、角色肩背承受牵引、地面留下拖痕；
- **结果**：完成横向弹射、绕柱换线或对目标的短距拖拽。

### 3.4 双链交绞

- **功能**：把两条已建立张力的链汇成一次集中控制或终结；
- **前置**：两链已经分别锁定不同锚点、目标双臂或目标与地形；
- **轨迹**：一链保持固定，另一链绕过目标形成交叉，随后两侧同步回拉；
- **结果**：目标双侧受力、护架打开或身体旋转，形成明确裂纹、倒地或单体终结窗口；
- **限制**：交绞不是开场大招，不能跳过前置挂接和张力建立。

### 3.5 链回拉二次打击

- **功能**：利用第一次命中后的回弹或失衡完成二次接触；
- **起势**：链条命中目标后不立即消失，保持可见松弛段和回收方向；
- **动作**：角色先放松再收紧链条，沿目标当前移动方向回拉，或借锚点改变链头角度；
- **结果**：目标再次撞向链体、地面或角色预设的终结位置；
- **限制**：二次打击必须来自第一次受力后的新位置，不能让目标瞬间回到原点。

## 四、双属性协同

双链可承载不同属性，但属性首先服务职责分工：

- 一条负责冻结、减速、缠绕或切断路线；
- 另一条负责鞭击、灼烧、破甲或迫使目标暴露；
- 两条链只有在共同目标已被限制、两侧锚点成立或终结窗口出现时才交汇。

推荐结构：

`属性A封线/减速 → 属性B打击暴露点 → 双链分别保持锚定 → 同步交绞或回拉 → 单一结果`

禁止开场即把两种属性混成一条无方向能量带，也禁止每次挥链都同时触发两套全屏效果。颜色与材质必须让观众能区分左右链的职责。

## 五、清群到单体终结

### 5.1 清群阶段

双链分别负责左右或前后区域。链体要持续接触敌人、地形或彼此形成路线封锁。普通敌人可以被扫开、缠住、拉倒或逼入狭窄区，但不应全部同时停滞等待。

### 5.2 战场转换

清群后保留真实战损：坑、裂柱、焦痕、冻结面、断桥或残链。单体目标从这些结果中出现或利用破坏反扑，迫使角色重新建立锚点，而不是无缝切换到干净场地。

### 5.3 单体锁控

先读出目标前摇和攻击方向，再由一链锁住腕部或肘部，另一链攻击暴露的面门、甲缝或支撑腿。锁控只制造窗口，不自动取消目标反抗；目标应有挣扎、回拉、甩臂或借地反制。

### 5.4 终结

双链分别控制目标两侧或双臂，角色借链张力、地面支点或目标身体反作用力完成腾跃、绕身或压制。最后的交绞、注入、回拉或撞击只选择一种主要结果，并把裂纹、碎片、余波和链条回收延续到终帧。

## 六、身体与空间门禁

1. 角色必须承受链条牵引，肩、肘、腕和躯干方向应与张力相符。
2. 链条挂接柱体或断梁时，要交代锚点受力和结构反馈；不能把不可承力的薄片当固定点。
3. 链条绕过目标关节后，目标的肘肩线和重心必须改变；无变化时只能称为擦过，不能称为锁控。
4. 双链动作需要中景或中广景读取链路，特写只强调一次挂接、锁腕或回拉接触。
5. 链条不能穿过角色身体、武器或彼此无因穿模；链节间距和回收方向要连续。
6. 释放链条后必须明确松脱、回收、断裂或留在锚点，禁止下一镜满状态无因复位。
7. 角色没有双链控制能力时，不因视觉需求临时增加第二条链；单链动作应使用相应的普通兵器或能力规则。

## 七、与相近专项的区分

- 双链、锁腕、拉拽、交绞和链条借力使用本专项；
- 法相实体抓控、提身和摔投使用 `09-巨型法相擒摔专项.md`；
- 控制僵直处决与腿法连段使用 `17-控制僵直型擒杀腿法专项.md`；
- 飞扇、环刃等脱手追杀和回收使用 `10-投掷法器追杀回收专项.md`；
- 文字化形、经文光墙或固定法阵不由本专项覆盖。

## 八、交付检查

- 是否明确两条链的来源、左右职责和锚点；
- 是否写出张力方向、目标重心变化和受击反馈；
- 是否存在释放、回收、断裂或留锚点的结果；
- 双属性是否先分工、后交汇，且只承担一个主要终结；
- 清群战损是否为单体阶段提供真实支点和障碍；
- 是否避免无锚点束缚、漂浮光带、瞬移拉拽和全屏特效遮挡链路。
