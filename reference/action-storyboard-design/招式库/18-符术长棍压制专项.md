# 符术长棍压制专项

来源：《10秒疯批符术棍法》。保留长棍技法与符术触发关系，不继承角色表演。

## 技法链

低位扫棍攻下盘 → 旋棍横格偏开重击 → 垫步劈砸面门 → 翻身连扫头颈肩腰膝 → 反身挑砸破坏重心 → 棍花卸力后突刺胸口 → 横扫劈砸点棍压防 → 击偏敌兵器后直线终结。

## 执行要点

- 扫棍由转髋带杆身横过膝线，命中后对手脚步失衡。
- 横格使用棍身中段承力，双手分距，接触后顺势旋杆卸力而非硬停。
- 挑砸先压低棍尾再由腿髋抬升，把对手武器或肩线挑开。
- 棍花只承担卸力、换手和遮线，不能长时间独立表演。
- 点棍和突刺瞄准护架缝隙；普通棍不写穿刺，符术强化时表现为冲击或符纹爆发。

## 符术绑定

符纹沿握持点、棍身和落点传播。轻击只留局部墨纹，重击产生环形震纹，终结才汇聚为巨大棍影或雷痕。
