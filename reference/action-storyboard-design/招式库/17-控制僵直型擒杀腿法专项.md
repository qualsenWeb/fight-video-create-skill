# 控制僵直型擒杀腿法专项

来源：《30秒擒杀连段》。

## 进入与控制

以肩颈扣控、臂部缠压或腰胯控制建立主受力点，贴身膝撞胸腹使对手重心后移。控制者不得只靠单手悬空提人；超常力量档可例外，但需明确能力。

## 连段动作

1. 保持肩颈或臂部控制，借前脚蹬地腾起，后旋重踢肩侧，使对手绕控制点转向。
2. 空中横踹胸腹延续后退方向；脚尖点踏躯干只能作为超常能力借力，写实档改为落地垫步。
3. 左右交替侧踢用于持续改变躯干方向，不在同一高度机械重复。
4. 双腿交叉锁夹颈肩后向下蹬属于高风险风格化动作，非教学用途；写实版本改为夹肩翻摔。
5. 旋风扫堂或连续踏击把目标送向地面，随后俯冲追打，不给无因复位。
6. 地面扫踢、侧踹或膝击只保留一条短链，再以抓控或抛投进入终结。

## 终结条件

此前必须已建立目标朝向、控制点和落点。单腿重蹬、投掷或砸落沿既有轴线完成，命中后进入明确倒地、失能或脱离结果。

## 避免使用

势均力敌且用户要求攻防互换、目标体型无法被控制、角色无擒拿能力、时长不足以交代控制转换。
