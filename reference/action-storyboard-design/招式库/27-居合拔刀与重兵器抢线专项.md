# 居合拔刀与重兵器抢线专项

## 来源与使用边界

- 来源：用户提供的武士题材战斗资料之动作设计层。
- 用途：处理刀在鞘内起手的抢线、半拔格挡、归鞘换势，以及短刀路对抗长重刀的回收空隙。
- 适用武器：打刀、太刀、横刀或具备稳定刀鞘与拔刀空间的单手长刀。

## 核心原则

居合不是反复表演收刀。归鞘必须由错身、格挡弹开或对手回收形成安全间隙；拔刀动作同时承担出刃、攻击和身体换线。面对长重刀时，不正面承受完整下劈，而是让开刃部主轴后接触刀脊、刀侧或对手持握线。

## 执行动作链

### 1. 侧身半拔格脊—旋入横斩

`对手长刀斜劈 → 前脚斜跨离开刃线 → 刀鞘随髋转避开碰撞 → 刀刃半拔接触对手刀脊 → 借相击力完成出鞘 → 身体沿对手外侧旋入 → 横斩迫使其转身回防`

半拔接触只改变刀路，不承担完整硬挡；护手、手腕和刀鞘不能互相穿插。

### 2. 低姿让弧—贴身三点削切

`对手大弧横斩 → 降髋从弧线下方进入 → 第一刀削持械肩臂 → 第二刀切腰侧迫使转胯 → 第三刀扫膝后侧破坏支撑 → 沿对手回身方向退出`

三点攻击服务“削弱持械—限制转身—破坏支撑”，不追求无功能次数。

### 3. 受压退步—跪姿撑刀—归鞘反拔

`连续重劈迫退 → 横刀偏转而非停住重击 → 最后一击将身体送入翻滚或跪姿 → 刀尖短触地面稳定方向 → 对手高举重刀暴露躯干 → 撑地起身与归鞘同步 → 沿雪面或地面低线拔斩穿过空门`

刀尖撑地只用于短时稳向；刀身结构不足以承重时改用空手撑地或膝步转身。

### 4. 错身收刀确认

`低线拔斩完成 → 双方继续原方向错身 → 攻方不回头追砍 → 利用余势纳刀 → 对手持械侧失力或跪落 → 收刀结束时保持安全距离`

结果由接触位置和前段损伤决定，不用收刀动作本身制造伤害。

## 门禁

- 鞘口方向、持鞘手和拔刀手全程一致。
- 重刀每次改变方向都需要回收时间；轻刀方只能在该时间窗内抢线。
- 湿滑或积雪地面会延长滑移，拔斩后必须安排减速、跪步或错身距离。
- 没有刀鞘、拔刀空间不足或武器已严重弯折时，不使用归鞘再拔链。
