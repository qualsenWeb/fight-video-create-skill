# 12-剑伞古刹环境连招专项

## 来源与使用边界

- 来源：用户资料《8.2.txt》《7.31.txt》，吸收日期2026-08-22；
- 用途：持长剑角色与伞类兵器角色在庭院、回廊、飞檐、屋顶和大殿中的执行级攻防与环境连招；
- 原文提供动作名称、身体路径、接触和场景结果；下文对重心、衔接和适用条件的补全属于入库整理，不伪称传统武学定式。

适用于具备持械训练和较高机动能力的角色。伞必须有可承力伞骨、伞柄或钩状结构；普通雨伞、脆弱装饰伞或低强度写实任务不得硬接重剑。超重建筑破坏、墙面高速奔跑和延迟斩击只用于夸张能力档。

## 角色动作签名

- **剑手**：以斜撩抢线、刺撩抹截连续压迫、剑身粘推改变伞面角度、低位平削追击落点、错身平斩终结；
- **伞手**：展开伞面竖架和偏转、收伞后用伞柄点刺、以伞钩挂檐挂链改变高度、借摆荡巨物改写攻击线；
- **距离关系**：展开伞面主守中距，收拢骨伞主战短距；长剑在剑尖距离压线，被伞面卡住后通过压剑、滑刃或换角重新夺线。

## 执行级动作与连招

### 1. 反手斜撩—竖伞卡锋

`剑手贴地突进 → 后手拔剑由下向斜上撩出 → 伞手侧后滑步让开身体中线 → 伞面竖起并以受力较强的伞骨接住剑锋 → 剑锋沿伞骨短滑并产生摩擦 → 双方手腕回弹，伞手借反作用力后翻或退入下一锚点`

- **攻击目的**：斜撩逼对手抬高防线并让出前进路线；
- **接触点**：剑刃中前段对外侧伞骨，避免剑尖无因穿过伞面；
- **反馈**：剑腕向外偏、伞柄压向肩侧、脚下水膜向相反方向炸开；
- **下一条件**：伞手获得后退或腾空动量，剑手沿同一方向追击。

### 2. 腾空旋身回旋斩

`伞手借上一格挡后翻拉开 → 剑手蹬地追起 → 空中收膝并转髋蓄转 → 腰腹带肩臂完成水平回旋 → 剑刃沿圆弧横扫伞手撤退线 → 伞手继续后翻、压伞偏转或改变高度`

- 旋身来自蹬地和收膝转髋，不写成空中无因连续自转；
- 全景或低位跟随必须显示起跳点、圆弧轨迹和落点；
- 未命中时剑风切雨或削断檐角，证明攻击方向。

### 3. 刺—撩—抹—截四连压伞

`直刺逼伞面正对 → 斜撩抬高伞缘 → 横抹沿伞缘切向持伞手 → 短截封住侧退路线 → 伞手以倾伞、竖架、侧滑和后退逐次化解 → 剑手在第四击完成后压住伞面而非复位`

- 四击共享向前追压动量，剑手步法沿回廊纵轴推进；
- 伞手每次防守改变伞面角度和脚步，不在原地重复抖动；
- 短链结束态为“剑压伞面、双方重心前倾”，可直接进入翻身重斩或伞柄反击。

### 4. 压伞借力—凌空重斩

`剑身压住伞面 → 剑手屈肘压肩把伞面向下逼偏 → 以前脚或伞面反作用力起跳 → 身体翻过接触线 → 双手或主手把剑从上向下重劈 → 伞手横伞硬架或侧移让重斩落在护栏/屋面`

- 起跳必须看见支点和离开接触点的瞬间；
- 重斩命中后出现剑臂下沉、伞骨弯曲、伞手膝胯降重心和脚步滑移；
- 环境破坏只沿剑刃落点发生。

### 5. 伞钩挂檐—踏柱逆空追劈

`伞手受击后退 → 反手抬伞让伞钩挂住飞檐翘角 → 手臂拉紧并以摆荡弧线上升 → 剑手踏上湿木柱连续蹬踏 → 每一步改变高度并留下焦痕/水印 → 接近檐口时由下向上逆势劈出 → 伞手松钩、收伞或沿檐横移躲开`

- 墙面奔跑需要连续支点、向上的已有速度或超常能力，不写“违反重力”；
- 伞钩、檐角和手臂形成承力三角，伞不能像绳索一样无限伸长；
- 逆劈未命中时削断檐角并改变下一落脚点。

### 6. 崩伞点刺—粘剑推挡—寸劲截腕

`伞手收拢骨伞当短棍 → 以前手连续三次点向胸腹不同位置 → 剑手后滑并以剑身贴住伞柄外侧 → 手腕翻转让剑身沿伞柄滑移，把第三刺引向身体外侧 → 伞手持械腕暴露 → 剑手空手短距离打击腕部 → 伞柄偏离中线，紫雾或附着效果散开`

- 三次点刺不能击中同一点原地连闪，需配合伞手的小步追进；
- “粘剑”是持续接触下的引偏，不是磁吸；
- 腕部打击只造成疼痛、握力下降或持械线偏转，不声称点穴、截脉或永久失能；
- 下一条件为伞手中门短暂暴露，剑手可进入重击但必须给对手格挡机会。

### 7. 劈顶压伞—屋脊塌陷共同坠落

`伞手腕线被打偏 → 剑手沿屋脊高点跃起 → 双手反握或正握重剑下砸 → 伞手横举伞骨架住 → 双方武器相抵并向屋脊主梁传力 → 主梁先裂后断 → 两人保持接触姿态随断木碎瓦共同下坠`

- 只有结构已受损或能力强度足够时才允许屋脊塌陷；
- 下坠不是新动作起手，必须继承兵器相抵、人物朝向和碎片速度；
- 下一镜可由一方先松开接触、翻身找支点或抓住铁链获得攻击权。

### 8. 伞钩荡钟—贴地滑铲—地堂平削

`坠殿途中伞手翻身 → 伞钩挂住铜钟铁链 → 身体沿铁链摆出半圆 → 双脚在弧线末端踹中钟体 → 铜钟沿切线横扫剑手 → 剑手抢先落地并后仰滑铲 → 巨钟从身体上方掠过 → 剑手在滑行中转腕，让长剑贴地横削伞手落点 → 伞手跳起或收腿避开`

- 铜钟摆动方向由踹击位置与铁链轴决定；
- 滑铲前必须有落地速度和湿滑地面，背部、髋部与脚跟共同稳定低姿；
- 平削攻击脚踝或落脚区，以逼跳和改变高度为目的，不自动命中双腿；
- 未命中时切开积水并留下半月水刃或地面划痕。

### 9. 伞钻追刺—压低反冲—错身平斩

`伞手落地后收伞旋腕，把伞骨形成前向钻刺 → 剑手从滑铲末态收膝起身并压低重心 → 前脚蹬地沿伞钻外侧切线反冲 → 剑与身体共同穿过对手侧面 → 单次水平平斩完成接触 → 双方沿原方向分离 → 剑手临崖滑停`

- 反冲路线避开伞尖正轴，不以更快速度正面穿过武器；
- 平斩只有一次核心接触，不叠加多次看不清的闪击；
- 对手倒下、失衡或继续反击由用户锁定胜负决定。

### 10. 入鞘延迟斩（夸张能力档）

`错身平斩已留下可见斩线/裂痕 → 剑手在安全落脚面减速 → 保持身体稳定完成入鞘 → 剑格闭合成为既有能量释放节点 → 对手与建筑沿同一斩线出现延迟结果 → 雨、碎片、衣袍和坍塌继续运动`

- 只用于角色具有延迟剑气或空间斩能力的设定；
- 延迟结果不能改变原攻击方向，也不能让未接触区域无因同时爆碎；
- 写实任务改为斩击当场出现结果，入鞘只承担声音与情绪收束。

### 11. 蹬佛上行—肩部高位重劈—斜坠砸门

`伞手从庭院突刺逼线 → 剑手侧倾让过并蹬佛像底座 → 双方沿佛身裂缝/衣褶连续踏点上行 → 剑手先到肩部并顿步转身 → 双手高位重劈 → 伞手横举伞骨承力 → 身体沿斜下方向坠向正殿木门 → 门板先弯裂后被撞穿 → 剑手沿同一轴线俯冲追入`

- 佛像表面必须提供连续脚点，跑壁不依靠无因吸附；
- 重劈先让伞骨、肩线和下肢承重，再进入击落；
- 木门破坏方向、人体坠落方向和追击方向保持一致。

### 12. 剑柄倒砸—逼眼让线—肩撞换权

`剑手突入短距并以剑柄向下颌线短砸 → 伞手仰头侧让并以空手掌指逼向眼线 → 剑手偏头避开且保持剑刃离体 → 伞手沉肩前撞 → 剑手以肩胯回撞或侧步引开 → 双方分离半步重新建立兵器线`

- 掌指逼眼用于迫使转头和改变视线，不默认造成眼部重伤；
- 剑柄、剑刃与空手动作保持安全朝向，不能在贴身时无因穿体；
- 一秒镜头只保留两至三次主接触。

### 13. 扫堂失衡—单手撑地踢飞穿门

`剑手由肩撞完成态降髋下潜 → 支撑腿踩实并以另一腿横扫伞手支撑脚附近 → 伞手失衡腾起/侧倒 → 剑手单手撑地稳定躯干 → 转髋把后腿向上送出 → 靴底命中腹部防护区 → 伞手沿门洞轴线飞回庭院 → 剑手收腿起身追出`

- 扫堂先制造失衡，撑地踢随后进入，不把两腿同时执行两个方向；
- 撑地手、肩线与髋部形成稳定支撑，踢击后交代腿部回收；
- 击飞距离服从能力档，写实版本改为跌出门槛或连续退步。

### 14. 旋伞投掷—Z字避线—蹬墙突刺—挑柄卸武

`伞手落地滑退并旋身松手 → 骨伞以可辨实体轮廓沿庭院轴线旋转飞出 → 剑手两次折线换位避开伞路 → 侧身擦过伞缘后蹬墙反向 → 伞手沿回旋路径接回骨伞并举起格挡 → 剑手由墙面反蹬进入最后直线突刺/挑击 → 剑尖由下向上命中伞柄关节或握持弱线 → 骨伞脱手上飞，中门暴露`

- 飞伞的离手、弹道、擦身、回旋与接回完整；无法稳定回收时改为伞撞入固定锚点，再设计徒手或备用武器段；
- Z字换位至少显示两个落脚点和墙面支点，不用残影替代路线；
- 卸武针对伞柄结构或持械线，不声称一击必然击碎任何材质。

## 合理性门禁

- 使用前检查伞的结构强度、角色握持、主战距离、可用支点、湿滑表面、建筑承重和目标时长；
- 一条短镜只选一个主连招，不把十条动作连续塞进单次生成；
- 伞面、伞柄、伞骨和伞钩的功能转换必须通过展开、收拢、换握或挂接动作完成；
- 飞檐、屋顶、铁链和铜钟不是装饰，必须真实改变人物路线或攻击线；
- 原稿的固定冲击帧、强动态模糊和极限时间数值属于表现参数，不是本招式成立条件。
- 佛像垂直路线、屋顶塌陷铜钟路线和飞伞庭院路线按时长选择，不把三套环境连招无条件连续塞入同一短片。
