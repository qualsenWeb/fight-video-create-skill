# 爪刺对臂铠破甲专项

来源：《爪刺武学 VS 臂铠强攻》。

## 距离策略

臂铠强攻以直拳、横臂扫和砸地控制正面；爪刺角色不在拳锋完整发力区硬接，而是交叉爪卸线后贴臂滑入侧翼，攻击关节、甲缝和重心。

## 破甲链

贴地侧闪 → 双爪交叉偏开拳锋 → 沿臂铠外侧刮开表层 → 旋身绕背三次短刺肩背甲缝 → 低扫腿甲破重心 → 踩腿反弹倒挂上撩下颌护甲 → 滑步穿侧勾扯腹甲 → 双爪刺入脊背甲缝形成阶段破防。

## 反扑处理

对手砸地时双爪拍地后空翻越过冲击；连续重拳则以爪尖点打关节让拳线偏转，再抓住结构缝隙沿臂铠滑向胸口。点关节是改变方向，不是用小爪硬停整条重臂。

## 终结接口

双爪勾住已破损胸甲缝，腿髋发力向上撕开并挑飞目标；远程爪痕、残影龙形或雷墨终结必须由角色能力支持。

## 门禁

对手无甲缝、软体目标或无可抓结构时改用躯干划击和关节控制。不得把穿裆、颈部撕裂等高风险动作写成现实教学。
