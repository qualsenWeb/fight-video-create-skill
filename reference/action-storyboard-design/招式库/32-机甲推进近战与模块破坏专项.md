# 机甲推进近战与模块破坏专项

## 来源与使用边界

- 来源：用户提供的机甲题材战斗资料之动作设计层。
- 用途：组织人形机甲的推进突进、刃盾协同、抓取脱困、装甲接缝攻击和功能模块失效。
- 本条处理机体动作与接触结果；武器形态切换的能力状态另由技能库 `08-模块化武器形态切换.md` 管理。

## 机体状态表

进入每轮动作前记录：

- 主推进器与姿态喷口是否可用、推力方向和剩余负荷；
- 左右臂武器、盾、炮管、爪指与关节状态；
- 装甲裂口、暴露导管、过热区和座舱安全；
- 当前支撑面、可承力墙体和坠落方向。

## 执行动作链

### 1. 坠势劈击—蹬甲侧绕—切炮根

`从高位或断桥边缘坠落 → 主刃沿重力方向劈向护架 → 对手爪/盾承受接触 → 机体足部短蹬其护甲 → 侧向喷口点火绕到武器侧 → 刃口攻击炮管根部、弹仓外壳或肩关节`

蹬甲只改变路线，不无因增加主刃伤害。

### 2. 盾沿撞甲—刃从下线进入

`对手大范围横扫 → 机体降姿让过攻击端 → 左盾展开护住头肩 → 盾沿撞击肋侧使躯干偏转 → 主刃从盾沿下方上撩 → 命中因偏转暴露的装甲接缝`

盾和主刃分工明确，不让同一机械臂同时完整展开互斥武器。

### 3. 被抓掼墙—借墙反冲脱爪

`持械腕被机械爪钳住 → 对手将机体掼入残墙 → 背甲与墙体先受力 → 双足踩住可承力结构 → 姿态喷口朝墙内反喷 → 全机拧身让腕部沿爪缝退出 → 脱离时带走已松动爪甲 → 横斩切断追击模块`

若腕关节已严重损伤，改为弃械、断开外接件或由副臂解脱。

### 4. 模块失效—职责转移

`炮管被切开 → 泄压或能量外逸 → 射击精度与蓄能能力下降 → 对手被迫转用近战爪 → 爪张开牵动胸侧甲缝 → 防守方用盾顶住主抓线 → 主刃连续破坏爪指与甲缝`

功能失效必须改变战术，不只增加表面火花。

### 5. 核心终结与安全脱离

`同一甲缝已被两次攻击扩大 → 推进器沿正轴持续顶进 → 主刃贯入动力或控制模块 → 对手机体停止主动发力 → 攻方抽刃并侧向喷离 → 用踢推或盾撞让失效机体远离自身 → 对手按质量与地形倒落`

非致命版本改为切断武器、推进与控制线路，使对手机体失去继续作战能力。

## 环境协同

- 断桥、钢梁、残墙和楼体可用于高差、遮蔽、反蹬或阻断，不作为无限耐久支点。
- 重型机体撞墙后，墙体破坏与机体速度共同变化；不能只破墙而机体不减速。
- 钢梁被斩断或轰碎后，碎片按原方向坠落并影响双方路线。

## 门禁

- 巨型机体动作保留质量感；喷口负责启动与改向，关节负责姿态，不能靠人体式轻跳完成全部位移。
- 已损坏炮管、爪指、喷口和装甲不会通过武器变形恢复。
- 能量刃或高热武器命中后按材料形成切口、熔蚀和功能损伤，不用单次接触无因摧毁完整重甲。
- 座舱、能源核心和弹药区的风险必须服从用户设定的致命程度。
