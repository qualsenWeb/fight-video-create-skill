# 游击射手对重型追击者专项

## 来源与使用边界

- 来源：用户提供的西幻游侠与西部枪手题材战斗资料之动作设计层。
- 用途：为弓、弩、手枪等投射武器角色设计移动射击、掩体换位、局部削弱和被迫近身后的脱离链。
- 本条不规定弹体属性，也不替代具体枪械安全、弹药或弓术训练知识。

## 对抗关系

射手依赖距离、视线和可用弹药；重型追击者依赖覆盖、破坏和迫近。射手的每次射击应承担以下职责之一：迫使偏头、限制落脚、破坏持械、削弱关节、逼离掩体或争取换位时间。

## 执行动作链

### 1. 高低掩体接力射击

`从高位或掩体边缘射击 → 命中持械肩臂迫使攻击偏线 → 立刻离开原位 → 对手破坏旧掩体 → 射手借坠落或侧移进入下一节点 → 回身补射其转向较慢一侧`

射击后必须换位；旧掩体被破坏后不再重复使用。

### 2. 关节累积削弱

`第一发测试外层防护 → 第二发逼迫抬臂或转身 → 第三发命中膝窝/肘弯/持械手 → 对手步幅或挥击幅度下降 → 射手围绕受损侧持续换线`

终结点只能落在已被连续削弱或因动作暴露的部位。

### 3. 投掷物迫离—移动补射

`重型目标投掷残骸或掀起范围攻击 → 射手横向离开覆盖中心 → 在移动末端恢复瞄准 → 击中投掷手或落脚点 → 迫使目标偏离最短追击线`

闪避方向必须避开投掷物后续滚动或坍塌区。

### 4. 武器脱手应急链

`落脚点被破坏或受击翻滚 → 主武器脱手 → 用短兵、踢击或障碍争取一拍 → 沿地面滚向武器而非原地召回 → 捞回后以跪姿或贴掩体姿态完成一次短距反击 → 立即重建距离`

### 5. 双枪或双发射器职责分工

`主手持续压制方位 → 副手覆盖换位间隙 → 主手耗尽或受伤时副手接管枪线 → 退到掩体后完成恢复 → 两者重新分配职责`

不得在跑动、受伤和近身缠斗中无代价保持精确连续射击。

## 门禁

- 每次射击标明目标、目的和对手反应；落空也必须改变路线或掩体状态。
- 弹药、箭矢、拉弓体力和受伤手臂持续计入后续动作。
- 重型目标必须至少一次成功压缩距离或破坏射手节点。
- 射手被逼入近身后，优先脱离和夺回距离，不把长弓或长枪械当作无约束短兵器使用。
