# 剑盾对双持重兵器破架专项

## 来源与使用边界

- 来源：用户提供的古罗马角斗题材战斗资料之动作设计层，并吸收重甲巨剑对抗中的破架关系。
- 用途：处理圆盾或小盾配短剑，对抗双斧、双刀或单件大范围重兵器的防线分配、贴身抢位与弃盾转势。

## 结构化绑定

- `shield_role`：偏转一条主攻击线、撞击重心、遮蔽短剑起点。
- `sword_role`：从盾沿下或重兵器回收侧攻击持械手、腋下、肋侧和装甲接缝。
- `required_space`：至少容纳一次侧滑或绕柱换位；完全贴墙时盾手只能压线突围。

## 执行动作链

### 1. 高低双线拆分

`对手一高一低双击 → 盾面迎向高线并斜置偏转 → 后脚侧滑离开低线 → 短剑从盾沿下刺向腰侧 → 盾沿外翻阻止第二件武器回收`

盾面一次只解决主威胁；低线依靠步法离开，不写成盾牌同时覆盖全身。

### 2. 贴柄进入—盾击重心

`重兵器横扫 → 盾手压低重心贴近柄部 → 盾面护住头肩 → 短剑削持械手腕 → 前脚占住对手转身路径 → 盾沿撞胸或下颌迫其后退 → 短剑继续封住回收侧`

进入点在柄部内侧或挥击末端，不从刃部正面硬闯。

### 3. 借柱消耗大弧攻击

`对手连续大弧抡击 → 盾手退向柱侧而非死角 → 盾牌只接擦碰 → 最后一步贴柱换线 → 重兵器砍入或擦过柱面 → 对手回收受阻 → 短剑攻击肩臂接缝`

柱体损伤持续保留；达到阈值后断裂会改变双方路线。

### 4. 破盾后的职责转换

`重劈使盾面开裂 → 盾手顺震力后倒翻滚 → 用残盾投掷遮挡视线或偏开追击 → 双手改握短剑 → 沿对手劈碎残盾的余势进入持械侧 → 集中攻击同一甲缝`

弃盾后不再获得盾牌防护，动作策略必须从承受转为闪避与抢线。

## 终结接口

`前段持续攻击持械侧 → 对手为重击抬臂 → 腋下或肩甲接缝再次暴露 → 盾手沿斧弧下方进入 → 双手短剑刺入已建立缺口 → 立刻侧移避开兵器坠落`

非致命版本改为刺穿护具固定持械臂、缴械或以盾撞迫使认输。

## 门禁

- 盾面角度决定弹开方向，正面硬接重斧会同时损伤手腕与盾体。
- 双持对手的另一件武器始终保留威胁，不能在第一件被格挡后无因消失。
- 沙地、湿地或碎石会改变侧滑和扎步，盾手失去稳定下盘时不得连续硬挡。
- 装甲弱点必须由结构、前段损伤或动作暴露建立。
