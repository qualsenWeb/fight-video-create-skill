# 天地开界巨兵器专项

> 来源：用户资料《0819紫红》第三、第四段连续提示词；吸收日期：2026-08-21。
>
> 定位：为具备天象级兵器或开界能力的角色，提供裂谷承接、巨兵器降临、插地、地层分离、吸落与闭合的执行级结构。

## 一、结构化绑定

- `required_capability`：角色可建立持续裂谷/能量通道，并操控天象级巨兵器或等效的地层开界力量；
- `primary_range`：跨公里宏观尺度；
- `combat_role`：关键目标终结、地形重构、群体吸落或封印；
- `required_space`：数公里开放地形与清楚的高空/地层尺度锚点；
- `avoid_when`：室内、近身对决、角色没有开界能力、缺少前段裂谷承接，或时长无法容纳完整开合过程。

## 二、连续动作链

`闭合天幕受击 → 裂痕扩张为稳定裂谷 → 巨兵器沿既有轴线降临 → 正面命中关键目标 → 插地冲击 → 二次沉降/能量灌入 → 地层裂纹贯穿 → 两侧大陆级断层分离 → 异界显露 → 吸流拉动目标 → 地层闭合`

裂谷、巨兵器和界门属于一条因果链。巨兵器必须从前段已建立的空间通道降临，界门必须由巨兵器插地或能量灌入产生的地层变化打开。

## 三、基础招式

### 3.1 裂谷贯天

- **功能**：建立巨兵器降临的空间来源；
- **过程**：闭合天幕先出现单一裂痕，云层向两侧撕开，裂口沿横向和纵向持续扩大；
- **限制**：裂谷稳定前不出现巨兵器轮廓，避免来源倒置。

### 3.2 巨兵器垂直压落

- **功能**：锁定关键目标并把高空动量传入地面；
- **尺度**：镜头同时保留普通目标、山岳级目标与巨兵器，证明体量关系；
- **接触**：先完整读清下压路径，再以极短冲击帧强调正面命中；
- **限制**：不能退化成细光柱、普通巨剑或画外爆炸。

### 3.3 插地二沉

- **功能**：将巨兵器的剩余动量转为地层能量；
- **动作**：初次插地后保留露出地表的巨大主体，能量沿兵器结构压缩，再二次向地下沉入；
- **反馈**：雪原下陷、黑岩放射裂开、冲击环贴地扩张；
- **限制**：第一次爆破未完成前不抢先打开界门。

### 3.4 大地开界与吸落

- **功能**：把地层裂缝升级为异界入口并清除剩余群体；
- **过程**：`裂纹贯穿 → 两侧断层抬升 → 地层分离 → 内部世界显露 → 小目标滑动腾空 → 重型目标犁地抵抗 → 全体坠入`；
- **限制**：界门是大地本身打开，不使用小洞、圆形法阵或建筑门框替代。

### 3.5 地层闭合

- **功能**：结束吸落并收束宏观环境；
- **动作**：两侧地层回拢、碰合，最后余光和吸流收缩熄灭；
- **结果**：仅在闭合后安排施术者安全落点或余波收势；
- **限制**：已被终结的关键目标不得无因再出现。

## 四、门禁

每个宏观镜头都检查尺度锚点、攻击轴线、地形连续性和角色安全。一个短段只保留一次主要开界与一次主要闭合，避免多套末日机制竞争结尾。
