# 双唐刀高频绞杀专项

来源：《双刀武器通用战斗提示词》。原文重复段落已去重。

## 双刀分工

前手刀用于封线、格挡、黏压和短刺；后手刀用于横斩、反撩和补击。双刀不能长期完全同步，否则失去攻防层次。

## 动作链

双刀合劈压开护架 → 左右分斩扩大防守角度 → 垫步双刺逼退 → 一刀架住重击、另一刀反撩 → 交叉锁刃短时控制 → 旋身回斩脱离攻击线 → 反手双斩覆盖两侧 → 凌空双刀下劈或落地合斩终结。

## 一打多变体

以交叉刃网控制正面一至两人，旋身时只让一把刀承担主要攻击，另一把保护侧后。敌人攻击权重叠接力，主角沿缺口移动，不在原地双刀乱舞等待敌人进入。

## 门禁

双刀交叉绞杀必须有明确目标，如敌兵器、护架或装甲缝；不得写成剪刀式无接触光效。复杂连段优先中景读取双臂和刀轨。
