# 陌刀七式刀腿连招专项

来源：《陌刀七式》。招式名称按资料保留，执行时服从武器重量和时长。

## 七式

1. 力劈华山：双手举刀过顶，沉髋下劈肩线；可接低扫腿绊脚，但两者不能同一瞬间争用重心。
2. 横扫千军：前脚外开、转髋带长柄横扫腰腹；落空后必须顺势转步，避免过度暴露后背。
3. 倒卷珠帘：利用横扫余势旋身反撩，从低位挑向兵器或躯干。
4. 力拨山河：双手调整握距，身体旋转带刀划圆弧，用于逼退和重建距离。
5. 突刺穿云：刀尖沿中线直刺胸腹；可在对手后撤时接垫步或短飞踢，但不能持重刀长时间凌空。
6. 撩刀望月：刀尖自下向上挑开护架或下颌线，近身可接膝撞。
7. 砸刀镇岳：用刀背或刀身重砸肩甲、武器或地面落点，命中后形成明确击退。

## 升空与终结

撩刀升空仅适用于超常能力档，由下向上重击把目标送入空域；追击者借地面、武器反力或能力升空。凌空三斩每击必须继续改变目标高度，最后再以垂直重劈送向地面。

## 门禁

普通人体不可在1秒内无惯性完成七式；短视频应选3至4式形成主链。刀腿混用时腿法只用于破重心或近身补击。
