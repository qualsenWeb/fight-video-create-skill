# 14-竹林刀剑环境借力连招专项

## 来源与使用边界

- 来源：用户资料《竹林打斗.docx》，吸收日期2026-08-22；
- 用途：为刀剑角色在密竹林中的俯冲、滑行、绕竹、蹬竹升层、倒挂俯冲、暗器封线和纵深错身提供执行级动作链；
- 下述名称用于检索和编排，不冒充传统武术定名。五次空中格挡、三周空翻和0.5秒七次攻防均按角色能力与时长降级。

## 结构化绑定

- `weapon_binding`：单手刀、横刀、长剑或长度相近的可控兵器；
- `required_space`：可承力竹干、横枝、湿泥落点和至少一条纵深穿行廊道；
- `primary_range`：近身为主，短程刀气或暗器只用于封线；
- `required_capability`：普通档需优秀平衡与跳跃能力；跑竹、倒挂俯冲和环形断竹需高机动或超常能力；
- `avoid_when`：无可见支点、竹干过细无法承力、目标时长只够一次挥砍，或纯写实角色被要求长时间滞空。

## 执行级动作与连招

### 1. 高位俯冲—贴地横滑—低扫反追

`高位剑手从竹梢/横枝蹬离 → 身体与剑线沿斜下方向压向地面目标 → 地面刀手降髋并横向滑出落点 → 剑气或剑锋砸入原位置 → 刀手从滑行末态沿贴地圆弧反扫 → 高位者落地后沿反扫外侧追入`

- 滑行必须离开垂直落点，肩、髋和脚保持可控低姿；
- 砸地点先出现局部泥水和断叶，不能用全屏爆炸遮住反扫；
- 结束态为双方进入同一竹干附近，可衔接绕竹换位。

### 2. 蹬竹回身满月斩—贴地绕背—拍竹下劈

`刀手单脚蹬竹让竹身弯曲 → 借回弹转髋回身 → 刀刃沿水平大圆弧封住前方 → 剑手降重心贴地从圆弧下方/外侧滑过并绕到竹后 → 刀手用空手拍竹或第二次踏竹升高 → 拧腰从上向下劈向剑手新位置 → 剑手后翻退出落点`

- 绕背路线必须经过竹干外侧，不能以切镜瞬移到身后；
- 满月斩与下劈共享同一竹干支点，不再额外叠加第三次无功能旋转；
- 未命中时分别留下竹叶气流和地面刀痕，证明两条攻击线。

### 3. 枝间升层—分拍格挡—折枝对冲

`双方分别踏上相邻竹干/横枝 → 每次蹬踏改变高度 → 进攻方以两至三道短程剑气封住上升路线 → 防守方用刀身偏转并更换落脚枝 → 承重枝条在最后一次蹬踏后折断 → 双方利用离枝动量相向冲刺 → 刀剑完成一次重接触后分离`

- 原稿“五发五挡”改为按时长选择二至三拍；
- 每次格挡都要改变刀角、身体朝向或落脚点；
- 折枝发生在最后一次承重后，断枝继续下落，不跨镜恢复。

### 4. 倒挂枝头俯冲—仰身滑行—横刀上挑

`剑手以膝弯/脚背或能力短暂固定横枝 → 上身倒悬确认地面目标 → 松开支点并沿垂线俯冲直刺 → 刀手仰身贴地滑出剑尖轴线 → 滑行中转腕让刀刃由下向上挑向对手侧腹/兵器线 → 剑手收剑、侧转或翻滚卸力落地`

- 倒挂只作为短促起势，不能静止展示；
- 上挑从滑行末态进入，刀手不能无因从仰躺瞬间站立；
- 下一条件为双方在地面错身，可进入短链或再次利用竹身。

### 5. 暗器封竹—未封侧反蹬—侧后横切

`剑手后撤并连续投出少量飞针/暗器 → 暗器沿两至三条线钉入目标周围竹干 → 刀手侧移避开并识别未封通道 → 单脚踏向未被暗器占据的竹身 → 竹干回弹把身体送入侧后切线 → 刀刃沿水平线攻击剑手后侧防区 → 剑手翻滚、侧扑或回剑格挡`

- 暗器数量服务封线，不用满屏针雨替代空间设计；
- 每枚关键暗器有发射方向、钉入位置和残留状态；
- 反蹬不得穿过已被暗器封死的路径。

### 6. 重接触弹开—双竹反蹬—纵深错身

`一次可读刀剑重接触 → 双方沿相反方向弹开 → 各自在明确竹干落脚 → 脚掌压弯竹身并短暂停留至回弹点 → 同时离竹沿纵深廊道加速 → 兵器在中央完成单次交错接触 → 双方继续原方向分离并保留攻击轴`

- 第二次冲刺由竹干回弹和前段分离距离共同成立；
- 错身只有一次核心接触，结果由用户锁定胜负决定；
- 环形断竹或大范围冲击波只用于明确超常终结。

## 合理性门禁

- 先检查竹干直径、弯曲幅度、横枝承重、落脚面积、湿滑程度和目标时长；
- 一条短镜只选一个主连招，快速攻防用清楚的两三拍替代不可读次数；
- 竹身遮挡用于接力，不隐藏关键接触；
- 空中旋转来自蹬地、收膝、转髋与支点回弹，不以“残影”替代发力过程。
