# 竹林刀剑多层借力追击导演方案

## 适用边界

适用于密竹林、竹谷或具有大量可反蹬竖向支点的东方刀剑双人战。双方至少具备高机动轻功或风格化能力，能够在地面、竹干、横枝和竹梢之间连续换层。竹林必须真实改变动作路线，而非只做绿色背景。

不适用于低机动写实格斗、无支点空中悬停、纯远程站桩对轰，或短到无法交代起跳与落点的单镜头。原稿中的五次空中格挡、0.5秒七次攻防和三周空翻属于高能力与高帧率档，不作为默认速度。

## 导演脊柱

`竹梢俯冲抢先手 → 地面滑行反扫 → 绕竹换位 → 蹬竹升层 → 枝隙短交换 → 倒挂俯冲与贴地反制 → 暗器封线后借竹改向 → 地面近身重接触 → 双方弹开 → 纵深廊道二次加速 → 错身终结与竹林余波`

战斗的核心不是连续旋转，而是每次竹身接触都改变高度、方向或攻击权。相同职责的绕竹、蹬竹和空翻不能重复堆叠。

## 借力与换层纪律

- 蹬竹前先让脚掌贴住竹面，竹干向受力方向弯曲；角色离开后竹干回弹并指出新方向；
- 绕竹时把竹干当作短暂视觉轴，双方分处竹身两侧，重新出现后保持原有追逃关系；
- 倒挂需要腿弯、脚背或明确能力锁住横枝，松开支点后才进入俯冲；
- 枝间格挡只保留能够读清的两至三拍，其余连续攻击用轨迹和环境反馈概括；
- 暗器钉入竹干后成为封线路标，下一次反蹬不得无因穿过已封死通道；
- 纵深对冲前先用全景建立两人的分离距离、廊道和终点，再以加速而非随机切镜制造冲击。

## 攻防组织

1. **俯冲与滑行**：高位攻击者以重力压落，地面防守者沿横向滑出攻击轴并从低位反扫；
2. **绕竹夺背**：反扫迫使高位者落地，双方利用同一竹干前后换线，避免瞬移式背刺；
3. **地空交换**：一方通过蹬枝上升，另一方沿相邻竹干追入；远程刀气只用于封线或逼位，不替代身体路径；
4. **倒挂反制**：倒挂俯冲把攻击线变为垂直，防守者以仰身滑行和上挑让攻击者越过；
5. **暗器与反蹬**：暗器先压缩可走通道，受压者再利用未被封锁的竹干反蹬切入侧后；
6. **终结接口**：一次可读重接触把双方弹向相反方向，竹干回弹提供二次冲刺的共同触发，错身结果沿既有交战轴发生。

## 镜头策略

- 地面俯冲用中全景或低位广角交代高度与落点，接触瞬间再短沉；
- 绕竹采用侧向弧线跟拍，竹干短暂划镜，不持续鱼眼环绕；
- 升层使用垂直跟随或远侧全景，复杂格挡期间稳定摄影机；
- 倒挂俯冲使用一个倒置建立镜头，随后回到正常地平，避免连续翻转令方向失真；
- 暗器段先以侧面全景显示发射轴与钉入位置，再选择一次贴刃/贴刀主观镜头；
- 终局高空俯拍只在错身完成后使用，用于显示冲击传播和竹林结果。

## 特效与生成门禁

- 黑墨与青金效果分别绑定人物、兵器、接触点和既有轨迹，碰撞后恢复清楚归属；
- 轻接触用刃口偏转、少量粒子和竹叶气流，重接触才选短冲击帧或镜头回弹；
- 全屏负片、鱼眼和环形冲击波只服务唯一终结；
- 竹叶、泥点、墨雾和动态模糊不得遮住支点、脚步和刀剑接触；
- 每次折竹、断枝、泥沟和暗器落点跨镜保留；
- 写实档把环形断竹降级为局部断枝与竹干弯折，把多周空翻和极限换招降为一次明确折返。
