# 荒野枪剑双雄冷暖特效对决导演方案

## 适用边界

适用于开放平原、荒野、沙地或草原中的一打一兵器战，尤其适合长枪对剑等主战距离不同的异质兵器组合。剧情需要同时包含人物亮相、空间关系建立、近身高速缠斗、短暂拉距聚势和双方终极能力正面对撞，并以不同材质或色彩区分两名角色。

不适用于纯写实无能力战、仅需单镜头短动作、纯远程站桩放波或要求逐招武学考据的任务。时长不足十秒时，应压缩为“建立方向—一轮缠斗—一次对撞”，不要机械保留七镜。

## 导演脊柱

`单人低机位亮相 → 横移揭示远方对手 → 纵深关系转左右对峙 → 先手突进与枪剑换招 → 多机位换位缠斗 → 拉开身位并行聚势 → 大全景双能力对撞与动态余波`

原案例约16.8秒，七段职责分别为：

1. 低机位从衣角抬升，以单人全身和视线方向建立先手角色；
2. 摄影机沿视线横移，在远端纵深位置揭示对手，形成一近一远；
3. 小幅回旋把纵深关系平滑改写为A左B右的横向交战轴；
4. 长兵器角色先手突进，双方以短链完成第一次近身攻防；
5. 用完成态切镜延续换位、距离争夺和攻防权交换；
6. 交手对冲后拉开距离，聚势与环境变化同步发生；
7. 大全景容纳两种能力的正面对撞、爆发范围与环境余波。

## 空间与观察轴

- 起点为近处持枪者，远端视线方向为持剑者揭示点，中央开阔区为近身交锋锚点；
- 第三段完成纵深转横向后，默认保持持枪者在左、持剑者在右；越轴必须用正面、中性俯拍或遮挡转场重新建立；
- 长枪通过枪尖封线和枪杆横扫维持中距，剑手通过偏转、切线和贴杆进入内圈夺取近距；双方换位必须来自攻击、格挡、卸力或受击；
- 拉开身位不是无因瞬移：必须由一次兵器对冲、格挡弹开或双方主动撤步形成，并保留后退方向和落脚结果；
- 终极对撞切至大全景后，仍保留双方、能量起源点、碰撞中心和地面尺度锚点。

## 枪剑缠斗规则

原文提供的是动作类别和导演节奏，不是完整武学招式资料。执行时按以下因果补全，但不得把补全内容伪称原文招式：

- 持枪者的直刺、横抡、挑枪、横扫和回身戳刺拆成不超过三招的短链；每招明确枪尖或枪杆轨迹、封锁目的和剑手响应；
- 剑手以斜斩、点剑偏转、撩剑卸力、反手刺或腾空下劈改变枪线，不在长枪有效距离内无因硬抗；
- 贴身后必须处理长枪回收困难：剑手沿枪杆切入，持枪者转髋用枪杆或枪尾截击并重新夺回中距；
- 每次重接触至少出现武器震颤、腕臂偏转、肩线下沉、脚步滑移或尘土炸开中的一项；
- 拳脚只作为贴身距离内的连接动作，不能取代双方兵器动作签名；
- 多机位快切落在格挡完成、横扫落空、脚步换位或受击滑移等完成态，禁止在兵器尚未接触前切断动作。

## 双特效分工

- 角色A可绑定水墨、烟气、墨浪或干湿墨拖影；角色B可绑定金色粒子、鎏金光尘、粒子刃或剑域；具体色材质服从用户设定；
- 轻动作只保留短轨迹和少量粒子，重接触才出现局部冲击帧或气浪，终结阶段才扩展为环境级效果；
- 两套效果从各自武器或身体动作起源，碰撞时只在接触界面混合，不得互换角色归属；
- 冲击帧用于少数关键重击，不默认每次碰撞都插入，以免节奏机械、遮挡接触并造成频闪；
- 聚势阶段允许0.8—2秒，但必须同时发生后退站稳、能量汇聚、地表纹路或周围草尘受力，不能只站桩发光；
- 终极能力必须保留“起源—扩张—接触—对冲—余波”链路，不能用全屏爆光跳过中间碰撞。

## 镜头纪律

- 亮相与空间建立可慢，进入缠斗后动作越复杂镜头越稳定；近身多招优先侧面双人中景或中广景；
- 低机位、横移、回旋、推镜和后撤各自承担单一职责，不在同一短段堆叠多种主运镜；
- 环绕只用于对峙重建或低动作密度聚势，不在复杂枪剑接触时持续360度环绕；
- 关键接触时保持兵器交点清楚，碰撞之后再震镜、甩镜或后撤；
- 最后一镜的快速后撤以容纳冲击范围为目的，终点需同时看见人物尺度、对撞中心与向外扩散的余波。

## 生成门禁

- 枪、剑的长度、握持和左右手连续，不穿体、不变形、不无因换手；
- 人物不可因快切重置到初始站位，上一镜的姿态、方向、速度和余波成为下一镜起点；
- 运动模糊只留在边缘和轨迹，人物轮廓、兵器接触点与受力方向保持可读；
- 不把“60帧、8K、全程快切、每击冲击帧”等案例参数升级为所有任务的通用硬规则；
- 大招对撞不等于既定胜负；胜负、受伤和结尾必须服从用户锁定事实；
- 最后一帧保留冲击波、草尘、碎石、衣摆或摄影机后撤中的至少一层运动。
