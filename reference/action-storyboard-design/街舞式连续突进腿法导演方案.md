# 街舞式连续突进腿法导演方案

来源：《10秒街舞格斗腿法·连续突进突袭战》与《霜月剑姬·冰封沧溟》。只提炼可迁移的腿法调度和镜头规则。

## 定位

用于单人以腿法为主的1v1高速压制。动作母题为：贴地切入 → 支撑腿法升层 → 换位连踢 → 对手反扑中同步闪避反击 → 俯冲终结。

## 动作结构

1. 滑铲降低重心进入下盘攻击线，左右腿横扫迫使对手抬脚或后移。
2. 单掌撑地承接滑行动量，髋部旋转带出低位与高位二段横踢。
3. 落地脚尖点地折线变向，后旋踢、扫堂腿与腾空横踢交替改变高度。
4. 对手以拳、肘或重武器反扑时，腿法角色通过倒立侧踢、空中格挡或侧身飞踢在同一动作中闪避并反击。
5. 终结由先前下盘破坏或护架偏转形成窗口，再使用连续俯冲飞踢或旋转重踢。

## 摄影规则

复杂腿链优先全身中景或全景；接触点可短切腿锋和护架，但不得连续只拍腿部。镜头沿人物运动方向平行跟随，撑地和腾空时短促降低或抬升；360度环绕仅在空间已建立且动作链简单时使用。

## 门禁

撑地踢需要可承力地面；滑铲需要已有速度和可滑表面；连续腾空必须由蹬地、反弹或对手接触提供动量。不得把舞蹈姿态写成无接触表演，也不得用残影替代脚掌落点。
