# 双人分层协同清军导演方案

## 一、适用边界

适用于两名同阵营角色在开放山谷、废墟、城墙或其他具有明显高度差的战场中，对多层敌群进行协同清场。核心不是两人同时出招，而是让两名角色承担不同空间职责，并通过威胁交接、短暂救场和末段合击形成连续战斗。

适用条件：

- 两名角色属于同一作战目标或至少有明确协作关系；
- 地面、中层和高空敌人承担不同威胁职责；
- 两名角色拥有不同但可互补的攻击线、移动方式或属性媒介；
- 场景能同时容纳至少两个高度层和一条可读的交接路线；
- 时长足以表现分工建立、威胁升级、救场或交接、合击结果。

不适用于敌对双人远程追逐、两人并肩站桩对波、单人清群、无法交代高度差的狭窄空间或没有明确协作目标的多人混战。

## 二、核心协议

全段围绕：

`分层就位 → 各自清理职责区 → 敌方交叉施压 → 一方进入危险窗口 → 另一方沿可读路线救场/交接 → 双方回到分层 → 末段合击 → 合击余波分区收束`

双人协同必须改变至少一项：敌方威胁方向、角色位置、攻击权、可用路线或能力阶段。单纯同框、同色特效和同步挥剑不构成协同。

## 三、分层职责

### 3.1 地面层

地面角色处理步卒、盾阵、长枪、残柱和沟壑附近的近地威胁。动作以贴地突进、横向切线、低位破口、借柱换向和短距回撤为主。每次清场要为下一次移动留下真实通道，而不是把敌人从画面中无因抹除。

### 3.2 中高空层

空中角色处理飞骑、远射、投射物或高处节点。动作以俯冲、横移、拉升、借敌或地形反力和斜向压制为主。空中路线必须保留起点、换向点和落点，不能用瞬移掩盖救场距离。

### 3.3 交接区

中线或两层之间设置短暂交接区。交接可以是地面角色把威胁推向空中、空中角色切断来袭火力，或双方攻击线在同一目标附近短暂相交。交接完成后必须显示谁获得攻击权、谁退回原层以及敌方剩余威胁。

## 四、三段结构

### 第一段：分区建立

先用宽景别同时建立两名角色、敌群高度和战场纵深。地面角色清理近地破口，空中角色压制中高空单位；两人的运动方向不能互相遮挡。段尾用一次俯视或斜向贯穿镜头确认分层关系，并留下足以迫使下一段升级的敌方火力。

### 第二段：威胁交接

敌方通过夹击、交叉射线、飞骑俯冲或侧翼补兵压缩其中一人的路线。危险必须先由敌人动作和角色受限状态建立，再由另一人进入救场线。救场攻击要切断具体威胁，被救角色要沿明确落点、缺口或反力路线脱离，不能原地消失。

救场后两人不得长时间并肩摆拍。镜头应记录救援造成的缺口、敌方队形变化和双方重新分层的方向。

### 第三段：同轨合击

只有在前两段已经建立各自的能量存量、攻击方向和共同目标时，才进入合击。两种能力可沿同向环轨追逐、首尾咬合、压缩成单一推进体，再沿目标边缘完成扫荡。合击是同一能量链的连续变形，不是多个独立大招同时叠加。

合击后必须保留地面与空中的分区结果，例如沟壑、焦痕、冻结区、残柱断裂和持续余波；不能因大招结束而全场复原。

## 五、协同动作门禁

1. **同框有目的**：同框只服务救场、攻击线交接、共同目标确认或合击，不用作无因英雄站位。
2. **救场有威胁**：先显示被救者面对的具体来袭方向，再显示救援者的进入轨迹和接触结果。
3. **角色有退路**：被救者必须获得可读的逃离落点、遮挡物或反力来源。
4. **分工不排队**：两名角色可以同时行动，但攻击区域、目标和高度必须不同；禁止轮流清除静止敌人。
5. **交接可追踪**：攻击线从一人转给另一人时，至少保留目标、方向、速度和受击结果中的三项连续证据。
6. **合击有存量**：合击形态必须来自前段已经出现的两种媒介，且明确由一次发令或接触触发。
7. **合击有唯一职责**：合击只承担一次主要清场或终结，不在其后追加同职责的第二套全屏大招。

## 六、空间与镜头

- 开场使用中广或广角同时读取地面/空中分层，避免先拍一人再让另一人无因出现；
- 地面段以低角度、绕障碍和斜向跟拍读取脚步、支点和近地攻击；
- 空中段以侧面或俯角读取俯冲、拉升、飞行目标和落点；
- 救场时摄影机沿救援攻击线移动，结尾落在被救角色的逃离点或敌方受击区；
- 合击前短暂后撤重建两人、目标和攻击轴，合击中简化摄影机运动；
- 新镜头至少继承人物高度、攻击方向、目标分布、能量形态和环境余波中的四项；
- 特效不能遮挡两名角色的轮廓、攻击线和接触点。

## 七、时长模板

### 15秒三段式

`0—5秒分层建立 → 5—10秒交叉施压与一次救场 → 10—15秒同轨合击和余波`

### 30秒扩展式

`0—8秒建立高度与职责 → 8—16秒各自清场并让敌方补位 → 16—22秒救场/交接 → 22—27秒合击准备 → 27—30秒单一合击结果`

若时长不足，优先保留分层建立、救场结果和合击来源，删除重复清场镜头，而不是压缩成无动作来源的瞬移串联。

## 八、生成门禁

- 两名角色是否始终有不同高度、目标或攻击线；
- 同框是否具有救场、交接或合击目的；
- 救场是否交代威胁、救援路线、接触结果和逃离落点；
- 双方是否在救场后回到可读的分层关系；
- 两种能量是否各自绑定角色，并在合击前保持归属；
- 合击是否由已建立的媒介和动作触发，且只保留一个主结果；
- 敌群、残骸、沟壑、烟尘和余波是否跨段继承；
- 是否避免敌人排队、角色并肩站桩、无因闪现和全屏特效遮挡。

## 九、与相近方案的区分

- 同阵营双人分层救场与合击使用本方案；
- 敌对双方持续远程追逐、封线和对冲使用双剑修纯远程剑气追逐方案；
- 单名剑修对三层军阵使用单剑修三层军阵饱和水刃清场方案；
- 群体飞剑由单一控制中枢统御时使用群体飞剑鱼群化方案；
- 具体水刃、黑雾或其他属性剑气的身体路径另行检索对应招式专项。
