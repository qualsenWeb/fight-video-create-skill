# 双剑修纯远程剑气追逐导演方案

## 一、适用边界

适用于两名具备剑气外放能力的持剑角色，在废墟、山谷、断崖、建筑群或其他开放多层空间中持续高速换位，并通过远程剑气完成追击、封线、反击、对冲和阶段终结。

本方案的决定条件：

- 双方各自持有可稳定挥斩的剑类武器；
- 主战距离为中远程，攻击主体是由挥剑触发的剑气；
- 双方都能一边移动一边连续攻击，不站桩轮流放招；
- 场景具备可借力、遮挡、破坏和跨区转场的空间锚点；
- 剧情需要双目标关系、弹道攻防和追逐路线同时可读。

不适用于近身拼剑、群体飞剑清群、普通剑客无剑气能力、单人演武、狭窄室内或只有一次简单出剑的短镜头。

## 二、纯远程战斗协议

### 2.1 攻击映射

每一次有效挥剑对应一道可辨认剑气。必须写清：

`持剑姿态 → 身体发力与剑刃轨迹 → 剑气从剑刃方向脱离 → 飞行路径 → 对手响应 → 命中/落空/对冲 → 余势与下一击条件`

剑气不是独立法术光团。挥剑方向、剑气刃面、飞行方向和落点保持一致，武器不能静止而剑气凭空连发。

### 2.2 攻防方式

纯远程不等于双方隔空轮流输出。每轮短链至少包括：

1. 一方用直线、扇形、交叉或高低错层剑气封锁路线；
2. 另一方通过横切、下沉、借力升空或改变高度脱离主弹道；
3. 防守动作尚未结束便从新角度反射剑气；
4. 原攻击方被迫继续换线、对冲或用环境遮断；
5. 两人的位置、攻击权或地形状态至少改变一项。

允许剑气对冲、擦身掠过、命中地形和远程格挡；禁止实体兵刃接触、身体接触和为了制造冲突而短暂切成近身战。

### 2.3 距离与压力

- 用持续压缩或拉开距离表现追击关系，不靠口头声明“追击方”；
- 强压方可用多层封线迫使目标进入预设地形，防守方通过切线反击夺回主动；
- 双方距离变化要有镜头和地标证据，不能靠人物突然变大或变小冒充跨场位移；
- 大招前可以短暂拉开，但拉开过程仍保持攻击或威胁，不进入静态对峙。

## 三、空间路线与地形借力

先设计路线，再填剑气。推荐从以下动作中选择与场景匹配的组合：

- **蹬柱接力**：连续点踏不同高度柱顶，借反力升空或折向；
- **踏壁折返**：沿垂直表面横移后蹬壁改变俯冲方向；
- **屋顶跑酷**：沿屋脊疾驰、蹬檐、跨隙并在落足时继续挥剑；
- **贴地折返**：沿地面做大尺度S形或V形切线，利用沟壑和残骸遮断弹道；
- **空域换层**：由明确起跳、反蹬或上一段动量进入垂直拉升和大角度俯冲。

角色升空和变向必须有来源。脚部接触点伴随碎石、瓦砾、尘线或表面剥落；禁止无接触漂浮、无因瞬移和在同一小区域反复抖动。

## 四、双属性差异化

角色差异应由攻击材质、弹道行为、命中结果和移动习惯共同建立，而不只换颜色。

### 4.1 角色A模板

- 主体介质可为水、冰、风、光或其他流体化属性；
- 附着效果沿服装结构、手臂发力链、剑身与剑气根部传递；
- 可偏宽幅直线压制、连续水刃或垂直重柱；
- 命中后留下与介质匹配的水渍、冰晶、切痕或扩散路径。

### 4.2 角色B模板

- 主体介质可为雾、焰、雷、砂或其他体积化属性；
- 附着效果同样锚定服装、剑身和挥剑瞬间；
- 可偏弧形封线、黑雾刃、俯冲重斩或横向潮压；
- 命中后留下焦痕、余烬、烟迹、侵蚀或对应材质反馈。

属性组合由用户设定。本方案不固定水系与黑雾、男女身份、阵营颜色或命名武器。

## 五、剑气碰撞与破坏

### 5.1 碰撞层级

- **掠过**：形成短促风压、尘线、浅痕和人物局部衣料反馈；
- **对冲**：先压缩介质，再产生方向明确的流体炸裂、蒸汽、碎屑或环形冲击；
- **命中地形**：从表层裂纹和崩角开始，按攻击体量升级为沟壑、断裂或结构倾倒；
- **命中角色**：先建立攻击路径、闪避失败或防御崩解，再给受力方向和后续失衡，不能无因直中。

不同属性相遇时只保留一项主要反应，例如水火汽化、雷沿湿痕扩散、烈焰点燃雾中颗粒；不要同时叠加所有反应遮住剑气结构。

### 5.2 命中连续性

每次破坏都为下一动作提供条件：残柱断裂改变路线，地面沟壑迫使起跳，蒸汽短暂遮断观察，飞石成为前景速度证据。禁止爆炸后场景无痕复原，也禁止每一击都升级成同等规模终极爆炸。

## 六、镜头系统

### 6.1 双目标锁敌

- 宏观镜头同时保持双方、中央弹道区和至少一个地形锚点；
- 跟随一方时，另一方可位于远景、画框边缘或由攻击来源证明位置，但不能长期脱锁；
- 双方交叉换位后重新确认屏幕方向，避免追击者和被追击者身份互换；
- 镜头具备加速、过冲、刹停和回弹，模拟ACT跟拍惯性，但画面不得出现UI、血条或技能图标。

### 6.2 景别职责

- **14—18mm超广角**：建立全域追逐、角色尺度和攻击距离；
- **24mm贴地跟拍**：用前景残骸和尘线证明速度；
- **固定低角度仰拍**：读取上下层换位与空域剑气网；
- **35—50mm中近景**：读取一次关键挥剑、手部发力或面部决策；
- **主观镜头**：只在终极威胁或弹道逼近时短暂使用，避免持续眩晕。

### 6.3 划镜纪律

宽幅剑气可在近处掠镜形成瞬间墨痕、流体或属性遮挡，用于连续运动转场。每次划镜必须短于核心动作，遮挡结束后立即恢复人物、武器和攻击方向；不能用长时间填屏掩盖动作缺失。

## 七、短时节奏骨架

### 7.1 8秒压缩结构

`0—2秒 全域启动与首轮对射 → 2—4秒 贴地或屋顶跨区追逐 → 4—6秒 高低层换位与剑气网对冲 → 6—8秒 锁定一方爆发追拍并留下未决压力`

只安排一个短特写。眼部和手部特写不能同时占用过多动作时间。

### 7.2 10秒升级结构

`0—2秒 超广角追逐 → 2—4秒 地形借力与重剑气闪避 → 4—6秒 空域对冲夺权 → 6—8秒 双向拉开并建立终结前摇 → 8—10秒 唯一大招或临界威胁`

最后两秒只选择“明确命中与层级破坏”或“第一视角临界袭来”之一，不同时装入蓄力、命中、核爆、拉远和定格等多个结尾。

## 八、生成门禁

交付前检查：

- 双方是否始终是持剑角色，剑气是否由每次挥剑触发；
- 是否保持纯远程，没有实体兵刃或身体接触；
- 每轮是否包含攻击、响应、换位和反击，而非轮流放波；
- 大范围位移是否跨越不同地形锚点并保留接触反馈；
- 双目标关系、攻击来源和追击方向是否始终可读；
- 属性效果是否锚定服饰、剑身、剑气根部、落点或裂痕；
- 剑气碰撞是否保留结构，未被全屏粒子和爆光吞没；
- 地形破坏是否由落点触发并影响下一动作；
- 近镜划过是否短促且不遮住核心人物；
- 8—10秒是否只保留一个主要高潮和一种结尾逻辑。

## 九、来源观察

来源案例为即梦-720 三段一次生成后剪辑的提示词：第一段8秒，第二、三段各10秒。作者认为整体节奏不满意且未继续修改，并分别提出第一段开头交锋可修、第二段末大招可替换、第三段直出但个人不满意。因此本方案只吸收纯远程追逐、双目标锁敌、地形借力、属性剑气和层级破坏机制，不把原镜头数量、参数堆叠、近身片段或节奏效果当成已验证通用方案。
