# 骨伞近战转修罗巨掌镇压导演方案

## 适用边界

适用于角色的伞类兵器既能展开防守、收拢点刺，也能作为召唤或法相媒介。前半段为高速双人近身兵器战，后半段为单次巨掌镇压终结。目标必须具备法相、空间裂隙或同等级能力，场景需容纳高柱、开阔祭坛与巨掌落点。

不适用于普通雨伞、纯写实剑术、全程只能近身的设定，或没有时间交代法器离手、雾、裂隙和巨掌来源的短镜头。

## 冲突裁决

原资料同时要求“全程高速近身、无隔空对波、无长时间蓄力”，又安排法器盘旋、裂隙撕开和巨掌镇压。入库后拆成两个阶段：

1. **近身争权阶段**：俯冲对点、旋伞卸力、收伞直刺、挂腕与踢击，位移由脚步、坠落和反作用力完成；
2. **超常终结阶段**：重击拉开安全距离后，骨伞离手释雾并成为法相媒介。裂隙和巨掌只执行一次终结，不再宣称全程近身。

写实任务停在踢击、击退或兵器破绽，不启用第二阶段。

## 动作脊柱

`高柱压迫亮相 → 俯冲伞尖与上迎剑尖建立第一次重接触 → 落地横斩与旋伞卸力 → 收伞直刺逼退 → 剑手下劈 → 伞柄挂腕破坏重心 → 转身侧踹形成分离 → 骨伞离手盘旋释雾 → 雾中裂点扩大 → 双手沿相反方向撕开空间 → 法相轮廓与巨掌建立 → 目标承压 → 单次向下镇压 → 地面与烟尘结果`

## 近身段纪律

- 伞尖与剑尖对点属于高精度风格化动作，先交代共同轴线，接触后双方武器都要偏转或回弹；
- 展开伞面卸力依靠倾角和旋转把横斩导向侧方，持伞者同时后滑，不能让伞面静止吞掉冲击；
- 收伞直刺前必须出现合拢或换握，伞骨不在展开与长矛形态间瞬变；
- 伞柄挂腕只在剑手下劈已形成向下动量、腕线进入可挂距离时使用；
- 侧踹从挂腕造成的肩线和重心偏移进入，命中后建立足够分离距离供法器段启动。

## 法相段纪律

- 骨伞先离手并保持可辨认轮廓，青雾从伞骨、伞面或旋转轨迹释放；
- 雾中先出现单一裂点或裂缝，再由两只同源巨手沿相反方向撕开，不能直接跳到完整法相；
- 法相面具、双眼和巨掌只承担身份与压迫，不替代施术者的发令关系；
- 镇压前用广角同框目标、手掌投影和地面落点，目标衣发、气场、积水与碎石先出现受压反馈；
- 命中后先显示掌压、地面下沉和冲击传播，再允许烟尘吞镜。

## 镜头与效果

- 开场面部特写只承担短促挑衅与方向确认，不形成长时间站桩；
- 俯冲用同轴下坠跟拍，近身交换改用双人中景侧跟；
- 踢击命中可短切接触特写，但必须回到全景显示被击退轨迹；
- 法器升空后用全景建立雾区和裂隙尺度，巨掌下压用高空俯冲或侧面超广角二选一；
- 心跳式震动、全屏负片、闪白与鱼眼最多服务裂隙首次打开或巨掌命中之一，不能同时覆盖全过程。

## 生成门禁

- 伞的展开、收拢、离手和盘旋状态连续；
- 角色高速位移保留起点、路径或落点，不能以残影冒充动作；
- 法相具有来源、生成、施术关系、接触和收束；
- 巨掌只落在已建立位置，不能因推镜改变目标相对方向；
- “绝望特写”期间环境压力继续，随后巨掌命中方向与瞳孔倒影一致。
