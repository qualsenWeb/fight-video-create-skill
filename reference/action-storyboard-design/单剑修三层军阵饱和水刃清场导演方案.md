# 单剑修三层军阵饱和水刃清场导演方案

## 一、适用边界

适用于单名具备剑气外放和水系塑形能力的剑修，在山谷、废墟、古战场或其他开放大纵深空间中，对近地步卒、中空飞骑和高空投射组成的多层军阵持续移动、挥斩和清场。

决定条件：

- 对战规模是一名主角对大量军阵，而非双人势均力敌对决；
- 主角使用一把剑持续挥斩，攻击主体是水刃、水浪或由其汇流形成的短时化形剑气；
- 敌军主动合围、补兵、远射和包抄，形成持续压力；
- 火力从单道落点升级为线、面和三层覆盖，但每次攻击仍有动作来源；
- 场景可容纳近地、中空、高空三层目标和地空贯穿摄影。

不适用于群体实体飞剑、普通持剑者、双人追逐对射、纯近身军阵搏杀、单次拔剑展示或只有一个静态终极光束的清场。

## 二、核心导演协议

全段围绕：

`持续移动 → 可见挥剑 → 水刃沿刃轨脱离 → 敌军闪避/对冲/受击 → 阵线破口与炸点 → 下一层敌军补位 → 主角换层再攻击`

每次镜头切换仍拍同一条力量链。禁止“摆姿势—全屏水光—军阵自动消失”。

### 2.1 三联同步

每轮攻击至少保留以下三项连续证据：

1. **挥剑动作**：重心、肩肘腕和剑刃方向清楚；
2. **剑气出鞘**：水刃从剑刃轨迹延伸，形态与挥斩一致；
3. **军阵结果**：落点、受击方向、阵线断裂和残骸可读。

可使用手腕挥剑微距、剑气脱刃中景、军阵炸点广角组成三联快切，但不能在每轮重复同一组镜头。

### 2.2 火力单向升级

推荐升级链：

`单道精确水刃 → 横向连续炸点 → 扇形/交叉/网状覆盖 → 近地与中空双层对冲 → 三层饱和轰炸`

火力只能通过挥剑频率、弹道数量、覆盖层级和目标反制逐步提高。达到饱和后不再额外叠加无关核爆或第二种终极技能。

### 2.3 双人协同扩展门禁

若清场主体由两名剑修或远程角色共同承担，本方案只保留“三层军阵”的高度逻辑，不直接复制单人火力协议。应先分配地面/空中或前排/后排职责，再按“第一人建立破口或封线 → 敌军路线改变 → 第二人沿新路线接力 → 第一人换层或回补”组织动作。

- 两名角色的挥剑、剑气来源和目标层级必须分别可追溯，不能把两人的弹道合并成无来源的同色光幕；
- 一名角色攻击时，另一名角色应处于换层、瞄准、封侧或承接结果的有效状态，避免双人同时站桩放波；
- 每次接力都要保留前一轮炸点、断面、残骸或敌群位移，后一轮沿已改变的路线发生；
- 双属性或不同材质先按清层、封线、减速和破防等职责分工，只有共同目标受限或终结窗口成立时才交汇；
- 双人协同无法在时长内保持层级与落点时，退回本方案的单人结构，不额外叠加第二套完整清场高潮。

## 三、军阵攻防

### 3.1 近地破口

主角沿军阵缝隙突进，以横斩、撩剑、下劈和环形水浪切开前排；敌军从两翼补位，长枪和盾阵迫使主角借残柱、断壁或沟壑换向。

### 3.2 中空包抄

飞骑从侧面俯冲，弩箭与法术弹交叉封线。主角不能只向地面输出，需通过上挑水刃、斜向流刃或俯冲反切先打断中空包抄，再把余势导向地面阵线。

### 3.3 高空压制

主角升入高空后仍持续小幅闪转、俯冲拉升和横向错位；地面军阵沿山谷推进，高空与地面的弹道在中央空域对冲。炸点从前排向飞骑和后排节点扩展，三层均有明确结果。

### 3.4 补兵连续性

敌军数量压力来自山谷两翼和后排通道持续进入。前排被清除后，后排需要绕过沟壑、残柱和残骸重新布阵；禁止下一镜在同一位置刷新完整敌军。

## 四、主角运动链

可从以下动作中选择目标时长能容纳的组合：

- 沿阵缝贴地突进并横斩开路；
- 滑铲绕柱后反手撩剑攻击中空目标；
- 蹬石跳跃、燕子翻身、贴柱折返连续换位；
- 环形水浪震开近地敌军后借反力升空；
- 高空闪转、俯冲、拉升和横向错位保持攻击；
- 跟随已经成立的水刃形态穿阵，而非无接触漂浮。

每次升空、倒飞和折返必须有脚部接触、反冲、上一攻击余势或明确能力依据。

## 五、水刃形态层级

### 5.1 基础压制

- 直线或弧形水刃：精确切开单层阵线；
- Z字切线：由连续两至三次可见挥斩形成，改变敌军避让方向；
- 环形水浪：由一次完整旋身横斩向四周扩散，用于震开包围并换层。

### 5.2 饱和弹幕

- 扇形、交叉、网状弹幕必须由连续挥斩逐步生成；
- 单次挥剑默认只对应一道主剑气；角色明确具备分刃能力时，才允许一道主刃在飞行中裂成有限支刃；
- 数百道细刃需要前置连斩、剑阵式分化或已建立的水刃汇流机制，不能凭空爆射。

### 5.3 化形水刃

冰鹰、游龙等形态只在角色具备水系精细塑形能力时使用：

`先建立水刃/水浪存量 → 挥剑或剑尖触发汇流 → 形成具有明确攻击部位的短时形态 → 沿既定路线攻击 → 命中后散回水刃、水雾、冰晶或电弧残留`

化形不是独立召唤兽。冰鹰依靠翼刃、利爪和俯冲路线攻击；游龙依靠龙首冲击、躯干盘旋和龙尾横扫攻击。没有前置介质与剑刃触发时不得凭空出现。

## 六、镜头系统

### 6.1 近地阶段

低角度横扫、绕柱跟拍和短促刃口特写负责读取突进、借力、挥剑和甲胄反馈。动态模糊作用于背景、剑刃边缘和飞散碎屑，人物脸与主轮廓保持清晰。

### 6.2 地空尺度切换

环形水浪或重斩形成空间转折后，镜头随主角倒飞/升空快速后拉，从近景过渡到山谷全景，同时保留地面军阵和上升弹道。

### 6.3 三层贯穿

高空俯角或斜向贯穿镜头同时读取主角、箭雨/飞骑和地面炸点。摄影机可以穿过弹道间隙，但不能进入全屏爆炸后失去主角和攻击方向。

### 6.4 饱和高潮

镜头围绕山谷中央火力交汇区扩大半径，扫过不同高度的炸点；每次震动对应一次可见碰撞。毫秒级闪切、负片和抽帧最多选择一种作为重击强调，不连续叠满。

## 七、10秒结构

`0—2秒 近地破阵与残柱借力 → 2—3秒 环形震开并升空拉距 → 3—4.8秒 首轮高空下射建立横向炸点 → 4.8—7.2秒 弹道与挥剑频率升级覆盖中空飞骑 → 7.2—10秒 三层饱和对冲并以动态全景收束`

若使用冰鹰或游龙化形，应替换最后一个饱和阶段，而不是在完整弹幕高潮后再追加一套终极技。

## 八、节奏与可读性门禁

- 高频来源是动作、弹道、敌军响应和落点递进，不是单纯提高切镜次数；
- 每秒3—4组快切只可视为风格目标，不作为必须执行的固定参数；
- 轻度、中度、重度动态模糊不能随着时间机械叠满，以人物和剑气轮廓可读为上限；
- 特写只服务挥剑、眼神决策或关键形态触发，不能挤占军阵空间关系；
- 收尾可以减速，但烟尘、水雾、军阵补位或主角移动仍需保持动态，禁止静态定格冒充结果。

## 九、生成门禁

交付前检查：

- 是否为单名剑修对大规模主动军阵，而非敌人静止排队；
- 三层军阵是否具有不同高度、职责、弹道和受击结果；
- 每道主要水刃是否能追溯到挥剑、分刃或前置汇流；
- 火力是否由点到线、面和多层递进，没有中途回落或无因跳级；
- 地形借力、升空、俯冲和折返是否有动作来源；
- 冰鹰或游龙是否由水刃存量汇流，且拥有可读攻击部位；
- 形态技能是否替换而非叠加在完整饱和高潮之后；
- 水痕、碎石、甲胄和敌军状态是否跨镜累积；
- 画面是否仍能看清人物、剑刃、弹道和至少一层敌阵；
- 是否删除了无平台依据的8K、UE版本和帧率保证。
