# 赤紫法相擒摔压制导演方案

## 适用边界

适用于施术者以同源巨型能量实体，在开放空域或大地战场拦截山岳级目标并完成擒控、摔投或压落。法相是角色能力的延伸，不是脱离控制关系的独立怪物。

## 动作因果

`施术媒介蓄力 → 法相从角色后方或指定位置逐步显现 → 锁定攻击轴线 → 巨掌正面接触 → 指节/掌根可读地控制受力点 → 腰肩带动整体抡起 → 完整摔投轨迹 → 落点冲击 → 法相与能量余波撤销或收束`

- 先展示施术媒介和能量汇入，再显示法相成形；禁止跳过起势直接出现巨手。
- 巨掌接触必须对准目标头部、躯干或指定控制点，目标的表层、姿态和移动方向要有受力反馈。
- 摔投使用完整弧线，至少读清“控制—提起—越肩/翻转—压落”，不把目标瞬移到地面。
- 施术者、法相、目标在至少一个侧面超广角中同框，固定前后关系与攻击轴线。

## 镜头与特效

先用中近景建立媒介和发令，再用侧面超广角完成拦截与摔投，最后用宏观远景容纳落点、环境与法相。特效附着于施术者、法相轮廓、接触点和冲击传播，不能用全屏发光代替抓握和受力。

## 门禁

- 法相外形与施术者同源但不必复制面部细节；
- 巨型目标的全身动量必须被连续带动；
- 落点后保留地表、云层或粒子化结果；
- 法相完成职责后收束、淡化或转入下一动作，禁止静止占场。
