# 赤紫法相擒摔十秒即梦案例

## 来源与可靠性

- 来源文件：用户提供的《0819紫红.txt》第一段；
- 生成工具：即梦2.0，720P；
- 原始结构：10秒，单次生成；
- 作者未提供成片效果结论。

本案例保留原始法相擒摔、巨蛇与能量设定，供参考十秒内“生成—拦截—摔投—落点”的宏观动作组织；不视为跨模型验证结论。

## 核心结构

`魔王挥扇显蛇 → 男主以悬浮长剑蓄力 → 同源赤红法相显现 → 巨掌正面截蛇 → 控首提起 → 空中完整过肩摔 → 雪原双层冲击 → 巨蛇粒子化消散`

|---|---|---|
| 00:00—00:02.10 | 魔王转身挥扇，紫白爆心、黑水漩涡与紫焰显现；山岳级巨蛇沿固定轴线冲向男主。 | 魔王在超广角中保持渺小，巨蛇从男主正面来袭。 |

## 可迁移观察

- 巨型能量实体先以施术媒介蓄力建立来源，再进入接触动作，较易读清控制关系；
- 拦截与摔投应固定攻击轴线，侧面超广角比连续反打更能避免巨物前后关系翻转；
- 十秒可容纳一个主机制，法相拦截、控首和过肩摔构成同一机制，不宜再追加第二套终结。
