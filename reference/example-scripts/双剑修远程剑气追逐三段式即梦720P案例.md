# 双剑修远程剑气追逐：三段式即梦-720案例

## 来源与可靠性

- 来源文件：用户提供的《剑仙魔仙.txt》；
- 生成工具：即梦-720；
- 原始结构：三段一次生成后剪辑，第一段8秒，第二、三段各10秒；
- 作者总评：生成后认为整体节奏不满意，未继续修改；
- 分段观察：第一段开头交锋可修；第二段最后大招不好看，可自行替换；第三段为直出，作者称“没什么缺陷”，但个人仍不满意。

这些评价是作者对该次生成的主观观察，不代表机制已经跨模型验证。本案例保留原提示词的结构、命名武器和角色属性，供即梦短视频编排与失败风险复盘；通用规则应转用对应导演方案和招式专项。

## 全局设定

- 画幅与媒介：16:9，电影级写实仙侠，冷调玄幻水墨质感；
- 场景：残柱林立的废墟古战场，包含断崖壁、石质殿宇屋顶群、沟壑碎石区和巨型石门残骸；
- 战斗关系：魔仙为追击方，剑仙为反击方；双方以单手剑和属性剑气作战；
- 魔仙：水系剑气与暗红电弧，命名武器「银华断界」；
- 剑仙：黑雾剑气与烈焰，命名武器「冥渊・噬夜」；
- 主战逻辑：高频挥剑、远程剑气、地形借力、大范围追逐、流体碰撞和层级破坏；
- 镜头倾向：14mm超广角建立全域，ACT双目标锁敌，跟拍具备摇杆式操作惯性和回弹；
- 特效纪律：电弧、烈焰沿服饰、发丝和剑身纹理附着，挥剑时延伸到剑气根部；人物主体清晰，避免悬浮光团和无载体粒子。

## 双角色剑气定义

### 魔仙：水浪冰晶剑气 + 暗红电弧

- **宽幅贯空水刃**：凝实宽幅液态水浪，约为常规剑气3—4倍宽；表面翻涌，边缘带冰晶和水墨飞白，根部缠绕暗红电弧；命中后水浪、冰晶、电弧和岩石碎屑定点炸开，留下水渍与灼痕。
- **巨型崩岳水柱**：超粗液态水柱式剑气，落地后径向炸开水浪和环形冲击，适合大范围地形破坏。

### 剑仙：黑雾剑气 + 烈焰

- **宽幅贯空黑雾刃**：凝实厚重的液态黑雾刃，边缘保留水墨飞白，根部缠绕烈焰；命中后黑雾、火星和碎石炸开，留下焦黑与余烟。
- **巨型崩岳黑雾柱**：浓淡分层的超粗黑雾柱状剑气，落地后形成墨色烟浪、环形冲击和大范围焦痕。

## 第一段：8秒全域纯远程追逐

### 原段目标

全程无站桩、无近身兵刃或身体接触。双方跨越残柱、断崖、屋顶与沟壑持续挥剑对射，剑气近镜划过2—3次，镜头始终保持双目标锁敌。

### 时间轴

| 时间 | 镜头与动作 | 接力状态 |
|---|---|---|
| 0:00—0:02 | 14mm高空上帝视角铺开全域废墟。魔仙从残柱群蹬柱升空，剑仙沿断崖踏壁拉升；双方零对峙同步连射，双色宽幅剑气在中央交错对撞并炸起墨尘浪。 | 双方位于对角远端，追逐方向与全域尺度成立。 |
| 0:02—0:04 | 镜头急坠贴地并横向跟拍。魔仙地面S形突进后冲上屋脊，剑仙蹬柱升空、俯冲踏壁并落向另一侧屋顶；水刃与黑雾刃连续命中残柱、檐角和地面。 | 双方跨区换层，屋顶与断崖破坏保留。 |
| 0:04—0:06 | 固定低角度仰拍空域。魔仙蹬屋脊垂直升空，剑仙沿断崖连续变向；密集剑气形成扇形和网状覆盖。中途插入约0.5秒剑仙眼部特写后切回全景。 | 双方一上一下，空域弹道持续对冲。 |
| 0:06—0:08 | 先给魔仙握剑手部约0.8秒特写，再极速拉远为旋转冲刺跟拍。魔仙连续蹬檐、踏壁、折线升空并持续射出水刃，剑仙始终保留在有效战斗区。 | 以追击方最高速复合位移和持续炸点结束。 |

### 第一段风险

- 作者认为开头交锋可调整；
- 8秒同时包含两次特写、全域追逐、复杂地形与高频剑气，动作容量偏高；
- 0.8秒手部加0.5秒眼部共占1.3秒，可能挤压主战过程；
- 固定仰拍、贴地跟拍和旋转冲刺跟拍切换频繁，需用剑气划镜或地形遮挡维持空间连续。

## 第二段：10秒由追逐转向命中终结

### 原段结构差异

该段总则仍声明远程剑气，但时间轴在1.3—5.9秒安排魔仙近身回旋斩、剑仙近身侧闪和俯冲下劈，与“纯远程、无近身兵刃接触”的通用规则存在冲突。此处按来源原貌保留，不并入纯远程导演方案。

### 时间轴

| 时间 | 镜头与动作 | 接力状态 |
|---|---|---|
| 0—1.3秒 | 高空俯拍向左上高速滑镜。魔仙持「银华断界」从右下极速入镜并冲出右上，衣摆、发丝、电弧和尘浪形成速度拖尾。 | 魔仙取得高速追击动量。 |
| 1.3—3.6秒 | 低角度荷兰角。魔仙冲向剑仙，以单手180°回旋斩释放水浪冰晶剑气，短暂升格约0.5秒。 | 水刃占据正面路线，双方距离被压缩。 |
| 3.6—5.9秒 | 剑仙近身侧闪后腾空后撤，持「冥渊・噬夜」俯冲下劈黑雾烈焰剑气；魔仙贴地横滑闪避，地面留下纵深沟壑和灼痕。 | 双方重新拉开，地形被切开。 |
| 5.9—7.7秒 | 左下—右上对角构图。魔仙地面后撤横滑，剑仙半空突进；双方连续对射，水雾、黑雾、火星、电弧和碎石在多点碰撞。 | 对射升级，双方仍保持清晰轮廓。 |
| 7.7—10秒 | 魔仙斜向抽射击飞剑仙，使其撞向远端残柱；随后落地蓄力斩地，复合水浪冰晶电弧剑气沿地面推进并触发残柱、岩层和碎屑的层级破坏，镜头拉升至超广角定格。 | 以大范围命中和废墟毁灭结束。 |

### 第二段风险

- 作者明确认为最后大招不好看，可替换；
- 末2.3秒同时包含击飞、撞柱、落地、蓄力、斩地、复合剑气、层级破坏、数公里烟柱、拉升和定格，明显过载；
- 总则“无站桩蓄力”与结尾“落地后蓄力”冲突；
- 高温电离、电弧、熔融液滴、水浪与大规模烟柱同场，视觉介质竞争严重；
- 若修订，优先删除前置击飞或核爆级数字绘景，只保留一种终结结果。

## 第三段：10秒远程对射与第一视角临界终招

### 时间轴

| 时间 | 镜头与动作 | 接力状态 |
|---|---|---|
| 0—2秒 | 14mm高空俯拍。魔仙从左上追向右下，双方沿残柱和屋顶做立体位移，并以水系电弧剑气与黑雾烈焰剑气交错对射。 | 全域追逐与属性关系成立。 |
| 2—4秒 | 镜头急坠贴地。魔仙蹬柱俯冲，以竖直巨型水系浪柱斩砸向剑仙；剑仙在抵达前低位侧滚，镜头同步旋转半圈，随后起身连射黑雾烈焰剑气。 | 水柱落地形成沟壑和环形水浪，剑仙完成反击。 |
| 4—6秒 | 低角度跟随剑仙蹬柱翻转、沿崖壁上升；魔仙空中折线追击。双方剑气在空域中点高密度碰撞，以白雾、爆闪和分级震屏表现远程格挡。 | 无兵刃接触，攻击权暂时均衡。 |
| 6—8秒 | 镜头垂直拉升，双方反向拉开并继续对轰。剑仙在断崖顶将密集黑雾烈焰剑气汇成「崩岳烈焰黑雾潮」，临界成型时插入0.3秒子弹时间。 | 黑雾火潮蓄势完成，魔仙位于远端残柱群。 |
| 8—10秒 | 切魔仙第一人称，视野边缘仅露肩部和剑刃局部。剑仙催动百米级黑雾火潮横贯战场，扫断残柱、掀飞屋顶并向镜头急速放大；近点急停0.2秒后由浓黑与余烬压暗画面。 | 终招停在临界袭来，不展示最终受击结果。 |

### 第三段观察与风险

- 作者说明该段直出、没有明确缺陷，但个人仍不满意；
- 该段的结构相对统一：追逐—重剑气闪避—远程格挡—拉开蓄势—主观临界；
- “全程零站桩”与剑仙在断崖顶汇聚终招之间需要用持续后撤、挥斩和环境卷吸保持动态；
- 第一视角终招能避免在末2秒同时承担完整命中与核爆结果，是三段中较清楚的收束方式；
- 0.3秒子弹时间与0.2秒急停均依赖模型精细时间响应，不能视为稳定能力。

## 原案例负面约束汇总

- 禁止站桩蓄力、动作拖沓、硬直和小范围原地闪避；
- 禁止近身兵刃或身体接触，但第二段来源时间轴存在短暂近身例外；
- 禁止人物主体拖影、糊脸、轮廓虚化和无因全身残像；
- 禁止无脚部接触、无碎石和无尘浪反馈的漂浮、瞬移或假地形交互；
- 禁止剑气缓慢、纤细、稀疏或与挥剑动作脱节；
- 禁止高饱和塑料特效、无结构纯色剑气、无载体游离光团；
- 禁止电弧脱离服饰和剑身乱飘，禁止烈焰无附着点飞散；
- 禁止长时间划镜遮挡、人物占比过大、镜头切换无惯性；
- 禁止现代枪械、游戏UI、血条、技能图标、现代屋顶材质和穿模畸形。

## 可迁移结构

1. **纯远程因果**：每次挥剑对应一道剑气，攻击方向、弹道和落点一致；
2. **追逐可读**：用残柱、断崖、屋顶、沟壑和石门证明跨区位移，不靠缩放冒充距离；
3. **地形借力**：升空和折返保留脚部接触、碎石与反向尘线；
4. **属性锚定**：附加电弧或烈焰从服饰、手臂和剑身延伸到剑气根部；
5. **远程格挡**：以剑气对冲、介质压缩和定向炸裂替代兵刃碰撞；
6. **终结取舍**：短时结尾只选完整命中破坏或第一视角临界威胁之一；
7. **平台校准**：来源仅记录即梦-720该次三段一次生成与剪辑结果，迁移平台时应减少镜头和效果层级后重测节奏。
