# 渊鳞双色双链墨海清场与巨魔终结案例

## 来源与用途

- 来源文件：用户提供的《塞拉斯.txt》第二、三段；
- 用途：参考双链角色在墨海中用水蓝龙链与焰橙火链分工清群，先清普通敌潮、再在玻璃化巨坑处理单体岩甲巨魔的两段式结构。

## 双链职责

- 左侧水蓝龙链：缠绕、冻结、拉拽、龙息与水蓝切线；
- 右侧焰橙火链：鞭击、火莲爆燃、灼穿岩甲缝隙；
- 双链交汇：只在明确的对撞、双鱼融合或最终爆裂节点发生，不能从头到尾无差别混色。

## 两段结构

| 阶段 | 动作与战场 | 接力状态 |
|---|---|---|
| 墨海清群 | 渊鳞在黑镜墨海、残柱与断桥间用双链横扫、缠绞、借力弹射和墨海龙卷处理敌潮；水火对撞后由双鱼法阵、墨潮和掌心光核完成清场。 | 墨海被蒸空，留下玻璃化巨坑与黑灰粒子。 |
| 巨魔残局 | 岩甲巨魔从巨坑破土，以巨爪与甩臂建立前摇；渊鳞滑铲避开横扫，水蓝链锁腕冻结，焰橙链击入面门或岩甲缝隙。 | 巨魔双臂受限，渊鳞获得腾跃到头顶的窗口。 |
| 阴阳终结 | 双链缠住双臂，角色借胸口蹬踏腾跃；两链交绞形成双色双鱼，注入巨魔体内后以回拉触发裂纹爆碎。 | 巨坑、碎裂岩层和黑灰余波保留到终帧。 |

## 执行约束

1. 双链要始终锚定手臂、目标关节或地形支点；不得变成无接触的漂浮光带。
2. 巨魔须有可读前摇、受击点与反制力。锁腕、面门击裂、被甩飞后的插链减速和二次突进顺序不能颠倒。
3. 清群段和巨魔段之间必须保留环境战损：墨海蒸空、玻璃化地面、坑壁裂纹和黑灰飘落。
4. 来源中的停顿、特效比例、互动文案和渲染参数不作为通用规则；特效优先服务链条张力、目标位置与接触反馈。

## 适用边界

适合水蓝/焰橙双链、墨海战场、双属性清群、玻璃化巨坑与链条锁臂终结。它与高空黑金剑阵为不同角色、武器和空间机制，必须分开路由。
