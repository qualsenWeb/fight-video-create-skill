# 青蓝女剑客与赤狐折扇女侠雨后江南古宅对决案例

## 来源与用途

- 来源文件：用户提供的《2.txt》；
- 原始目标：30秒东方江湖二次元角色战斗PV；
- 用途：参考青蓝直剑女侠与赤狐折扇女侠的轻快近战拆招、雨后古宅追击与力量觉醒高潮；
- 画质、帧率和引擎描述均为来源条件，不纳入通用规则。

## 角色与机制

- **青蓝女剑客**：纤长直剑，水流、电弧与水墨效果锚定剑刃、手腕和步法；以低位滑步、踏墙、反手剑、卸力与连续追击取胜。
- **赤狐折扇女侠**：折扇承担格挡、切线、开合扰乱和短距反制；狐耳、狐尾与红黑能量服务于转向和节奏变化。
- **关系**：不是远程能量互轰。两人必须在兵器接触、错身、回弹后才获得下一次攻击窗口。

## 三段结构

| 阶段 | 动作与场景 | 接力状态 |
|---|---|---|
| 入宅试锋 | 雨后庭院与石阶建立湿滑地面；折扇先以开合和扇缘改线，直剑以侧闪、格挡和低位滑步夺回中线。 | 双方兵器已接触，剑客获得扇面开合的节奏信息。 |
| 回廊追击 | 两人穿过廊柱、窗格与屋檐水线；剑客踏墙转身斩，赤狐以扇面卸力、狐尾配重后退并从侧路反入。 | 庭院水迹、掉落瓦片与被切开的帘幕保留方向。 |
| 觉醒对撞 | 青绿水墨剑弧与赤金扇风在古宅纵深内建立一条明确对冲线；先由连续近战累积破绽，再进入一次大范围能量碰撞，余波仍推动衣发、积水和残片。 | 终段可开放胜负，但不能以无因法阵跳过前述拆招。 |

## 执行约束

1. 每次攻击遵循起步、加速、挥剑或开扇、接触/落空、受力和重心回收；不使用站桩挥武器。
2. 剑气只在剑刃轨迹、已有蓄水或强力挥斩后出现；折扇的能量必须由扇面开合、旋扇或格挡动作触发。
3. 雨后古宅的核心是庭院—回廊—屋檐的横向与短垂直换位，不应替换为悬空古刹、山谷军阵或纯空战。
4. 结尾大招只保留一次，镜头需先读清人物、兵器和对冲方向。

## 适用边界

适合青蓝女剑客、赤狐扇手、雨后江南宅院、近身拆招与水墨剑气对扇风的案例。与“青灵御水者与赤狐妖灵”共享水系/赤狐外观，但前者是无固定剑的多层古刹控场，本案是直剑对折扇的古宅近战，必须独立路由。
