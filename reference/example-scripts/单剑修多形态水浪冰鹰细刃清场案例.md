## 多形态转换逻辑

来源提示词的技能顺序可以整理为：

`宽幅下劈 → 旋身Z字连斩 → 连续单刃突进 → 环形水浪 → 图腾区域爆发 → 弧形追击 → 冰鹰俯冲 → 细刃群爆射 → 多层横扫`

改编时不应把九种形态都视为独立大招。基础水刃、Z字、环形和弧形属于挥剑轨迹变体；图腾属于区域落点变体；冰鹰属于短时化形；细刃群属于分刃能力。

## 风险与修订提示

- 10秒内塞入九类形态、多个特写、720度旋身、负片定格和数百细刃，容量明显过高；
- 720度旋身必须由腾空、转髋和落地轴完成，不宜只用人物无重力旋转；
- “图腾形水浪”需要明确图腾是水体轮廓、落点纹样还是控制场，避免凭空出现固定图案；
- 冰鹰、数百细刃和最终多层横扫集中在最后2.5秒，存在三重高潮竞争；
- 推荐在实际生成中只保留“冰鹰”或“细刃群”之一，最终横扫作为结果；
- 冰鹰必须由水浪汇流并在命中后散回水雾、冰晶和电弧，不能变成长期独立召唤兽；
- 数百细刃需要明确角色具备分刃能力，普通剑气外放角色不得直接套用；
- 原文未说明实际平台和生成结果，不把快切、负片、FPV和升格时间控制视为稳定能力。

## 负面边界

禁止站桩、静止割草、低频挥剑、稀疏水刃、敌军不反击、无飞骑与远射层、纯色塑料水光、冰晶水珠缺失、暗红电弧游离、镜头长期固定、人物与武器变形、特效穿模、地面无水痕与残骸、冰鹰无来源生成、单次挥剑无因复制数百剑气。
