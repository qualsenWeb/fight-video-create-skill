# 黑紫骷髅鱼群天幕水墨清群案例

## 来源与用途

- 来源文件：用户提供的《5.txt》；
- 原始目标：30秒高空主宰对妖魔潮的群体清场；
- 用途：参考骷髅头群以鱼群编队、骨瀑和天幕节点完成多层围剿的结构。

## 核心机制

- 主宰悬浮高空，以手势、视线和下压动作指挥骷髅群；骷髅不能无理由静止堆叠。
- 骷髅从远天汇为五路鱼群，依靠S形偏航、疏密变化与高度分层冲入妖潮；咬合、撞击与骨瀑下坠都必须带来目标和地表反馈。
- 黑紫墨色天幕是第二阶段的发射与分层节点，不替代骷髅群本身的路径设计。

## 时间轴

| 时间 | 动作与镜头 | 接力状态 |
|---|---|---|
| 0—4秒 | 高空主宰单掌建立黑紫能量，远天骷髅眼窝亮起并汇为五路鱼群；镜头从超广角读入群体规模后跟入一条前锋线。 | 骷髅已获得统一飞行方向和高度层。 |
| 4—10秒 | 鱼群下压、迂回和低空包抄，汇成骨瀑冲撞妖潮；慢镜只用于一次咬合/弯折读点，随后立即回到高速。 | 首轮冲击留下碎骨、墨雾和裂地，残敌仍在分流。 |
| 10—17秒 | 骷髅在贴地与中空重组，主宰展开黑紫铭文天幕；天幕节点向不同高度投下骷髅群，形成空中、天幕中层和地面骨潮的三层攻势。 | 天穹有可追踪的骷髅漩涡，地面残敌被压缩到终结区。 |
| 17—23秒 | 头顶鱼群漩涡由外环、中层补位和内层拧转组成；主宰睁眼后将其折成多道垂天骨瀑，配合贴地骨潮扫过残敌。 | 骨瀑和地面骨潮均保留冲量，进入水墨终结。 |
| 23—30秒 | 泼墨冲击仅作为最终放大器，保持骷髅穿透和墨浪命中的可读性；颜色恢复后由高空拉远，骷髅回旋、碎骨回落和能量余波继续运动。 | 不使用完全静止的定格收尾。 |

## 风险与边界

- 鱼群、骨瀑、天幕与漩涡必须明确继承关系，不能每段无因重新生成一批骷髅。
- 黑白高反差和频闪不得遮蔽骨群轮廓、目标位置或接触；眼部触发应服务指令变化，而非替代动作。
- 适用于骷髅群体、鱼群路径、黑紫天幕与水墨清群；不路由至普通万剑剑雨或单剑修水刃清场。
