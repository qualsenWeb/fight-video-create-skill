# 青灵御水者与赤狐妖灵暴雨悬空古刹对决案例

## 来源与用途

- 来源文件：用户提供的《1.txt》；
- 原始目标：约30秒东方幻想动作PV；
- 用途：参考无固定兵器的御水者与狐尾妖灵在暴雨多层古刹中的追击、控场与坠落路线；
- 不把来源中的8K、60fps、渲染器或特效密度视为通用交付保证。

## 不可替代要素

- **关系**：青灵以雨水、水面和青玉灵环建立控制区；赤狐以狐尾、妖火、黑红丝绸与短距离爪刃切入。
- **场景**：断裂悬空山体古刹，自上而下为山门、倾斜庭院、悬空回廊、半毁钟楼与云海断桥。
- **动作原则**：能量贴附手势、衣摆、发丝、狐尾、湿瓦与水面；双方靠踩踏、转髋、落点和建筑阴影换位，不以瞬移或悬浮大法阵替代运动。

## 三段战斗结构

| 阶段 | 空间与攻防 | 状态接力 |
|---|---|---|
| 雨幕试探 | 青灵从屋檐积水感知狐尾切风，侧折避开赤狐的阴影突袭；赤狐踩湿瓦、甩尾切水，以近距离错身试探。 | 青灵确认雨水可作介质，赤狐确认屋檐和阴影是高速入口。 |
| 屋脊至回廊 | 青灵以袖摆和灵环拉起短时水刃、涟漪与水幕，切断赤狐的直线入口；赤狐借狐尾配重，在倾斜屋顶、石墙和回廊栏杆之间折返，迫使对方移动控水。 | 水幕破碎后转为落雨和地面积水，双方被推向更低一层。 |
| 钟楼至断桥 | 赤狐利用木构与阴影完成连续变向并以尾击压迫；青灵将雨水卷成受手势牵引的弧形水流，借断梁、钟体与断桥边缘反制。终段保留坠落、雨幕、衣摆和水流的未完动势。 | 不预设胜负；断桥和云海为下一段提供垂直追击入口。 |

## 空间与镜头约束

1. 每次层间转移必须显示可用支点、落点和高度差；水幕可遮挡视线，但不能遮蔽关键接触。
2. 狐尾必须承担配重、扫击或改线职责，不能只作漂浮装饰；青灵的水刃必须由已有雨水或水面介质汇聚。
3. 镜头从雨滴微距进入屋脊追拍，再以侧向或俯角读取回廊、钟楼和断桥的纵深；不得把多层古刹压缩成平面庭院。
4. 赤狐的高速来自脚步、建筑阴影与狐尾惯性，不使用无过程瞬移；青灵越接近积水，控制范围越稳定。

## 适用边界

适合参考暴雨古刹中的水系控场、狐尾近战、多层建筑追击和垂直坠落接力。它不是剑伞古寺案例：没有骨伞、佛像跑壁、铜钟改线或既定卸武结局；也不适合普通平地双人拼刀。
