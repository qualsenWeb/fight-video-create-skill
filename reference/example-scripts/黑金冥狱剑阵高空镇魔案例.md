# 黑金冥狱剑阵高空镇魔案例

## 来源与用途

- 来源文件：用户提供的《塞拉斯.txt》第一段；
- 原始目标：30秒高空法阵蓄力后万剑清场；
- 用途：参考主角保持高空、敌群持续反扑、法阵逐步扩张、万剑在末段释放的单一宏观结构。

## 核心因果

`升入高空 → 符咒与飞剑围绕主角形成剑阵 → 敌方攻击法阵边缘 → 法阵扩张与局部绞杀 → 万剑压缩定向 → 剑雨落地 → 收剑余波`

主角的高空位置、法阵覆盖范围、敌方反击和飞剑密度必须逐段累积。万剑不是开场即有的背景贴图，也不能在敌群早已清空后继续蓄力。

## 时间轴

| 时间 | 动作与镜头 | 接力状态 |
|---|---|---|
| 0—8秒 | 主角进入高空、俯视古战场，结印引出黑金红法阵、符咒和初始剑影；前排魔物试探法阵边缘。 | 主角悬空，剑阵尚未满载。 |
| 8—18秒 | 法阵扩大并用边缘剑气和局部剑潮阻挡敌群；巨魔横扫、魂火标枪和灵力弹反复撞击屏障。 | 反击压力让压缩终局具备因果。 |
| 18—25秒 | 飞剑回收并对准下方，法阵进入压缩态；仍保留少量敌人和战场锚点。 | 目标区与落剑方向明确。 |
| 25—30秒 | 主角下挥，剑阵崩解成剑雨；落点冲击清开古战场，主角降落收剑，魂火与冥烬继续飘动。 | 收尾不使用人物、环境同时冻结。 |

## 边界

- 高空施法需要稳定构图，但不能把“全程不落地”理解为角色毫无姿态调整；结印、避弹和法阵反冲必须提供运动。
- 敌群受击以魂火、冥烬与焦黑粒子表现，避免血腥肢解。
- 不把来源的超高特效密度、顿帧和技术参数当作通用要求；特效不能遮住主角、法阵边缘或剑雨方向。
- 适合黑金剑阵、符咒、敌方持续破阵和末段万剑齐发；不适合骷髅鱼群、水刃剑修或贴地近战清群。
