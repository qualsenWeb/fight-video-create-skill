# 水刃黑雾双剑修分层协同清军三段案例

## 来源与用途

- 来源文件：用户提供的《2人协同对敌.txt》；
- 原始结构：三段各15秒；
- 用途：参考女性水刃剑修与男性黑雾烈焰剑修在同一山谷军阵的分层职责、短暂救场同框与合击化形。

## 职责划分

- **魔仙**：地面层，以水浪剑气和暗红电弧清开步卒、长枪与残柱区；以蹬柱、踏壁和屋顶折返维持移动。
- **剑仙**：中高空层，以黑雾烈焰剑气压制飞骑和远射单位；以俯冲、借飞骑或地形反力、拉升与横移维持轨迹。
- **同框门禁**：只有救场、交接或合击需要时同框；同框时两人各有明确攻击线，不能做无因的并肩摆姿。

## 三段结构

| 段落 | 动作设计 | 接力状态 |
|---|---|---|
| 第一段：分区清剿 | 魔仙在地面切开步卒，剑仙在中高空扫荡飞骑；末尾以上帝视角确认地面/空中左右分区，双方剑气仅在中线短暂对冲。 | 敌方集中远射与飞骑夹击，二人仍处于不同高度。 |
| 第二段：救场与再分工 | 魔仙被三层火力压缩；剑仙俯冲斩断上方飞骑并横扫周围重甲，魔仙借形成的缺口脱离。两人分开回到各自高度继续清场。 | 敌军损失累积，但仍保留足以迫使合击的边缘兵力。 |
| 第三段：同轨合击 | 水刃形成冰凤凰、黑雾烈焰形成麒麟；二者沿同向环轨追逐并首尾咬合，压缩为龙卷，再塑成双色游龙沿边缘完成扫荡。 | 合击后留下双环沟壑、水痕、焦痕和持续余波。 |

## 连续性与风险

1. 合击只能在前两段已建立的水刃与黑雾存量上发生；凤凰、麒麟、龙卷和游龙是同一能量链的连续变形，不是四个并列大招。
2. 救场必须有明确威胁、救援攻击线和被救者的逃离落点；不得以跨空间闪现掩盖位置变化。
3. 双人各自清场不等于协同：协同只体现在分层分工、中线交接、救场窗口和末段同轨合击。
4. 原始画质、动态模糊、快切与帧率为来源参数；使用时优先保证人物区分、攻击线、敌军来向与能量锚点可读。

## 适用边界

适合双人分层清军、水刃对黑雾、空地协同、俯冲救场与双兽同轨化形。它不适合单主角水刃弹幕，也不适合无配合的双人决斗。
