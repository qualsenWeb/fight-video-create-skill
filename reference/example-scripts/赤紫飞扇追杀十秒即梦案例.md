# 赤紫飞扇追杀十秒即梦案例

## 来源与可靠性

- 来源文件：用户提供的《0819紫红.txt》第二段；
- 生成工具：即梦2.0，720P；
- 原始结构：10秒，单次生成；
- 作者未提供成片效果结论。

本案例保留赤红与暗紫阵营、巨大魔扇和紫焰线网等原貌，用于参考高速空域中“投掷—追杀—闪避—回收”的动作闭环。

## 核心结构

`双人瞬闪碰撞 → 男主瞬刺被魔扇正面格挡 → 魔王后翻拉远 → 脱手掷出巨大魔扇 → 飞扇以线网三次追杀 → 男主三维换位躲避 → 魔王回收魔扇 → 赤红大招压盾并逼出抽离`

## 飞扇段时间轴

| 时间 | 动作与镜头 | 连续性要求 |
|---|---|---|
| 00:02.10—00:03.80 | 魔王后仰空翻，拉至数百米外；持扇手臂后拉，腰肩发力后松手，巨大魔扇由右上向左下离手。 | 先看到扇在手中，再看到离手和固定初始攻击轴线。 |
| 00:03.80—00:05.40 | 飞扇沿大弧变轨追击，并从扇体释放紫焰线网。男主依次侧向瞬闪、向下俯冲、反向斜上瞬现。 | 每次都呈现旧位置赤红气流爆开、跨空域拖尾、新位置聚拢、旧位置被线网切爆。 |
| 00:05.40 | 魔扇沿回旋轨迹回归，魔王抬手接住。 | 扇面、扇骨和轮廓始终可辨，回收不无因消失。 |

## 后续压力段

男主在宏观赤红雾暴中原地挥剑，放出天幕级攻击；魔王以宽厚紫盾承压后竖向抽离，攻击击穿残盾命中远山。该段的关键是人物不随大招前冲，攻击、护盾、抽离和山体命中保持同一轴线。

## 可迁移观察

- 投掷法器的实体可读性来自持有、离手、弹道和回收四个状态，不来自法器名称；
- 多次闪避需要改变高度与纵深，且旧位置受击，才能证明是目标移动而非镜头跳切；
- 飞扇追杀与后续大招属于两个阶段，十秒内应只让一个阶段承担主要高潮。
