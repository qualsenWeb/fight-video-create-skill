# 浩然正气经文光墙镇魔三十秒案例

## 来源与用途

- 来源文件：用户提供的《浩然正气歌.txt》；
- 原始结构：两个相互承接的15秒段落；
- 用途：参考儒家女主以经文光墙、古篆文字化形和山河镇压，对太古关隘外妖魔潮分区净化的空间逻辑。

## 空间铁律

- 城墙横向位于画面上方；女主始终悬在城墙正上方高空；经文光墙固定在女主背后并与城墙平行。
- 妖魔从城外向城墙推进。第一次净化只能清掉前至中后段，远方与侧翼仍保留密集敌群，供后续文字化形处理。
- 白金经文光墙、深蓝洪水和白金山岳各有明确来源和方向，不能混为无锚点粒子。

## 两段时间轴

| 时间 | 动作与结果 | 接力状态 |
|---|---|---|
| 0—3秒 | 粉金女主在空中点出空间涟漪，完成一次有残影的空间跳跃并换为儒家素白深衣。 | 女主、城墙和妖潮的相对方位锁定。 |
| 3—10秒 | 女主念“起”“天地有正气”，经文古篆在其背后展开成横贯天际的光墙；光海由上方推向城外，净化中央大片妖潮。 | 中央出现空地，左右与远方敌军仍存。 |
| 10—15秒 | 女主念“杂然赋流形”，古篆“鼎”剥离光墙、拆笔画并重组为巨鼎，准备压向左侧。 | 巨鼎明确指向左区，右区与巨兽不受影响。 |
| 15—21秒 | 巨鼎落入左侧妖潮，锯齿状冲击波向外扩散；“锁”字化为漫天锁链并覆盖右侧，绞杀右区巨兽和妖群。 | 左中右三区依次净化，光墙仍在后方，更多文字保留可用性。 |
| 21—30秒 | 女主念“下则为河岳”并挥袖；战场裂隙喷出深蓝洪水，水龙冲起后回砸，随后白金巨岳压入战场。 | 以山河余波、城墙、女主和光墙的稳定方位结束。 |

## 适用边界

1. 台词、经文、文字化形和攻击方向是这个案例的关键；若不需要语言或文字机制，不能仅因“女主清群”而使用。
2. 文字化形必须逐步读清笔画拆解、重组和实体尺寸增长，不能直接切成完成体。
3. 女主不应落到城墙或地面；固定机位可突出方位，但全片不应因过多静镜失去能量推进。
4. 适用于经文光墙、古篆巨鼎、锁链绞杀、山河镇压和关隘守城；不适用普通剑气或骷髅群清场。
