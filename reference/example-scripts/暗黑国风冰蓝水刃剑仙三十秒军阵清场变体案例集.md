# 暗黑国风冰蓝水刃剑仙三十秒军阵清场变体案例集

## 来源与去重说明

- 来源文件：用户提供的《3.txt》与《4.txt》；
- 两份原文共享同一核心：冰蓝水系剑气、暗红雷纹、上古山谷废墟与三层军阵清场；
- 已合并为同一案例集，避免将相同的渲染、画质、动作模板和军阵设定重复入库；
- 与既有单剑修水刃案例相比，只保留其可区分的**30秒分段、近身破阵转剑域/形态高潮、末段清场**变体。

## 基础条件

- 场景：断柱、沟壑、残壁与积水构成的上古山谷，近地步卒、中空飞骑和后排远射形成三层反扑；
- 主角：单剑剑仙，冰蓝液态水刃为主，暗红雷纹仅在高速斩击、碰撞与爆发时附着剑身和水刃根部；
- 受击：甲胄、碎石、水花与雾气沿攻击方向分层扩散，地表累积水痕与战损。

## 30秒变体结构

| 时间 | 变体动作 | 连续性职责 |
|---|---|---|
| 0—8秒 | 以残柱、断壁和军阵缝隙完成近地突进、横斩、撩剑、滑铲与升空，优先破开步卒层。 | 建立剑刃、水刃和环境破坏的对应关系。 |
| 8—16秒 | 敌方箭雨和飞骑接管攻势；剑仙以俯冲、拉升和横移避线，水刃从单道升级为扇形或交叉覆盖。 | 将攻击权从地面转换到中高空，不让敌军停止反扑。 |
| 16—24秒 | 从连续剑刃中选择一种明确高潮：区域剑域、短时水刃化形或近身破阵后的广域斩线。 | 一次高潮只能保留一个主机制，不能与细刃群、冰鹰、游龙全量叠加。 |
| 24—30秒 | 高潮沿既定攻击线清开军阵，剑仙回收姿态；保留水雾、雷纹、残甲和未消散的敌方压力。 | 不以无因定格或全场突然静止终止。 |

## 变体使用门禁

1. 既有“持续饱和水刃”路由用于无单体高潮的长时间弹幕；既有“冰鹰细刃”与“游龙摆尾”分别用于对应化形。本案只在需要30秒的近地—地空—单一高潮—余波结构时使用。
2. 不将每次挽剑都扩张成大量剑气；分刃、剑域或化形必须有前置水刃存量和明确触发动作。
3. 画质引擎、8K、60fps、快切和负片均是原文表达，不代表稳定生成能力；特效不遮挡剑仙轮廓、敌方来向或关键接触。
4. 维持“挥剑—水刃脱离—敌军反馈”的因果；任何空中换位必须给出剑气反冲、建筑支点或角色能力条件。

## 适用边界

适合暗黑国风单剑剑仙、冰蓝水刃、暗红雷纹、山谷三层军阵、30秒分段清场。它不是双人协同案例，也不替代既有三条单剑水刃专项路线。
