# 万剑诀、雷域与箭雨：三段式即梦案例

## 来源与可靠性

- 来源文件：用户提供的《万剑诀+雷域+箭雨.txt》；
- 生成工具：即梦2.0，720P；
- 原始结构：三段10秒，单次直出；
- 作者观察：第一段存在少量逻辑问题；第二段整体偏慢，成片剪去前后各约1秒；第三段冲击感偏弱；再次抽卡效果未知。

本案例用于参考大规模飞剑的连续三段组织、群体形态和硬性约束，不代表原时间装箱、镜头数量、画质参数或效果强度已经跨模型验证。

## 全局设定

- 画幅与媒介：16:9，电影级写实国漫，暗黑仙侠史诗尺度；
- 场景：暗灰积雨云覆盖剑宗城外，黑岩城墙、剑塔、宫殿、群山、云海和荒原形成数公里纵深；地面为大妖潮；
- 人物：大师兄悬浮于剑宗上方极高空，白红极繁长袍、宽袖、围巾、长袍尾与黑色长发持续受高空风压影响；
- 仙力：深赤红丝绸状能量，由半透明绸带、光丝、绸幕和流动暗纹组成；不是火焰、实体布料、液体或普通光柱；
- 飞剑：正常尺寸、细长冷银剑体，剑锋附着少量赤红雷痕与短促红绸尾迹；
- 声音：无对白、无背景音乐，保留风啸、衣袍、红绸震鸣、万剑破空、赤雷、地裂、冲击和妖魔爆灭声；
- 通用禁止：字幕、文字、招式名、Logo、UI、水印、单剑领飞、巨剑替代万剑、规则圆盘和机械剑阵。

## 第一段：召剑、编队与垂天剑瀑临界

### 核心因果链

`高空蓄力 → 远天万剑赴命 → 人物音速换位 → 万剑从身后分层爆出 → 三次大范围换位牵动剑群 → 五路立体千剑流形成 → 一次挥手发令 → 五路宏观游走 → 目标上空转为剑瀑 → 大妖主观仰望`

### 时间轴

| 时间 | 镜头与动作 | 接力状态 |
|---|---|---|
| 00:00—00:00.85 | 18mm极端超广角、约12°负荷兰构图。人物是高空中的极小身影，单掌蓄力；红绸仙力铺满天空，远云开始出现冷银剑点。 | 远剑已响应，人物仍在原位控场。 |
| 00:00.85—00:01.50 | 万剑从远天、剑塔和群山方向沿不同高度逼近；掌前能量压缩，衣袍和长发被向后牵引。 | 剑群接近控制空域，蓄力达到爆发点。 |
| 00:01.50—00:02.00 | 人物本体沿清楚轨迹瞬移至摄影机前方；原位留下残影、音爆环、红绸拖尾和空间扭曲，刹停约0.08秒短减速。 | 近处人物完成换位，远处残影未散。 |
| 00:02.00—00:02.75 | 50mm侧前中近景，成百上千把飞剑从肩后、头顶两侧和更高空域分层爆出，不让单剑抢镜。 | 人物控场，万剑已越过人物进入宏观空域。 |
| 00:02.75—00:04.05 | 18mm高空超广角。人物依次跨越左下、中上、右后和中央高空；整片剑群外层拉弧、中层补位、内层偏航。 | 人物中央悬停，剑群仍在惯性改向。 |
| 00:04.05—00:04.90 | 万剑大范围展开，群体上下换层、前后穿插、局部压密后扩散；银剑、红绸和黑云形成天幕。 | 剑群已具备多个自然分轨区域。 |
| 00:04.90—00:05.35 | 五个区域自然形成五路不同高度、横向位置和纵深的立体千剑流。 | 五路群体保持独立体积，等待发令。 |
| 00:05.35—00:05.65 | 70—85mm长焦低角度，从群体前方读取蓬松锋线、中层补位和后层追入；约0.10秒短减速。 | 前层剑尖完成校准，后层仍在流动。 |
| 00:05.65—00:06.00 | 35mm侧后中景，人物只做一次单掌前挥；五路同时启动，加速由前向后传播。 | 五路获得共同目标但保留独立路径。 |
| 00:06.00—00:07.50 | 高位超广角与远距侧跟拍交替。五路分别前压下弯、弧线上升、S形偏航、掠云抬升和外侧绕行补位。 | 五路接近妖潮上空。 |
| 00:07.50—00:08.45 | IMAX式宏观远景同时容纳人物、横跨数公里的主剑群、持续补入的远剑和地面妖潮。 | 攻击规模与距离成立。 |
| 00:08.45—00:09.20 | 五路前部先下折，中段沿宽弧跟随，尾部延迟追入；底部、边缘和中段裂出次级支流，约0.12秒短减速。 | 横向剑潮完成向纵向剑瀑的转换。 |
| 00:09.20—00:10.00 | 地面大妖第一视角仰拍，8—12路主剑瀑和大量次级支流压下；结尾停在全面命中前。 | 万剑尚未命中，为下一段留下攻击接力。 |

### 第一段风险

- 10秒内包含召剑、人物多次瞬移、编队、远距迁徙和攻击转向，执行压力较高；
- “固定五路”与结尾“8—12路剑瀑”需要解释为五路主群在转向时裂出更多支流，否则会产生数量逻辑跳变；
- 三处极短减速依赖模型对精细时间指令的响应，不应视为稳定能力。

## 第二段：落剑、低空回潮与天幕雷域

### 核心因果链

`承接剑瀑压下 → 第一波命中清场 → 存量飞剑抬升重组 → 低空鱼群游荡绞杀 → 人物高空控场 → 红绸铭文天幕展开 → 分区群体下射 → 落剑区爆起雷柱 → 战场余波中人物收束`

### 时间轴

| 时间 | 镜头与动作 | 接力状态 |
|---|---|---|
| 00:00—00:01.20 | 新的战场低空机位承接高空剑瀑。群体飞剑命中妖潮，地面、黑雾、碎石和红绸能量爆开；大量飞剑随即抬升而非全部插地。 | 第一波完成局部清场，存量飞剑仍可控。 |
| 00:01.20—00:02.90 | 24mm贴地掠拍、35mm倾斜构图和18mm俯拍快切。多组剑群分别贴地回旋、斜切压入和侧路分流包抄后汇聚。 | 地面剑群持续猎杀，人物尚在高空。 |
| 00:02.90—00:03.60 | 50mm荷兰中近景，人物单手抬起控场，衣袍、长发和红绸仙力同步翻卷。 | 新一轮终极技前摇建立。 |
| 00:03.60—00:04.90 | 18mm超广角后拉升空，红绸扩张为遮天能量幕，覆盖妖潮并点亮铭文和能量纹理。 | 天幕控制场完成。 |
| 00:04.90—00:06.20 | 长焦先读取天幕内部成群剑影，再切超广角；不同区域分层、分批裂放三维剑群下射支脉。 | 群体下射覆盖不同战场区域。 |
| 00:06.20—00:07.40 | 贴地与高空俯拍交替。剑群命中区出现地裂，赤红雷光沿裂缝连续爆起成片雷柱；上方剑幕仍持续补入。 | 上下双层清场成立。 |
| 00:07.40—00:08.80 | 超广角展示三层攻击：上层铭文天幕、中层群体下射、下层低空剑群继续回旋猎杀。 | 战场大面积清空，仍有余波和少量剑群。 |
| 00:08.80—00:10.00 | 35或50mm人物中近景，天幕光照与红绸铺满前中后景；人物简洁收势，身后保留战场余波。 | 以人物英雄镜头结束。 |

### 第二段实测与风险

- 作者认为整体节奏偏慢，实际剪去前后各约1秒；
- 10秒内同时承担上一段落点、低空重组、人物前摇、天幕展开、再次下射、雷柱清场和人物结尾，职责过多；
- “雷柱”容易遮挡剑群接触，需按模型能力减少数量或改用地表雷海；
- 开头与结尾都偏展示性，若追求更高动作密度可保留其中一个。

## 第三段：天穹剑潮与地表雷剑终结

### 核心因果链

`新机位承接 → 红绸铺天 → 远天再召万剑 → 头顶形成不规则漩涡剑潮 → 人物抬头睁眼 → 全域同步爆发 → 一次挥手发令 → 剑潮推进并折成多处剑瀑 → 万剑覆盖妖潮 → 地表雷剑浪潮横扫 → 环形终结全灭`

### 时间轴

| 时间 | 镜头与动作 | 接力状态 |
|---|---|---|
| 00:00—00:00.35 | 第一帧切至18mm高空侧后超广角，保持人物高度、剑宗方位、云层色调、红绸规模和妖潮数量。 | 空间连续，原剑群暂时在画外。 |
| 00:00.35—00:01.45 | 镜头后拉抬升，人物单掌控场，红绸形成前后错层巨幕；本阶段不出现新剑群。 | 天空控制区域建立。 |
| 00:01.45—00:02.70 | 摄影机沿红绸抬向远天，银点从云层、左右天际、远山和高空深处持续赶来。 | 万剑来源清楚，正在汇入。 |
| 00:02.70—00:04.10 | 高位斜俯超广角，不同高度剑流汇成不规则三维漩涡；外层环绕、中层斜插、内层拧转，支流持续分离和并轨。 | 剑潮汇聚完成，人物稳定居中。 |
| 00:04.10—00:04.85 | 50mm侧前中近景推至75mm眼部特写，负荷兰角随人物抬头在睁眼瞬间回正；环境声短暂压低，约0.08秒短减速。 | 睁眼成为唯一全域触发点。 |
| 00:04.85—00:05.35 | 眼中雷光匹配切回18mm超广角；红绸外展、剑潮膨胀、雷痕点亮、战场被阴影覆盖、环形空气压缩波同步发生。 | 天地力量完成同步启动。 |
| 00:05.35—00:05.85 | 35mm高空中景，人物只做一次横向挥手，红绸指令贯穿剑潮，使其从拧转变为整体推进。 | 剑潮获得攻击方向。 |

| 00:08.35—00:09.25 | 赤雷只沿落剑点、妖体裂口和沟壑在地面铺开；低空飞剑重组为厚重剑潮，与贴地红绸形成横向雷剑浪潮。 | 浪潮扫过残余妖潮，地面能量网络连通。 |
| 00:09.25—00:10.00 | 地表雷痕在核心失稳，环形冲击波、地层撕裂、黑红体积爆云、碎石和红绸能量幕向外扩散；人物仍悬浮高空。 | 全域清空，冲击余波继续运动。 |

### 第三段实测与风险

- 作者认为整体冲击感偏弱；
- 4.10秒前主要用于铺天幕和召剑，终结动作集中在后半段，可能导致前慢后挤；
- 睁眼、镜头回正、天地同步爆发是有效的单一触发设计，应优先保留；
- 最终冲击依赖落剑点和地面雷痕的连续性，若前镜未建立清楚，核爆级结果会显得无因；
- 第三段明确禁止雷柱，与第二段的雷柱设计互斥。

## 群体飞剑共通定义

每组剑群由数百至上千把正常尺寸飞剑构成，具有前部、中段、尾部、横向宽度、上下厚度和前后纵深。内部持续换层、穿插、补位、分流和回补；前端先改向，中段顺势扭转，尾部延迟追随，外侧走大弧线，内侧压密，转向后再次扩展。

摄影机从剑群外部拍摄，清楚展示群体轮廓和空间路线。禁止进入剑群内部、只拍几把剑、用单剑领飞、用巨剑代替万剑、生成扁平剑板、剑墙、细线剑束、规则圆盘、同心圆、统一旋转中心、中央黑洞、空心剑管或机械螺旋。

“剑气如水、剑势成潮、剑流如河、剑瀑垂天”只描述群体运动，不生成真实水流、水幕、水花或瀑布。

## 可迁移结构

1. **规模建立**：远天来源 + 多纵深补入，比近景堆满剑体更可靠；
2. **群体可读**：前中尾结构 + 宽厚深 + 转向传播，比“数万把剑高速飞行”更可执行；
3. **人物控制**：极简人物动作与宏观群体同步响应，避免人物复杂结印抢占时长；
4. **跨段接力**：未命中剑瀑 → 落地清场 → 存量剑群回潮 → 再次编队；
5. **终结因果**：落剑点和沟壑建立雷痕网络 → 低空雷剑浪潮 → 地表环形爆发；
6. **平台校准**：原案例仅验证到即梦2.0-720的单次生成，迁移平台时需减少阶段并重测节奏。
