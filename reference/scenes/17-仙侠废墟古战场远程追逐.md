# 仙侠废墟古战场远程追逐

> 来源：用户资料《剑仙魔仙》，即梦-720 三段一次生成案例；吸收日期：2026-08-21。
>
> 定位：提供适合双人仙侠远程追逐的废墟空间、路线锚点与地形反馈。不绑定具体角色、属性、武器名称、分镜时长或胜负。

## 一、场景核心

冷调玄幻水墨质感的山谷废墟古战场。残柱、断崖、石质殿宇屋顶、沟壑碎石区与巨型石门残骸形成可连续跨越的立体路线，既能容纳超广角全域构图，也能为贴地追逐、踏壁折返和空域俯冲提供明确参照。

本场景优先服务双人或少量角色的中远程追逐，不按两军对垒、骑兵冲阵或攻城军阵组织。

## 二、空间锚点

### 2.1 残柱群

- 高低错落，柱顶宽度足以短促点踏；
- 柱体之间保留连续跳跃和变向距离；
- 踩踏处崩出石屑、墨尘和碎角，证明借力方向；
- 剑气命中后可由表层崩角逐步升级为柱身开裂或倾倒。

### 2.2 断崖壁

- 提供垂直攀升、横向踏壁、折返俯冲和高低层切换；
- 脚部接触产生剥落墨痕、碎石和反向尘线；
- 崖顶可作为远程压制点，但不能让角色长期停驻放波。

### 2.3 石质殿宇屋顶群

- 屋脊、檐角和屋顶间隙组成跑酷路线；
- 蹬檐、跨隙和落足处掉落瓦砾、石片与粉尘；
- 只使用古代石质或瓦质建筑，不出现现代屋面和金属板房。

### 2.4 沟壑碎石区

- 适合贴地横滑、低位翻滚、S形或V形折返；
- 沟壑既是攻击落点，也是人物切线和短暂遮挡来源；
- 剑气擦地后留下连续犁沟、裂纹、水渍、焦痕或其他与属性匹配的痕迹。

### 2.5 巨型石门残骸

- 作为全战场远端方向标和终结落点；
- 门柱、横梁与散落巨石提供前中后景尺度参照；
- 大招命中可按表层崩裂、深层剪切、主体倾倒的顺序产生层级破坏。

## 三、推荐追逐路线

### 3.1 地面—屋顶—空域

`沟壑贴地冲刺 → 蹬檐上屋脊 → 跨越屋顶间隙 → 踏柱升空 → 向断崖外侧俯冲`

适合追击方持续压缩距离，防守方通过高度和切线改变攻击角度。

### 3.2 断崖—残柱—远端石门

`踏壁横移 → 蹬壁折返 → 残柱顶连续点踏 → 低空斜切 → 石门残骸前急转`

适合双目标锁敌镜头保持长距离关系，并让远端地标持续证明位移尺度。

### 3.3 全域交叉

双方从战场对角启动，一方沿残柱与屋顶上升，另一方沿断崖和沟壑下降；在中央空域完成远程攻击交汇后，交换高低层并分别落向相反锚点。换位必须由追击、闪避、借力或攻击落点驱动。

## 四、地形交互门禁

- 大范围位移必须跨越至少两个空间锚点，不能在同一区域小幅横移冒充追逐；
- 无论奔跑、升空还是变向，都保留脚部接触、蹬踏反力或上一落点提供的动量；
- 空中停留只作为攻击、换向或观察的短暂中间态，不长期漂浮；
- 每次接触至少产生一种方向明确的反馈：石屑、瓦砾、尘线、裂纹、脚印或材质碎片；
- 环境破坏沿攻击落点递进，不能整片废墟无因同时爆炸；
- 前景碎石、断柱和尘雾可强化速度，但不得长期遮住人物、武器和攻击方向。

## 五、镜头适配

- **14—18mm高空超广角**：建立五类锚点、双人对角位置和全域追逐方向；
- **24mm贴地横移**：利用近景碎石、柱基和尘线制造相对运动；
- **低角度固定仰拍**：读取上下层角色、空域弹道和残柱尺度；
- **侧向或后侧跟拍**：跟随一名角色时仍把另一目标保留在有效战斗区域；
- **远端拉升**：用石门、断崖和残柱破坏展示大招规模。

镜头运动应与位移转向、攻击落点和爆炸反馈同步，保留加速、刹停、回弹等惯性，禁止无因跳到陌生区域。

## 六、不适用情况

- 需要大规模军阵、骑兵、攻城器械或两军战争的古战场；
- 纯室内近身对招；
- 没有高速位移、地形借力或环境破坏需求的静态斗法；
- 角色设定明确只能正常奔跑，却要求连续飞天、踏空和跨越全战场；
- 现代城市废墟、科幻遗迹或现代建筑材料为主的场景。
