# 暴雨悬崖古刹多层追击场景

## 来源与定位

- 来源：用户资料《8.2.txt》，吸收日期2026-08-22；
- 定位：为双人兵器战、轻功追击和超常能力战提供从室外到室内、从低处到高处再坠落的连续空间；
- 只提取环境、路线、材质和调度机制，不绑定原案例的黑发剑客、骨伞女或胜负。

## 场景总貌

古刹建在悬崖边缘，暴雨、闪电和翻滚暗云持续影响能见度、地面摩擦与材质反馈。建筑由积水庭院、木质回廊、飞檐屋脊、主殿高空与地面、悬挂铜钟、临崖大门组成，可形成“平面追击—垂直攀升—高处破坏—坠落入殿—巨物横扫—临崖终结”的多层路线。

## 五区空间拓扑

### A区｜积水庭院

- **空间职责**：建立双方方向、起手距离与第一轮攻防；
- **固定锚点**：院门、主殿台阶、回廊入口；
- **可交互物**：浅水膜、青砖、排水沟、石灯或台阶；
- **反馈**：踏步破水、滑移水痕、剑风切雨、青砖崩角；
- **转场出口**：受击、后翻或追击把人物送入木质回廊。

### B区｜狭窄木回廊

- **空间职责**：压缩横向闪避，迫使兵器进行近身格挡、偏转与连续换招；
- **固定锚点**：承重木柱、外侧护栏、上方飞檐；
- **路线限制**：两人不能并排大幅绕行，进攻方沿回廊纵轴追压，防守方只能后退、贴柱切线或借护栏改变高度；
- **反馈**：护栏断裂、木屑飞散、柱面刮痕、脚步在湿木板上打滑；
- **转场出口**：护栏或飞檐被击中后，一方借伞钩、手抓或踏柱向上，另一方沿柱或檐面追击。

### C区｜飞檐与湿滑屋脊

- **空间职责**：把平面近战升级为垂直追击与高低位攻防；
- **固定锚点**：飞檐翘角、承重柱顶、屋脊中线、破损瓦面；
- **路线限制**：所有上升、横移和折返必须有檐角、柱面、瓦片或绳索等支点，不能无因漂浮；
- **反馈**：瓦片滑落、檐角削断、木柱焦痕、雨水沿斜面形成滑行轨迹；
- **转场出口**：一次重击让屋脊主梁断裂，双方连同断木碎瓦坠入主殿。

### D区｜主殿与悬挂铜钟

- **空间职责**：承接坠落状态，利用巨物改变攻击线并为反击提供高度差；
- **固定锚点**：断裂屋顶缺口、悬钟铁链、铜钟摆动弧线、大殿地面与立柱；
- **可交互物**：铁链、铜钟、断木、碎瓦、积水、承重柱；
- **路线限制**：铜钟横扫前必须先看到铁链被抓住或踢击传力；摆动方向、人物闪避路径和落点保持在同一空间关系中；
- **反馈**：铜锈与雨水震飞、钟鸣、地面滑铲水痕、立柱和石板受斩击开裂；
- **转场出口**：大殿正门通向悬崖边，适合错身冲刺或远距离终结。

### E区｜临崖门口与暗云海

- **空间职责**：提供纵深尺度、终结停距和建筑破坏的观察背景；
- **固定锚点**：大殿门框、悬崖边缘、远处云海和山体闪电；
- **安全边界**：人物在临崖急停时保留清楚落脚面，终结冲刺不能无因越过悬崖；
- **反馈**：衣袍受风雨拉扯、积水向崖外流动、断裂建筑在前景坍塌、云海保持远景稳定尺度。

## 路线模板

`积水庭院起手 → 回廊纵轴追压 → 飞檐/木柱借力上升 → 湿滑屋脊短兵快打 → 屋顶重击塌陷 → 坠入主殿 → 铁链与铜钟改线 → 贴地滑铲反制 → 穿过殿门 → 临崖终结与建筑余波`

每次跨区必须由受击、追击、借力、坠落或巨物摆动触发；禁止通过无说明切镜让人物直接换层。

## 材质与光色

- **雨水**：附着衣物和兵器，形成水膜、溅射、切雨线和地面拖痕；
- **木材**：先弯曲或开裂，再产生木屑、断梁与空腔回响；
- **瓦片与青砖**：脚步滑移、崩角、碎裂和下坠需与受力方向一致；
- **铜钟与铁链**：保持重量、摆动惯性和金属回响，断面或凹痕服从攻击强度；
- **光线**：暗冷暴雨为底，闪电只短暂揭示建筑层次和人物轮廓，不长期过曝；
- **空气**：雨雾、木屑、瓦片、铜锈与水汽证明速度，但不得遮挡关键接触。

## 场景门禁

- 建筑破坏逐级累积，护栏、檐角、屋脊、立柱和铜钟不能跨镜恢复；
- 坠落镜头继承上一镜的兵器相抵、身体朝向和碎片速度；
- 复杂近战保留双人中景，跨层移动切回全景交代支点、落点和高度；
- 终结若使用延迟建筑破坏，先保留攻击路径和已建立裂痕，不能靠入鞘声无因制造新方向；
- 若用户只需要低法术武侠，保留雨、建筑和轻功路线并降低能量级破坏；若需要玄幻能力战，再放大附着特效与结构破坏。
