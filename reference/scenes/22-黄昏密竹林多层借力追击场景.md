# 22-黄昏密竹林多层借力追击场景

## 来源与定位

- 来源：用户资料《竹林打斗.docx》，吸收日期2026-08-22；
- 用途：为东方刀剑、轻功或风格化能力战提供“湿泥地面—密集竹干—横生竹枝—高处竹梢”的连续垂直路线；
- 本文件只提取空间、材质、遮挡和借力机制，不绑定白刃刀客、青衫剑主、固定胜负或九镜时长。

## 场景总貌

黄昏强侧逆光穿过密植青竹，形成可辨认的竖向光带和丁达尔光斑。地面由湿泥、碎石、浅沟和落叶组成；中层竹干密集但保留人体穿行宽度；高处横枝与竹梢可承担短暂落脚、摆荡和俯冲。竹林不是均匀背景，而是会压缩路线、遮挡视线、储存弯曲势能并留下连续破坏的多层战场。

## 四层空间拓扑

### A层｜湿泥碎石地面

- 承担开场俯冲、贴地滑行、第一次重接触和落地卸力；
- 湿泥显示滑痕、犁沟和落点，碎石只在砸地或重落时被带起；
- 贴地动作必须有既有速度与清楚终点，不能在原地无因启动。

### B层｜密集竹干通道

- 竹干形成窄门、侧向切线和反蹬支点，使双方围绕竹身换位而不是在空地原地轮招；
- 摄影机可短暂让竹干划过画面完成遮挡接力，但关键兵器接触前必须重新露出双方；
- 竹干受力先弯曲、震颤或留下刃痕，达到破坏阈值后才折断。

### C层｜横枝与中高层枝隙

- 承担蹬枝升空、倒挂俯冲、短时空中格挡和折返；
- 每次换层必须看见脚掌、手部或兵器与竹枝接触，折断的枝条继续下落并影响下一镜；
- 同一根枝条不能在承受重击折断后重新成为支点。

### D层｜竹梢与纵深冲刺廊道

- 高处竹梢用于建立俯冲起点和宏观高度，不作为长时间站立平台；
- 纵深廊道由两排竹干形成，适合双方弹开后借竹反蹬、加速对冲和错身终结；
- 大范围环形破坏只能在终结能力档启用，并沿已建立的接触中心向外传播。

## 推荐路线

`竹梢俯冲压落 → 地面滑行反扫 → 围竹换位 → 蹬竹升入枝隙 → 高低位短交换 → 倒挂俯冲与贴地反制 → 暗器封线或竹干反蹬 → 地面近身短链 → 双方弹开进入纵深廊道 → 错身终结与竹叶余波`

可按时长截取其中一段，但任何跨层都必须由俯冲、反蹬、挂接、折枝、坠落或上一动作动量触发。

## 材质与环境反馈

- **青竹**：受脚蹬先弯后弹，受刃先出切痕再断裂；弯曲方向与人物离开方向相反；
- **竹叶**：用于显示气流、下坠和旋转方向，不持续遮住人物轮廓；
- **湿泥**：滑行留连续沟痕，砸地形成局部凹坑，泥点沿受力方向飞散；
- **碎石与断枝**：速度慢于刀气和叶片，跨镜保持下落与滚动；
- **侧逆光**：强调竹干层次与兵器轮廓，不能让白衣或金色效果长期过曝。

## 场景门禁

- 竹干反蹬、跑竹和倒挂需要明确支点、接触时长和离开方向；
- 高速换位不等于无过程瞬移，至少保留起点、跨越路径和落点中的两项；
- 复杂近战使用双人中景，跨层和纵深冲刺使用全景；
- 全程强动态模糊降级为边缘与轨迹模糊，脚步、支点和兵器接触保持清楚；
- 环形断竹、连续空中格挡和极限旋转只用于明确能力档，写实武侠改为局部弯竹、断枝和短距离换层。
