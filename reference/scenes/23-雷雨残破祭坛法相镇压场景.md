# 23-雷雨残破祭坛法相镇压场景

## 来源与定位

- 来源：用户资料《7.30.txt》，吸收日期2026-08-22；
- 用途：为东方玄幻双人战提供“高柱伏击—积水祭坛近战—青雾封场—空间裂隙—巨掌镇压”的尺度升级路线；
- 本文件只描述空间、能见度、落点与破坏，不绑定骨伞女、剑女或固定结局。

## 场景结构

残破祭坛位于幽暗雷暴与月光交替的废墟中。主体由最高残柱、中心积水石台、外围断柱与碎墙、主落点凹坑及上方可容纳空间裂隙的开阔天幕组成。冷月和闪电负责短暂揭示高度，低雾与积水负责显示速度和压力；雾不能长期吞没人物与兵器关系。

## 五个锚点

1. **高柱伏击点**：供单人短暂停留、俯冲和起手方向建立；柱顶面积与角色落脚姿态必须匹配。
2. **中心石台**：承担伞尖与剑尖第一次重接触、近身换位和踢击；石板裂纹沿接触轴扩张。
3. **外围碎墙**：提供滑退终点和尺度参照，避免高速位移失去距离感。
4. **青雾转换区**：由可见法器或施术动作生成，负责遮挡转场而非无因清空战场。
5. **巨掌落点**：在镇压前保持可辨认目标、地面和手掌投影；命中后凹陷、碎石和积水沿掌压方向外推。

## 推荐路线

`高柱蓄势 → 垂直俯冲与地面上迎 → 中心石台短兵交换 → 重击拉开距离 → 施术者升空或法器离手 → 青雾建立转换区 → 裂隙由明确方向撕开 → 法相轮廓与巨掌出现 → 目标承压与落点建立 → 单次镇压 → 烟尘遮镜或余波收束`

近身阶段与召唤阶段是两个距离系统。若任务要求全程写实近身，删除裂隙与巨掌；若保留法相镇压，必须承认它是独立超常终结阶段。

## 环境反馈

- 积水先被脚步和兵器接触打散，再在巨掌压强下向外推成环；
- 石板先出现局部裂纹与下沉，终结时才扩大为凹坑；
- 低雾受人物突进切开，青雾由法器生成并具有来源、扩散方向与消散结果；
- 裂隙和法相依靠残柱、人物与落点维持尺度，不用纯黑背景替代空间；
- 雷声、石裂、伞骨旋转与巨掌压力可分层存在，不能用持续低频震动代替可见受力。

## 场景门禁

- 裂隙必须从可见裂点逐步扩大，巨手不能直接从画外无因落下；
- 至少一个广角同时交代施术者、法相/巨掌、目标与落点；
- 青雾遮挡后要恢复人物位置和攻击方向；
- 巨掌镇压只承担一次主终结，不再叠加同职责的第二次全屏爆发；
- 烟尘黑屏若用于结尾，先给出命中、受力和地面结果。
