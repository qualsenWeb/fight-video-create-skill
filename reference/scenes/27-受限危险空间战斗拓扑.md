# 受限危险空间战斗拓扑

## 来源与定位

- 来源：用户提供的二十份题材战斗资料之空间设计层归纳。
- 用途：处理狭窄、倾斜、失重、流体、易坠落、可坍塌或被群体持续挤压的战斗空间。
- 本条只保存空间拓扑、运动约束、环境反馈和终止条件，不绑定人物、题材、胜负或固定段落数量。

## 空间建模

先把场地拆为四类节点：

1. **生存节点**：可站稳、换气、恢复姿态或短时防守的位置。
2. **转向节点**：墙面、立柱、舱壁、桅杆、栏杆、残骸或水流交界，用于改变运动方向。
3. **风险节点**：舷缘、断崖、轨道、破口、火线、机关区、失压区或敌群入口。
4. **目标节点**：出口、控制装置、关键敌人、可夺取武器或必须守住的对象。

路线必须由目标驱动，并至少经过一个转向节点与一个风险节点。危险空间不是背景；它必须改变可走方向、动作幅度、攻击距离或失败代价。

## 六类空间机制

### 1. 狭窄通道

- 两侧墙面压缩横向闪避，长兵器和大幅抡击容易受阻，短桥、直刺、贴身控腕和纵向突围更有效。
- 前后出口决定攻防权：压迫方封住退路，脱身方通过贴墙换线、门框卡位或击倒前敌制造短通道。
- 群体战中每次只允许前排少量目标实际接触，其余目标通过逼近、封路和跨越倒地者持续施压。

### 2. 倾斜与周期晃动平面

- 甲板、飞艇或不稳定平台的倾角会周期性改变高低侧；角色可以顺坡滑入、逆坡减速或借回正瞬间突进。
- 站稳需要栏杆、缆绳、桅杆、低姿或宽支撑面；无支点的大幅挥击会放大失衡。
- 坠落风险必须通过脚步打滑、栏杆受力、绳索绷紧或边缘碎裂逐步建立，不能突然把人物移到场外。

### 3. 失重与低阻力空间

- 每次加速都需要蹬壁、抓杆、喷口、对手反震或抛出质量；挥击和格挡会同时改变双方漂移方向。
- 角色离开支点后不能无因急停。下一次转向必须等待新的接触、抓取或反向推力。
- 漂浮碎屑可提供方向与速度证据，也会遮挡路线或成为碰撞物；已受力碎屑沿原动量继续移动。

### 4. 流体与暗流空间

- 水下移动由推进、浮力、阻力和暗流共同决定；急转弯需要摆尾、划水、蹬物或借对手运动改线。
- 墨雾、沙尘或浑浊区只改变视野，不取消实体位置与惯性。进入遮蔽前先锁定出口或参照物。
- 狭窄残骸内部会限制长兵器转动，但可迫使柔性肢体折返、缠绕或撞上结构。

### 5. 可破坏掩体与结构

- 墙、柱、断桥、车厢、石棺和残楼先承担遮挡或支撑职责，达到受力阈值后才断裂、倾倒或坍塌。
- 结构破坏必须改变路线：打开新通道、封死旧通道、制造高差、暴露弱点或迫使双方分离。
- 破坏后的碎片、缺口和倾斜状态继续存在，不能在后续阶段复原。

### 6. 巨型尺度锚点

- 普通体型角色、巨型目标和环境参照物至少同时建立一次尺度关系。
- 小型角色优先沿脚踝、膝窝、肘弯、甲缝、感知器官或核心周围移动，不与完整质量正面对撞。
- 巨型攻击先形成覆盖区，小型角色从边缘、关节回收路径或结构盲区脱离；每次巨击也会制造新坑、断壁或可借力碎块。

## 路线骨架

### 困境突围

`出口被封 → 借窄口限制同时接敌数量 → 击倒前排制造短障碍 → 沿转向节点换线 → 承受一次真实受创 → 利用环境后果打开出口 → 带着伤损离场`

### 边缘死斗

`中心接触 → 平台倾斜或结构受损 → 双方滑向风险边缘 → 一方借固定支点改线 → 另一方因大幅动作失衡 → 缴械、制伏或迫退形成结果`

### 三维追逐

`高低层起点建立 → 第一支点加速 → 遮蔽区改线 → 对手攻击破坏下一支点 → 临时抓取或反作用力转向 → 在目标节点完成接触`

## 连续性门禁

- 每次跨层、急停和反向都必须有接触或推力来源。
- 环境交互至少改变位置、攻防权、武器状态、目标状态或场景结构之一。
- 同一支点损坏后不得再次承力；同一出口封闭后必须通过可见动作重新打开。
- 受伤、湿滑、低氧、失重、寒冷或甲板晃动必须影响后续选择，不能只作为气氛。
- 终结位置必须来自前段路线收缩，而不是临时指定的新地点。
